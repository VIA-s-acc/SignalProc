# Теория: банки фильтров, вейвлеты, тёплицевы матрицы {#theory}

Справочник по теории для переписывания на C++ старого Python-инструментария (двухканальный банк фильтров с полным восстановлением из факторизации полуполосного $P_0$, пирамида Малла, обнуление поддиапазонов WAV). Документ задаёт соглашения, формулы, алгоритмы, их стоимость, численные ловушки и **проверки, которые обязана проходить реализация**. Каждый подраздел самодостаточен: назначение → формулы → алгоритм и сложность → как проверить.

Метки приоритета реализации:

- **[ядро]** — нужно в первой работающей версии библиотеки и тестов;
- **[v1]** — первый полноценный выпуск;
- **[v2]** — следующий этап;
- **[исследовательское]** — по желанию, эксперименты.

Числа, помеченные «проверено», получены численно (Python 3.13, NumPy 2.3, PyWavelets 1.8) при подготовке документа; соответствующие проверки нужно перенести в тесты C++.

## 0. Соглашения и обозначения [ядро] {#conventions}

### 0.1. Сигналы и преобразования {#conv-signals}

- Сигнал $x[n]$, $n\in\mathbb Z$; конечный сигнал длины $N$ — индексы $0..N-1$.
- $z$-преобразование: $X(z)=\sum_n x[n]z^{-n}$. Задержка на $k$ отсчётов — умножение на $z^{-k}$.
- DTFT: $X(e^{i\omega})=\sum_n x[n]e^{-i\omega n}$, $\omega\in[-\pi,\pi)$ рад/отсчёт; частота в герцах $f=\omega f_s/(2\pi)$.
- DFT длины $N$: $X[k]=\sum_{n=0}^{N-1}x[n]e^{-2\pi i kn/N}$; матрица $F_{kn}=e^{-2\pi i kn/N}$, $F^{-1}=\tfrac1N F^{*}$.
- Обращение времени $h^-[n]=h[-n]\leftrightarrow H(z^{-1})$; модуляция $(-1)^n h[n]\leftrightarrow H(-z)$ (сдвиг АЧХ на $\pi$).

### 0.2. Фильтр как многочлен Лорана {#conv-laurent}

Фильтр хранится как пара (начальный индекс $n_0$, массив коэффициентов): $H(z)=\sum_{n=n_0}^{n_1}h[n]z^{-n}$, длина $L=n_1-n_0+1$. Отрицательные $n_0$ допустимы (нецентрированные и симметричные фильтры, лифтинг). Все операции (свёртка, модуляция, полифазное разложение, обращение) определены на этом типе.

**Ловушка.** Модуляция $(-1)^n h[n]$ зависит от *абсолютного* индекса: сдвиг фильтра на нечётное число отсчётов меняет знак ФВЧ. Массив без смещения теряет эту информацию — поэтому смещение хранится всегда.

### 0.3. Нормировка {#conv-normalisation}

- **Основная (ортонормированная):** $H_0(1)=F_0(1)=\sqrt2$; для ортогональных фильтров $\sum h_0[n]^2=1$. Это нормировка PyWavelets.
- **Суммирующая (Strang–Nguyen, старый код):** $H_0(1)=1$, $F_0(1)=2$. Сохраняет рациональность коэффициентов (Haar, 5/3, сплайновые CDF) и годится для точной арифметики.
- В обеих $P_0(1)=H_0(1)F_0(1)=2$. Переход: $h_0\cdot\sqrt2$, $f_0/\sqrt2$.

### 0.4. Знаки ФВЧ и соответствие PyWavelets {#conv-pywt}

Банк: анализ $h_0$ (ФНЧ), $h_1$ (ФВЧ); синтез $f_0$, $f_1$. Канал анализа $v_i[k]=(h_i*x)[2k]$, синтез $\hat x=\sum_i f_i*(\uparrow2\, v_i)$.

| роль | Strang–Nguyen / старый код | PyWavelets |
|---|---|---|
| ФНЧ анализа | $h_0$ | `dec_lo` $=h_0$ |
| ФНЧ синтеза | $f_0$ | `rec_lo` $=f_0$ |
| ФВЧ анализа | $H_1(z)=F_0(-z)$, $h_1[n]=(-1)^n f_0[n]$ | `dec_hi`$[n]=(-1)^{n+1}$`rec_lo`$[n]=-h_1[n]$ |
| ФВЧ синтеза | $F_1(z)=-H_0(-z)$, $f_1[n]=(-1)^{n+1}h_0[n]$ | `rec_hi`$[n]=(-1)^n$`dec_lo`$[n]=-f_1[n]$ |

Здесь $n$ — индекс массива от 0. Пара ФВЧ PyWavelets равна паре Strang–Nguyen со знаком минус; произведение $F_1H_1$ одинаково, все условия PR совпадают, у коэффициентов деталей меняется знак. Проверено на PyWavelets 1.8:

1. Все четыре массива одной длины; у `bior*` короткие фильтры дополнены нулями — при загрузке нули обрезать, сохранив смещение.
2. `dwt` вычисляет полную свёртку продолженного сигнала и берёт **нечётные** отсчёты: `cA[k]` $=(h_0*\tilde x)[2k+1]$. В нашей «чётной» записи это фильтры $zH_i(z)$; для Хаара это даёт восстановление без задержки (§5).
3. Ортогональные семейства: `dec_lo` = обращённый `rec_lo`; `rec_lo` — классические коэффициенты Daubechies (db2: $0.48296, 0.83652, 0.22414, -0.12941$), минимально-фазовые.
4. `biorNr.Nd`: у `rec_lo` $N_r$ нулей в $z=-1$, у `dec_lo` — $N_d$. Значит детали анализа обнуляют многочлены степени $<N_r$ (проверено: `bior3.1` обнуляет $t^0..t^2$, `bior1.3` — только константы), у вейвлета синтеза $N_d$ нулевых моментов. `rbioNr.Nd` — роли переставлены. `bior4.4` и `bior6.8` **не сплайновые**: это CDF 9/7 и 17/11 (длины ненулевых частей проверены).

Режим совместимости: библиотека C++ воспроизводит `pywt.dwt/idwt` для каждого режима границ с точностью $10^{-12}$ (double); знак деталей задаётся настройкой.

### 0.5. Полифазная запись {#conv-polyphase}

Фазы сигнала: $x^{(0)}[n]=x[2n]$, $x^{(1)}[n]=x[2n+1]$, $X(z)=X^{(0)}(z^2)+z^{-1}X^{(1)}(z^2)$.

- Анализ: $H(z)=H^{(0)}(z^2)+zH^{(1)}(z^2)$, $H^{(0)}(z)=\sum_k h[2k]z^{-k}$, $H^{(1)}(z)=\sum_k h[2k-1]z^{-k}$.
- Синтез: $F(z)=F^{(0)}(z^2)+z^{-1}F^{(1)}(z^2)$, $F^{(0)}(z)=\sum_k f[2k]z^{-k}$, $F^{(1)}(z)=\sum_k f[2k+1]z^{-k}$.

Тогда $V=H_p(z)X_p(z)$ и $\hat X_p=F_p(z)V$, где
$$H_p=\begin{pmatrix}H_0^{(0)}&H_0^{(1)}\\ H_1^{(0)}&H_1^{(1)}\end{pmatrix},\qquad F_p=\begin{pmatrix}F_0^{(0)}&F_1^{(0)}\\ F_0^{(1)}&F_1^{(1)}\end{pmatrix},$$
и PR без задержки $\iff F_p(z)H_p(z)=I$. Разные знаки степени $z$ у анализа и синтеза не ошибка: так оба соотношения выходят без лишних задержек. Матрица модуляции $H_m(z)=\begin{pmatrix}H_0(z)&H_0(-z)\\H_1(z)&H_1(-z)\end{pmatrix}=H_p(z^2)\begin{pmatrix}1&1\\ z&-z\end{pmatrix}$, отсюда $\det H_m(z)=-2z\det H_p(z^2)$.

## 1. Дискретные ЛИС-системы [ядро] {#lti}

### 1.1. Свёртка: линейная, круговая, корреляция {#lti-convolution}

**Назначение.** Базовая операция всех банков фильтров.

- Линейная: $y[n]=\sum_k h[k]x[n-k]$; длины $N$ и $L$ дают $N+L-1$.
- Круговая длины $N$: $(h\circledast x)[n]=\sum_{k}h[k]\,x[(n-k)\bmod N]$ — линейная свёртка, «завёрнутая» во времени. Совпадает с линейной, если сигналы дополнены нулями до длины $\ge N_x+L-1$.
- Корреляция: $r[n]=\sum_k h[k]x[k+n]=(h^-*x)[n]$. Анализ ортогонального банка — корреляция с `rec_lo`, то есть свёртка с `dec_lo`.

**Алгоритмы и сложность.** Прямая — $O(NL)$; через FFT — $O((N+L)\log(N+L))$; overlap-add/overlap-save с блоком $B\approx 2..4L$ — $O(N\log L)$. Порог выгоды FFT для double обычно $L\sim 32..128$ (измерить на целевой машине). Вейвлетные фильтры ($L\le 30$) считаются напрямую или лифтингом; FFT нужен для CWT и длинных КИХ.

**Ловушки.** Сдвиг начала (смещение Лорана); путаница круговой и линейной свёртки; у FFT-свёртки ошибка порядка $u\log N\,\|h\|\|x\|$ — абсолютная, а не относительная к каждому отсчёту, поэтому малые выходы получают большую относительную ошибку. Ошибку восстановления сравнивать с $\|x\|$, а не поэлементно.

**Проверка.** Прямая свёртка = FFT-свёртка = произведение на тёплицеву матрицу (§2.2) с точностью $10^{-13}\|h\|_1\|x\|_\infty$; круговая = линейная после свёртки по модулю $N$.

### 1.2. z-преобразование и DTFT {#lti-z-dtft}

Свойства: $h*x\leftrightarrow HX$; $x[n-k]\leftrightarrow z^{-k}X$; $x[-n]\leftrightarrow X(z^{-1})$; $(-1)^nx[n]\leftrightarrow X(-z)$; $a^nx[n]\leftrightarrow X(z/a)$. Область сходимости КИХ — вся плоскость без $0$ (и без $\infty$ при отрицательных индексах). DTFT — $X(z)$ на единичной окружности, период $2\pi$; Парсеваль: $\sum|x|^2=\frac1{2\pi}\int_{-\pi}^{\pi}|X|^2d\omega$. DFT — отсчёты DTFT в $\omega_k=2\pi k/N$; дополнение нулями сгущает сетку, но не повышает разрешение.

**Проверка.** DTFT прямым суммированием (Горнер) и через FFT с дополнением нулями совпадают с точностью $10^{-14}\|h\|_1$; численный Парсеваль.

### 1.3. Частотная характеристика, фаза, задержки {#lti-frequency-response}

$H(e^{i\omega})=|H|e^{i\varphi(\omega)}$; АЧХ $|H|$, ФЧХ $\varphi$, групповая задержка (ГВЗ) $\tau_g=-d\varphi/d\omega$, фазовая задержка $\tau_p=-\varphi/\omega$. Подробно, с устойчивыми формулами — §8.

### 1.4. Линейная фаза, типы I–IV {#lti-linear-phase}

Вещественный $h$ длины $L$, $M=L-1$. Симметричный: $h[n]=h[M-n]$, тогда $H(e^{i\omega})=e^{-i\omega M/2}A(\omega)$; антисимметричный: $h[n]=-h[M-n]$, $H=ie^{-i\omega M/2}A(\omega)$; $A$ вещественна (может менять знак).

| тип | симметрия | $L$ | $A(\omega)$ | вынужденные нули |
|---|---|---|---|---|
| I | симм. | нечётная | $\sum a_k\cos k\omega$ | нет |
| II | симм. | чётная | $\sum b_k\cos(k-\tfrac12)\omega$ | $z=-1$ |
| III | антисимм. | нечётная | $\sum c_k\sin k\omega$ | $z=\pm1$ |
| IV | антисимм. | чётная | $\sum d_k\sin(k-\tfrac12)\omega$ | $z=1$ |

Нули фильтра с линейной фазой идут парами $(z_0,1/z_0)$ и сопряжёнными — четвёрками; нули на окружности — сопряжёнными парами; $\pm1$ — одиночно. ГВЗ постоянна и равна $M/2$ (полуцелая при чётной $L$).

Следствие для банков: если $f_0$ типа II, то $h_1[n]=(-1)^nf_0[n]$ антисимметричен (тип IV); если $f_0$ типа I, то $h_1$ типа I. Биортогональные линейно-фазовые банки — пары «нечётная/нечётная» (5/3, 9/7) или «чётная/чётная» (2/6, 4/4). **Теорема:** единственный вещественный КИХ-ортогональный двухканальный банк с линейной фазой — Хаар (с точностью до тривиальных преобразований). Выбор: либо ортогональность, либо симметрия.

**Проверка.** Для симметричного фильтра ГВЗ на сетке равна $M/2$ вне нулей; корни идут взаимными парами (после удаления известных нулей в $\pm1$).

## 2. Тёплицевы матрицы [ядро / v1 / v2] {#toeplitz}

### 2.1. Определения и символ {#toeplitz-definitions}

$T_{ij}=t_{i-j}$ — матрица $n\times n$ задаётся $2n-1$ числами; символ $a(\omega)=\sum_k t_ke^{ik\omega}$, $T=T_n(a)$. Ганкелева матрица: $H_{ij}=h_{i+j}$. Перестановочная $J$ (единицы на побочной диагонали): $JTJ=T^{\mathsf T}$ (персимметрия).

### 2.2. Свёртка как ленточная тёплицева матрица [ядро] {#toeplitz-convolution}

**Формулы.** $y=T_hx$, $T_h\in\mathbb R^{(N+L-1)\times N}$, $(T_h)_{ij}=h[i-j]$: нижнетреугольная ленточная матрица ширины $L$. Режимы `same`/`valid` — подмножества строк. Для полных прямоугольных матриц $T_gT_h=T_{g*h}$ точно; квадратные усечения не замкнуты относительно произведения — поправки малого ранга, ганкелевого вида, сосредоточены у краёв.

**Алгоритм.** Матрица не хранится: умножение — прямая свёртка $O(NL)$. Явные матрицы строятся только для режима объяснений и тестов ($N\le 1024$).

**Проверка.** $T_hx$ (плотно) = свёртка; $T_gT_h=T_{g*h}$ для полных матриц.

### 2.3. Циркулянты и диагонализация DFT [ядро] {#toeplitz-circulant}

**Формулы.** $C=\mathrm{circ}(c)$, $C_{ij}=c[(i-j)\bmod N]$. Тогда $C=F^{-1}\operatorname{diag}(Fc)\,F$: собственные числа $\lambda_k=\hat c[k]$ (DFT первого столбца), собственные векторы — фурье-гармоники. Следствия: круговая свёртка — поэлементное умножение спектров, $O(N\log N)$; решение $Cx=b$ — деление спектров (если $\hat c[k]\ne0$); все циркулянты коммутируют; $\|C\|_2=\max|\hat c|$, $\mathrm{cond}(C)=\max|\hat c|/\min|\hat c|$. Режим `periodization` DWT даёт блочно-циркулянтные матрицы (§6.4).

**Проверка.** Собственные числа плотной $C$ (отсортированные) совпадают с FFT($c$); $Cx$ = круговая свёртка.

### 2.4. Тёплиц плюс Ганкель: симметричное продолжение [v1] {#toeplitz-plus-hankel}

**Формулы.** Полуотсчётное симметричное продолжение (HS, `symmetric` в pywt): $\tilde x[-1-n]=x[n]$, $\tilde x[N+n]=x[N-1-n]$. Свёртка, ограниченная на $[0,N)$, при $L<N$:
$$y=(T+H_L+H_R)x,\quad T_{ij}=h[i-j],\ (H_L)_{ij}=h[i+j+1],\ (H_R)_{ij}=h[i+j+1-2N].$$
Целоотсчётное (WS, `reflect`): $\tilde x[-n]=x[n]$; $(H_L)_{ij}=h[i+j]$ для $j\ge1$, $(H_R)_{ij}=h[i+j-2N+2]$ для $j\le N-2$. Для длинных фильтров отражения повторяются: продолжение периодично с периодом $2N$ (HS) или $2N-2$ (WS).

**Связь с DCT.** Для нуль-фазового симметричного фильтра ($h[k]=h[-k]$) и HS-продолжения $C_{\mathrm{II}}(T+H_L+H_R)C_{\mathrm{II}}^{\mathsf T}=\operatorname{diag}\big(H(e^{i\pi k/N})\big)$, где $C_{\mathrm{II}}$ — ортонормированная DCT-II (проверено численно, $N=10$). WS соответствует DCT-I. Это аналог пары «циркулянт ↔ DFT» для симметричных границ: быстрая фильтрация с симметричными краями и точный спектр матрицы.

**Проверка.** $(T+H_L+H_R)x$ = свёртка явно продолженного сигнала; диагонализация DCT-II с точностью $10^{-13}$.

### 2.5. Быстрое умножение через вложение в циркулянт [v1] {#toeplitz-fast-matvec}

**Алгоритм.** $T$ размера $n\times n$ с первым столбцом $c$ и первой строкой $r$ вкладывается в циркулянт порядка $m\ge2n-1$ с первым столбцом $[c_0,\dots,c_{n-1},0,\dots,0,r_{n-1},\dots,r_1]$; $Tx$ — первые $n$ компонент $C[x;0]$. Стоимость $O(m\log m)$; $m$ брать «гладким» ($2^a3^b5^c$). Прямоугольные матрицы свёртки — так же.

**Проверка.** Совпадение с плотным умножением для случайных $n$, включая простые.

### 2.6. Системы с тёплицевой матрицей: Левинсон–Дурбин, Шур [v2] {#toeplitz-levinson}

**Назначение в проекте.** МНК-синтез КИХ (нормальные уравнения тёплицевы или «тёплиц + Ганкель», §9.5), LPC/AR-огибающие как признаки, фильтр Винера для сравнения с вейвлетным шумоподавлением, спектральная факторизация методом Бауэра (§4.7).

**Дурбин** (симметричная положительно определённая $T$, уравнения Юла–Уокера $T_ma^{(m)}=-[r_1..r_m]^{\mathsf T}$, $A(z)=1+\sum a_jz^{-j}$): $E_0=r_0$,
$$k_m=-\frac{r_m+\sum_{j=1}^{m-1}a^{(m-1)}_jr_{m-j}}{E_{m-1}},\quad a^{(m)}=\begin{pmatrix}a^{(m-1)}\\0\end{pmatrix}+k_m\begin{pmatrix}Ja^{(m-1)}\\1\end{pmatrix},\quad E_m=(1-k_m^2)E_{m-1}.$$
$T$ положительно определена $\iff |k_m|<1$ для всех $m$. Произвольная правая часть — алгоритм Левинсона; оба $O(n^2)$ операций и $O(n)$ памяти. Слабо устойчивы для SPD; при нулевом ведущем миноре (неопределённые матрицы) — срыв: нужны look-ahead или плотное LU с выбором.

**Шур** вычисляет те же коэффициенты отражения и $LDL^{\mathsf T}$ без скалярных произведений — лучше распараллеливается; им же делается метод Бауэра. Сверхбыстрые $O(n\log^2n)$ алгоритмы — [исследовательское], для наших размеров не нужны.

**Проверка.** Решение = плотное решение; $|k_m|<1$ на AR-спектрах; детект срыва на матрице с вырожденным ведущим минором.

### 2.7. Формула Гохберга–Семенцула [v2] {#toeplitz-gohberg-semencul}

Пусть $T$ — обратимая тёплицева $n\times n$, $x=T^{-1}e_1$, $y=T^{-1}e_n$, $x_0\ne0$. Тогда
$$T^{-1}=\frac1{x_0}\Big(\mathcal L(x)\,\mathcal L(Jy)^{\mathsf T}-\mathcal L(Zy)\,\mathcal L(ZJx)^{\mathsf T}\Big),$$
где $\mathcal L(v)$ — нижнетреугольная тёплицева с первым столбцом $v$, $Z$ — сдвиг вниз, $J$ — перестановочная (проверено на случайной несимметричной $T$, $n=6$). Следствие: после вычисления $x,y$ (Левинсон, $O(n^2)$) каждое решение $T^{-1}b$ стоит четыре треугольных тёплицевых умножения через FFT, $O(n\log n)$. Полезно при многократных решениях с одной $T$.

### 2.8. Спектральный взгляд (символ) [v1] {#toeplitz-symbol}

Для вещественного чётного ограниченного символа $a$ собственные числа $T_n(a)$ лежат в $[\min a,\max a]$ и распределены как значения $a$ (Сегё): $\frac1n\sum_jF(\lambda^{(n)}_j)\to\frac1{2\pi}\int F(a(\omega))d\omega$; при $a>0$ $\mathrm{cond}(T_n)\uparrow\max a/\min a$. Блочный аналог для банка фильтров: сингулярные числа матрицы анализа заполняют $\big[\min_\omega\sigma_{\min}(H_p(e^{i\omega})),\max_\omega\sigma_{\max}(H_p(e^{i\omega}))\big]$ — это границы Рисса банка. В режиме периодизации — точно (§6.4).

**Проверка.** Плотные собственные числа $T_n(a)$ в пределах $[\min a,\max a]$; сингулярные числа матрицы анализа совпадают с объединением сингулярных чисел $H_p$ на сетке (§6.4).

## 3. Многоскоростная обработка и передискретизация [ядро / v1] {#multirate}

### 3.1. Прореживание и интерполяция: наложение и зеркальные копии [ядро] {#multirate-down-up}

**Формулы.** $\downarrow M$: $y[n]=x[Mn]$,
$$Y(z)=\frac1M\sum_{k=0}^{M-1}X\big(z^{1/M}W_M^k\big),\quad W_M=e^{-2\pi i/M};\qquad Y(e^{i\omega})=\frac1M\sum_{k=0}^{M-1}X\big(e^{i(\omega-2\pi k)/M}\big).$$
Спектр растягивается в $M$ раз; $M$ копий перекрываются — **наложение (aliasing)**, если $X$ не ограничен полосой $|\omega|<\pi/M$. Для $M=2$: $Y(z)=\tfrac12[X(z^{1/2})+X(-z^{1/2})]$.

$\uparrow M$: $y[n]=x[n/M]$ при $M\mid n$, иначе $0$; $Y(z)=X(z^M)$ — спектр сжимается, появляются $M-1$ **зеркальные копии (imaging)** в $2\pi k/M$.

Связка «вниз-вверх»: $(\uparrow2)(\downarrow2)x=\tfrac12\big(x+(-1)^nx\big)\leftrightarrow\tfrac12[X(z)+X(-z)]$ — компонента наложения $X(-z)$, присутствующая в любом двухканальном банке.

«Сжатие/растяжение» старого кода — это ровно $\downarrow2/\uparrow2$; без фильтров это не изменение темпа звука, а наложение и зеркальные копии.

**Проверка.** Синусоида частоты $\omega_0>\pi/M$ после $\downarrow M$ появляется на $|\omega_0M-2\pi k|$; после $\uparrow M$ спектр содержит копии в $\pm\omega_0/M+2\pi k/M$.

### 3.2. Дециматор и интерполятор для произвольного M [ядро] {#multirate-anti-alias}

- **Децимация:** ФНЧ с частотой среза $\pi/M$ и усилением $1$ в полосе пропускания, затем $\downarrow M$.
- **Интерполяция:** $\uparrow M$, затем ФНЧ со срезом $\pi/M$ и **усилением $M$**: вставка нулей уменьшает среднее (DC) в $M$ раз, фильтр восстанавливает амплитуду.

Практическая спецификация для звука: полоса пропускания до 20 кГц, задерживание — от половины новой частоты дискретизации, ослабление 90–120 дБ. В двухканальном банке, наоборот, наложение в каждом канале допускается, потому что синтез его компенсирует (§4.2) — это другая философия, чем у дециматора.

**Проверка.** Остаток наложения (тон в полосе задерживания) ниже спецификации; ошибка амплитуды тона в полосе пропускания в пределах пульсаций.

### 3.3. Тождества Нобла [ядро] {#multirate-noble}

$(\downarrow M)\to G(z)\ \equiv\ G(z^M)\to(\downarrow M)$; $\ G(z)\to(\uparrow M)\ \equiv\ (\uparrow M)\to G(z^M)$. Операции $\uparrow L$ и $\downarrow M$ коммутируют тогда и только тогда, когда $\gcd(L,M)=1$. Следствие: многоуровневое дерево сводится к одноступенчатым эквивалентным фильтрам (§8.7).

**Проверка.** Обе стороны тождества на случайном сигнале совпадают поэлементно.

### 3.4. Полифазное разложение для M каналов [ядро] {#multirate-polyphase}

Тип 1: $H(z)=\sum_{p=0}^{M-1}z^{-p}E_p(z^M)$, $e_p[n]=h[nM+p]$. Дециматор в полифазной форме вычисляет только сохраняемые отсчёты: $L$ умножений на выходной отсчёт вместо $LM$. Интерполятор (тип 2, коммутатор): выходная фаза $p$ получается фильтром $E_p$ на низкой частоте. Двухканальная запись §0.5 — вариант с $z^{+1}$ у анализа.

### 3.5. Рациональная передискретизация L/M [v1] {#multirate-rational}

**Схема.** $\uparrow L\to H\to\downarrow M$, где $H$ — ФНЧ со срезом $\min(\pi/L,\pi/M)$ и усилением $L$.

**Полифазная реализация.** $u=\uparrow L\,x$, $w=h*u$, $y[m]=w[mM]=\sum_r h[mM-rL]x[r]$. С $q_m=\lfloor mM/L\rfloor$, $p_m=mM\bmod L$:
$$y[m]=\sum_j h[jL+p_m]\,x[q_m-j].$$
Заранее строятся $L$ подфильтров $e_p[j]=h[jL+p]$ длины $\lceil N_h/L\rceil$; стоимость — $\lceil N_h/L\rceil$ умножений-накоплений (MAC) на выходной отсчёт, без обращений к нулям и отбрасываемым отсчётам; фазы повторяются с периодом $L$ выходов ($M$ входов).

**Пример 44,1 → 48 кГц.** $48000/44100=160/147$; промежуточная частота $7{,}056$ МГц. Полоса пропускания 20 кГц, задерживания — от 22,05 кГц, 100 дБ: по Кайзеру (§9.3) $N_h\approx(A-8)/(2{,}285\,\Delta\omega)$, $\Delta\omega=2\pi\cdot2050/7{,}056\cdot10^6$, откуда $N_h\approx2{,}2\cdot10^4$ отводов, $\approx138$ MAC на выходной отсчёт и канал ($\approx6{,}6\cdot10^6$ MAC/с) — проверено. Таблица коэффициентов: 160 фаз × 138 отводов. Наивная схема дороже в 160 раз.

**Произвольное и переменное отношение** — полифазная таблица с интерполяцией между фазами (полосно-ограниченная интерполяция, структура Фэрроу) [v2].

**Проверка.** Синусоида: частота и амплитуда после передискретизации; уровень наложения и копий (тон около 21 кГц); $L/L$ — тождество; цепочка 44,1→48→44,1 — ошибка в пределах пульсаций полосы пропускания; сверка с эталоном (`scipy.signal.resample_poly` с тем же фильтром).

### 3.6. Многоступенчатая децимация [v1] {#multirate-multistage}

При больших $M=M_1M_2\cdots$ первые ступени получают широкую переходную полосу (наложение достаточно подавить только в итоговой полосе), а самый крутой фильтр работает на самой низкой частоте в последней ступени. Полуполосные ступени ($M=2$) имеют каждый второй коэффициент нулевым. Выигрыш при $M\ge8..16$ — обычно порядок по стоимости (Crochiere–Rabiner). Пирамида Малла — та же многоступенчатая структура из ступеней $\downarrow2$, но без требования подавлять наложение.

### 3.7. Полифазная матрица и матрица модуляции для M каналов [v2] {#multirate-matrices}

Анализ $H_k(z)=\sum_pE_{k,p}(z^M)z^{-p}$ — полифазная матрица $E(z)$ размера $M\times M$; матрица модуляции $[H_m(z)]_{k,l}=H_k(zW_M^l)$. Выход банка: $\hat X(z)=\frac1M\sum_{l}\Big(\sum_kF_k(z)H_k(zW^l)\Big)X(zW^l)$. Для $M=2$ в нашей записи $H_m(z)=H_p(z^2)\begin{pmatrix}1&1\\z&-z\end{pmatrix}$.

### 3.8. Растяжение во времени без смены высоты — другая операция [v2] {#multirate-time-stretch}

Передискретизация меняет и длительность, и высоту тона (как воспроизведение на другой скорости). Изменить темп без изменения высоты можно только через анализ–модификацию–синтез: **фазовый вокодер** (STFT с разными шагами анализа и синтеза и пересчётом фаз; артефакт «фазовости», лечится фазовой синхронизацией — Laroche–Dolson 1999) или **WSOLA** (во временной области: наложение-сложение сегментов, выбранных по сходству формы волны, — Verhelst–Roelands 1993). Это не многоскоростная операция банка фильтров и в ядро не входит.

## 4. Двухканальные банки фильтров [ядро] {#two-channel}

### 4.1. Уравнения искажения и наложения {#fb-distortion-alias}

**Формулы.** При $v_i=\downarrow2(h_i*x)$ и $\hat x=\sum f_i*\uparrow2\,v_i$:
$$\hat X(z)=T(z)X(z)+A(z)X(-z),\quad T=\tfrac12\big[F_0H_0+F_1H_1\big],\quad A=\tfrac12\big[F_0(z)H_0(-z)+F_1(z)H_1(-z)\big],$$
в матричной форме $[T\ \ A]=\tfrac12[F_0\ \ F_1]H_m(z)$. **PR с задержкой $\ell$:** $A\equiv0$, $T=cz^{-\ell}$.

**Проверка.** Вычислить $T$ и $A$ как многочлены Лорана и сравнить с $z^{-\ell}$ и $0$ точно (рациональные фильтры) или с точностью $10^{-15}$.

### 4.2. Выбор синтеза для компенсации наложения {#fb-alias-cancellation}

Общее решение: $[F_0\ F_1]=[2cz^{-\ell},\,0]\,H_m^{-1}$, то есть
$$F_0=\frac{2cz^{-\ell}}{D(z)}H_1(-z),\quad F_1=-\frac{2cz^{-\ell}}{D(z)}H_0(-z),\quad D=\det H_m=H_0(z)H_1(-z)-H_0(-z)H_1(z).$$
$D(-z)=-D(z)$; КИХ-синтез для КИХ-анализа $\iff D$ — одночлен нечётной степени.

**Стандартный выбор** (Strang–Nguyen, старый код): $H_1(z)=F_0(-z)$, $F_1(z)=-H_0(-z)$. Тогда $A\equiv0$ при любых $H_0,F_0$, и
$$T=\tfrac12\big[P_0(z)-P_0(-z)\big],\quad P_0=F_0H_0 .$$
**PR $\iff P_0(z)-P_0(-z)=2z^{-\ell}$**: у $P_0$ единственный ненулевой нечётный коэффициент $p_0[\ell]=1$, $\ell$ нечётно, чётные коэффициенты свободны. Нуль-фазовая форма: $P(z)=z^{\ell}P_0(z)$ — **полуполосный** фильтр, $P(z)+P(-z)=2$ ($p[0]=1$, $p[2k]=0$ при $k\ne0$). Проектирование банка = выбор полуполосного $P_0$ и его факторизация $P_0=F_0H_0$ (§4.6–4.8).

### 4.3. QMF (Croisier–Esteban–Galand) {#fb-qmf}

$H_1(z)=H_0(-z)$, $F_0=H_0$, $F_1=-H_1$: наложение компенсируется, $T=\tfrac12[H_0^2(z)-H_0^2(-z)]=2z^{-1}E_0(z^2)E_1(z^2)$ при $H_0=E_0(z^2)+z^{-1}E_1(z^2)$. КИХ-PR возможна только для одночленов $E_0,E_1$, то есть для двухотводного (хааровского) фильтра. Практические QMF (Джонстон) — линейно-фазовые с почти полным восстановлением. «Зеркальность»: $|H_1(e^{i\omega})|=|H_0(e^{i(\pi-\omega)})|$ — симметрия относительно $\pi/2$. В проекте — только как исторический и учебный пример.

### 4.4. CQF / ортогональный банк (Smith–Barnwell) {#fb-cqf}

$L$ чётно, $N=L-1$: $H_1(z)=-z^{-N}H_0(-z^{-1})$, $F_0(z)=z^{-N}H_0(z^{-1})$, $F_1(z)=z^{-N}H_1(z^{-1})$ (синтез — обращённый анализ). Это частный случай §4.2: $H_1(z)=F_0(-z)$ при нечётном $N$. $P_0=z^{-N}H_0(z)H_0(z^{-1})$, и PR (нормировка $\sqrt2$) эквивалентна каждому из условий:
$$\textstyle\sum_nh_0[n]h_0[n+2k]=\delta_k\ \iff\ |H_0(e^{i\omega})|^2+|H_0(e^{i(\omega+\pi)})|^2=2\ \iff\ R(z)+R(-z)=2,\ R=H_0(z)H_0(z^{-1}).$$
Так как $R=|H_0|^2\ge0$ на окружности, полуполосный $P$ для ортогонального банка обязан быть **неотрицательным на окружности** (нули на ней — чётной кратности).

**Проверка.** Двойное сдвиговое ортогональное соотношение до $10^{-15}$; степенная симметрия на сетке 4096 точек.

### 4.5. Полифазное условие PR и параунитарность {#fb-polyphase-pr}

**Формулы** (запись §0.5). PR без задержки $\iff F_pH_p=I$; с задержкой $\ell=2m$: $F_pH_p=z^{-m}I$; с $\ell=2m+1$: $F_pH_p=\begin{pmatrix}0&z^{-m-1}\\z^{-m}&0\end{pmatrix}$. КИХ-обратная существует $\iff\det H_p(z)=cz^{-k}$, $c\neq0$. Тогда $F_p=\operatorname{adj}H_p/\det H_p$:
$$F_0^{(0)}=\frac{H_1^{(1)}}{\det},\ F_1^{(0)}=-\frac{H_0^{(1)}}{\det},\ F_0^{(1)}=-\frac{H_1^{(0)}}{\det},\ F_1^{(1)}=\frac{H_0^{(0)}}{\det},$$
что во временной форме даёт $F_0(z)=-z^{-1}H_1(-z)/\det H_p(z^2)$, $F_1(z)=z^{-1}H_0(-z)/\det H_p(z^2)$ — та же структура компенсации наложения.

**Параунитарность:** $\tilde H_p(z)H_p(z)=I$, $\tilde H(z)=H^{\mathsf T}(z^{-1})$ (вещественные коэффициенты), то есть $H_p(e^{i\omega})$ унитарна при всех $\omega$; тогда $F_p=\tilde H_p$, банк ортонормирован, выполняется Парсеваль. Любая $2\times2$ КИХ-параунитарная матрица раскладывается в решётку $R_K\Lambda(z)R_{K-1}\cdots\Lambda(z)R_0$, $\Lambda=\operatorname{diag}(1,z^{-1})$, $R_k$ — повороты (Vaidyanathan): PR сохраняется при любом квантовании углов [v2].

**Проверка.** $\det H_p$ — одночлен (как многочлен Лорана); произведение $F_pH_p$ как матрица многочленов равно $I$; для ортогональных — $H_p(e^{i\omega})$ унитарна на сетке.

### 4.6. Максимально плоский полуполосный фильтр Daubechies {#fb-maxflat}

**Формулы.** С $y=\sin^2(\omega/2)=(2-z-z^{-1})/4$ и $\cos^2(\omega/2)=(1+z)(1+z^{-1})/4$:
$$P_p(z)=2\left(\frac{(1+z)(1+z^{-1})}4\right)^{p}B_p\!\left(\frac{2-z-z^{-1}}4\right),\qquad B_p(y)=\sum_{k=0}^{p-1}\binom{p-1+k}{k}y^k .$$
Тождество Безу $(1-y)^pB_p(y)+y^pB_p(1-y)=1$ даёт $P_p(z)+P_p(-z)=2$; $B_p$ — единственный многочлен минимальной степени с этим свойством. Причинная форма $P_0(z)=z^{-(2p-1)}P_p(z)$: длина $4p-1$, задержка $\ell=2p-1$, $2p$ нулей в $z=-1$, максимальная плоскость в $\omega=0$ и $\omega=\pi$ (КИХ-аналог фильтра Баттерворта; замкнутая форма — Herrmann 1971).

**Пример $p=2$.** $B_2=1+2y$, $P_0=\frac1{16}(-1+9z^{-2}+16z^{-3}+9z^{-4}-z^{-6})=-\frac1{16}(1+z^{-1})^4(1-4z^{-1}+z^{-2})$, $\ell=3$ (проверено). Корень $y=-\tfrac12$ даёт $z+z^{-1}=4$, $z=2\pm\sqrt3$.

**Корни.** Каждый корень $y_j$ многочлена $B_p$ (степень $p-1$) даёт пару взаимных корней: $z^2-c_jz+1=0$, $c_j=2-4y_j$, $z=(c_j\pm\sqrt{c_j^2-4})/2$. $B_p>0$ на $[0,1]$, поэтому эти корни не лежат на окружности. Корни ищутся в переменной $y$ (степень $p-1$), а не в $z$ (степень $4p-2$); нули в $-1$ никогда не передаются в поиск корней.

**Проверка.** Сравнить $P_p$ с формулой для $p=1..20$ в рациональной арифметике (коэффициенты $B_p$ целые); проверить $P_p(z)+P_p(-z)=2$ точно.

### 4.7. Спектральная факторизация: правила распределения корней {#fb-spectral-factorisation}

Корни $P$ ($2p$ в $z=-1$ и $2(p-1)$ вне окружности) делятся между $H_0$ и $F_0$.

- **Ортогональный случай (dbN, $N=p$):** нужно $F_0=$ обращение $H_0$; из каждой взаимной пары $\{z_j,1/z_j\}$ (сопряжённые — вместе) берётся один корень, по $p$ нулей в $-1$ каждому. Минимальная фаза — все $|z_j|<1$: это dbN (`rec_lo` в pywt). Вариантов $2^{n_r+n_c}$ ($n_r$ — вещественные пары, $n_c$ — комплексные четвёрки). **Symlets** — вариант с фазой, ближайшей к линейной (критерий Daubechies; перебор реален при $p\le20$; в спорных случаях сверять с таблицами pywt).
- **Биортогональный линейно-фазовый:** каждая взаимная пара (четвёрка) целиком в одном фильтре; $k$ нулей в $-1$ — в $H_0$, $2p-k$ — в $F_0$. Сплайновое семейство CDF: $F_0\propto(1+z^{-1})^{N_r}$ (B-сплайн), всё остальное — в $H_0$. **CDF 9/7** ($p=4$): у $B_4$ один вещественный корень (вещественная пара → 7-отводный фильтр синтеза) и пара комплексных (комплексная четвёрка → 9-отводный ФНЧ анализа), по 4 нуля в $-1$ каждому. Проверено по `bior4.4`: нули `dec_lo` $2{,}031\pm1{,}739i$, $0{,}284\pm0{,}243i$; нули `rec_lo` $3{,}041$, $0{,}329$.
- **Не максимально плоские $P$** (Ремез, §9.6) с подъёмом $P\ge0$ для ортогональных банков — процедура Smith–Barnwell [v2].

**Численные трудности.** Нуль кратности $m$, найденный численно, имеет ошибку $\sim u^{1/m}$: у 9-отводного фильтра с четырёхкратным нулём в $-1$ найденные корни отклоняются на $1{,}2\cdot10^{-4}$ (проверено). Правило: нули в $-1$ известны точно и вводятся множителем $(1+z^{-1})^k$ с биномиальными коэффициентами. Обусловленность корней $B_p$ растёт экспоненциально с $p$; pywt хранит db до db38 заранее вычисленными таблицами. Альтернативы:

1. Повышенная точность (MPFR / Boost.Multiprecision, 100–300 бит) офлайн, затем таблицы.
2. **Метод Бауэра:** разложение Холецкого ленточной тёплицевой $T_n(Q)$ с символом $Q(e^{i\omega})>0$; строки множителя стабилизируются к коэффициентам минимально-фазового множителя. Сходимость медленная при нулях символа на окружности — поэтому сначала выносится $(1+z^{-1})^{2p}$, факторизуется остаток $Q$, множитель возвращается.
3. **Кепстральный (Колмогоров):** $\log Q(e^{i\omega})\to$ IFFT $\to$ оставить $c[0]/2$ и $c[n>0]$ $\to$ FFT $\to\exp$; требует $Q>0$ на окружности (снова вынести нули в $-1$) и большой FFT ($\ge32\times$ длины фильтра) из-за наложения кепстра.

**Проверка.** Произведение множителей восстанавливает $P$ с точностью $10^{-14}\|P\|$; полуполосность; ортогональность $\sum h[n]h[n+2k]=\delta_k$; минимальная фаза — все нули (кроме $-1$) внутри круга; совпадение с таблицами pywt.

### 4.8. Все факторизации P0 степени 6 (пример Strang–Nguyen) {#fb-p0-factorisations}

## 5. Учебный пример: банк Хаара [ядро] {#haar}

Точка входа режима объяснений: каждый шаг ниже — экран с конкретными числами и инвариантом, который на нём выполняется.

### 5.1. Фильтры и произведение P0 {#haar-filters}

Знаки Strang–Nguyen (индексы 0, 1):
$$h_0=\tfrac1{\sqrt2}[1,1],\quad h_1=\tfrac1{\sqrt2}[1,-1],\quad f_0=\tfrac1{\sqrt2}[1,1],\quad f_1=\tfrac1{\sqrt2}[-1,1].$$
В pywt `dec_hi` $=\tfrac1{\sqrt2}[-1,1]$, `rec_hi` $=\tfrac1{\sqrt2}[1,-1]$ (знаки ФВЧ обратные, §0.4).

$H_0=\frac{1+z^{-1}}{\sqrt2}$, $H_1=\frac{1-z^{-1}}{\sqrt2}=F_0(-z)$, $F_1=-H_0(-z)=\frac{-1+z^{-1}}{\sqrt2}$. Произведение $P_0=F_0H_0=\tfrac12(1+z^{-1})^2=\tfrac12(1+2z^{-1}+z^{-2})$; $P_0(z)-P_0(-z)=2z^{-1}$, задержка $\ell=1$; $T=z^{-1}$, $A=\tfrac14\big[(1+z^{-1})(1-z^{-1})-(1-z^{-1})(1+z^{-1})\big]=0$. Это максимально плоский $P_p$ при $p=1$ ($B_1=1$).

### 5.2. Пошаговый пример: анализ → ↓2 → ↑2 → синтез {#haar-walkthrough}

Сигнал $x=[4,6,10,12,8,6,5,5]$, $N=8$.

1. **Свёртки** (длина 9): $y_0=h_0*x=\tfrac1{\sqrt2}[4,10,16,22,20,14,11,10,5]$; $y_1=h_1*x=\tfrac1{\sqrt2}[4,2,4,2,-4,-2,-1,0,-5]$ ($y_1[m]=x[m]-x[m-1]$).
2. **Прореживание** — нечётные индексы 1, 3, 5, 7 (фаза pywt): $a=\tfrac1{\sqrt2}[10,22,14,10]\approx[7{,}0711;\,15{,}5563;\,9{,}8995;\,7{,}0711]$, $d=\tfrac1{\sqrt2}[2,2,-2,0]\approx[1{,}4142;\,1{,}4142;\,-1{,}4142;\,0]$. Смысл: $a[k]=(x[2k]+x[2k+1])/\sqrt2$ — масштабированное локальное среднее, $d[k]=(x[2k+1]-x[2k])/\sqrt2$ — локальная разность. Чётная фаза (индексы 0, 2, …, 8) дала бы 5+5 коэффициентов, захватывающих пары $(x[2k-1],x[2k])$ с нулём на краю, и восстановление с задержкой 1 — это причинная схема Strang–Nguyen.
3. **Растяжение** (на чётные позиции): $u_0=[a_0,0,a_1,0,a_2,0,a_3,0]$, $u_1=[d_0,0,d_1,0,\dots]$.
4. **Фильтры синтеза** (отсчёты $n=0..7$): $w_0=f_0*u_0=[5,5,11,11,7,7,5,5]$, $w_1=f_1*u_1=[-1,1,-1,1,1,-1,0,0]$.
5. **Сумма:** $w_0+w_1=[4,6,10,12,8,6,5,5]=x$ — точно и без задержки (анализ с фазой pywt эквивалентен фильтрам $zH_i$).

Инварианты экранов: $\|x\|^2=446=\|a\|^2+\|d\|^2=440+6$ (Парсеваль); $w_0$ — кусочно-постоянное среднее, $w_1=x-w_0$ — детали. Обнуление $d$ даёт $\hat x=w_0$, ошибку $w_1$ и наложение (§5.5).

**Точность.** В плавающей точке множители $1/\sqrt2$ дают ошибки округления. В суммирующей нормировке ($h_0=\tfrac12[1,1]$, $f_0=[1,1]$) все промежуточные значения для целого входа — двоично-рациональные, вычисляются точно, и режим объяснений может показывать точные дроби. Полностью целочисленный вариант — S-преобразование лифтингом: $d=x_{\text{odd}}-x_{\text{even}}$, $s=x_{\text{even}}+\lfloor d/2\rfloor$.

### 5.3. Многоуровневое разложение {#haar-multilevel}

Применяя тот же шаг к $a$: уровень 2 — $a_2=[16,12]$, $d_2=[6,-2]$; уровень 3 — $a_3=[28/\sqrt2]\approx[19{,}799]$, $d_3=[-4/\sqrt2]\approx[-2{,}828]$. Вектор коэффициентов в порядке pywt $[a_3,d_3,d_2,d_1]$: $[19{,}799;\,-2{,}828;\,6;\,-2;\,1{,}414;\,1{,}414;\,-1{,}414;\,0]$. Энергия $392+8+40+6=446$.

### 5.4. Матрица анализа при N = 8 {#haar-matrix}

Один уровень, перемежающийся порядок $(a_0,d_0,a_1,d_1,\dots)$: $A_1=I_4\otimes B$, $B=\tfrac1{\sqrt2}\begin{pmatrix}1&1\\-1&1\end{pmatrix}$. Матрица блочно-диагональна, потому что полифазная матрица Хаара постоянна, $H_p(z)=B$: блоки не перекрываются. В порядке $[L;B]$: $A_1=\tfrac1{\sqrt2}\begin{pmatrix}I_4\otimes[1\ 1]\\ I_4\otimes[-1\ 1]\end{pmatrix}$. $A_1^{\mathsf T}A_1=I$, синтез $S=A_1^{\mathsf T}$.

Три уровня $W=\operatorname{diag}(A^{(3)},I_6)\operatorname{diag}(A^{(2)},I_4)A^{(1)}$ (низкие частоты первыми). Строки $W$ (порядок $a_3,d_3,d_2,d_1$) — дискретные функции Хаара:
$$\tfrac1{\sqrt8}[1,1,1,1,1,1,1,1],\ \ \tfrac1{\sqrt8}[-1,-1,-1,-1,1,1,1,1],\ \ \tfrac12[-1,-1,1,1,0,0,0,0],\ \ \tfrac12[0,0,0,0,-1,-1,1,1],\ \ \tfrac1{\sqrt2}[-1,1,0,\dots,0],\ \dots$$
$Wx$ даёт вектор из §5.3, $WW^{\mathsf T}=I$. В знаках pywt строки деталей меняют знак.

### 5.5. АЧХ, ФЧХ, наложение {#haar-frequency}

$H_0(e^{i\omega})=\sqrt2\cos(\omega/2)\,e^{-i\omega/2}$, $H_1(e^{i\omega})=\sqrt2\,i\sin(\omega/2)\,e^{-i\omega/2}$. На $[0,\pi]$: $|H_0|=\sqrt2\cos(\omega/2)$, $|H_1|=\sqrt2\sin(\omega/2)$; $|H_0|^2+|H_1|^2=2$; ФЧХ $-\omega/2$ (тип II) и $\pi/2-\omega/2$ (тип IV), ГВЗ $\tfrac12$ у обоих. Относительно постоянной составляющей ($+3{,}01$ дБ) уровень $-3$ дБ ровно на $\pi/2$; при $3\pi/4$ $|H_0|/\sqrt2=\cos(3\pi/8)=0{,}383$ ($-8{,}3$ дБ); единственный нуль — в $\pi$. Утечка ФВЧ при $\pi/4$: $\sin(\pi/8)=0{,}383$, тоже $-8{,}3$ дБ.

При обнулении деталей: $T=\tfrac12F_0H_0=\cos^2(\omega/2)e^{-i\omega}$, наложение $|A(e^{i\omega})|=\tfrac12|F_0(e^{i\omega})H_0(e^{i(\omega+\pi)})|=\tfrac12|\sin\omega|$, максимум $\tfrac12$ ($-6$ дБ) на $\pi/2$.

### 5.6. Эквивалентные фильтры уровней {#haar-equivalent}

ФНЧ после $j$ уровней — «ящик» длины $2^j$: $G_j(z)=\prod_{k=0}^{j-1}H_0(z^{2^k})=2^{-j/2}\sum_{n=0}^{2^j-1}z^{-n}$. Детали уровня $j$: $H^{eq}_j(z)=H_1(z^{2^{j-1}})G_{j-1}(z)=2^{-j/2}\Big(\sum_{n=0}^{2^{j-1}-1}z^{-n}-\sum_{n=2^{j-1}}^{2^j-1}z^{-n}\Big)$.
$$|G_j(e^{i\omega})|=2^{-j/2}\left|\frac{\sin(2^{j-1}\omega)}{\sin(\omega/2)}\right|,\qquad |H^{eq}_j(e^{i\omega})|=2^{1-j/2}\frac{\sin^2(2^{j-2}\omega)}{|\sin(\omega/2)|}.$$
Боковые лепестки убывают лишь как $1/\omega$ (первый у «ящика» $\approx-13$ дБ) — октавные полосы сильно перекрываются.

### 5.7. Почему Хаар хорош во времени и плох по частоте {#haar-tradeoff}

Носитель ровно $2^j$ отсчётов, сдвиги не перекрываются (блочное преобразование), ступеньки и транзиенты локализованы идеально, вычисления целочисленные. Но: один нулевой момент (обнуляются только константы), поэтому гладкий сигнал даёт заметные детали — плохая концентрация энергии; $|H_0|\sim\cos$ — огромная переходная полоса и сильное наложение при изменении поддиапазонов; $\psi$ разрывна — блочные артефакты после порога или обнуления.

### 5.8. Сценарий режима объяснений {#haar-explain-script}

Экраны: (1) сигнал; (2) фильтры — коэффициенты, АЧХ, ФЧХ; (3) полные свёртки $y_0,y_1$; (4) прореживание с подсветкой сохранённых отсчётов; (5) $a,d$ и столбики энергии ($446=440+6$); (6) растяжение; (7) свёртки синтеза $w_0,w_1$; (8) сумма и нулевая ошибка; (9) матричный вид $A_1x=[a;d]$, $A_1^{\mathsf T}$; (10) многоуровневое дерево и матрица $W$; (11) частотный вид — $|H_0|,|H_1|,T,A$; (12) эксперимент «обнулить $d$» — $w_0$, спектр ошибки и наложения. На каждом экране проверяется свой инвариант (энергия, точное восстановление, $WW^{\mathsf T}=I$).

## 6. Матрицы банков фильтров и обработка границ [ядро / v1] {#fb-matrices}

### 6.1. Бесконечные матрицы анализа и синтеза {#fbm-infinite}

**Формулы** (Strang–Nguyen). $L_{k,n}=h_0[2k-n]$, $B_{k,n}=h_1[2k-n]$, $A=\begin{pmatrix}L\\B\end{pmatrix}$: каждая строка — обращённый фильтр, соседние строки сдвинуты на 2 («двойной сдвиг»). Синтез $S=[S_L\ S_B]$, $(S_L)_{n,k}=f_0[n-2k]$, $(S_B)_{n,k}=f_1[n-2k]$: столбцы — сдвинутые фильтры.

- PR без задержки: $SA=S_LL+S_BB=I$.
- Биортогональность: $AS=I\iff\sum_nh_i[2k-n]f_j[n-2m]=(h_i*f_j)[2(k-m)]=\delta_{ij}\delta_{km}$; при $i=j=0$ это полуполосность $f_0*h_0$.
- Ортогональность: $S=A^{\mathsf T}\iff f_i[n]=h_i[-n]$; $A^{\mathsf T}A=AA^{\mathsf T}=I$.

**Проверка.** На фрагменте $64\times64$ (в середине, вдали от краёв) $SA=I$ и $AS=I$.

### 6.2. Блочно-тёплицева структура и символ H_p {#fbm-block-toeplitz}

Перемежим строки $(v_0[k],v_1[k])$ и пары столбцов $(x[2n],x[2n+1])$. Блок $(k,n)$:
$$\begin{pmatrix}h_0[2(k-n)]&h_0[2(k-n)-1]\\ h_1[2(k-n)]&h_1[2(k-n)-1]\end{pmatrix}$$
зависит только от $k-n$: матрица $2\times2$-блочно-тёплицева, её символ $\sum_jB_jz^{-j}=H_p(z)$ (запись §0.5). Синтез — символ $F_p(z)$; PR $\iff F_pH_p=I$. Хаар: ненулевой только $B_0$ (блочная диагональ, §5.4); при длине $L$ — около $L/2$ ненулевых блоков в блочной строке.

### 6.3. Многоуровневое преобразование как произведение матриц {#fbm-multilevel}

$W_J=\operatorname{diag}(A^{(J)},I)\cdots\operatorname{diag}(A^{(2)},I)\,A^{(1)}$ (размеры уменьшаются вдвое, порядок коэффициентов $[a_J,d_J,\dots,d_1]$). Ортогональные уровни дают ортогональную $W_J$. Реализация матриц не строит, кроме режима объяснений и тестов ($N\le1024$).

### 6.4. Периодизация: блочный циркулянт [ядро] {#fbm-periodization}

**Формулы.** Для $N$-периодического $x$ ($N$ чётно) $A$ — блочный циркулянт из $N/2$ блоков $2\times2$: преобразование критически дискретизировано ($N$ коэффициентов), PR для любого PR-банка, ортогональный банк даёт ортогональную $A$ (проверено db3, $N=16$). Преобразование $(F_{N/2}\otimes I_2)$ блочно диагонализует $A$, на диагонали $H_p(e^{2\pi ik/(N/2)})$, $k=0..N/2-1$. Поэтому
$$\sigma(A)=\bigcup_k\sigma\big(H_p(e^{2\pi ik/(N/2)})\big)$$
(проверено `bior2.2`, $N=16$: $\mathrm{cond}=2{,}0$). Это даёт точное $\mathrm{cond}(A)$ и границы Рисса за $O(N)$; в бесконечном случае — $\inf/\sup$ по $\omega$.

**Недостаток:** разрыв на стыке периода даёт большие детали у краёв. $J$ уровней требуют $2^J\mid N$ (иначе — дополнение).

**Проверка.** $\|A^{\mathsf T}A-I\|$ для ортогональных; Парсеваль; спектр через $H_p$ равен плотному SVD.

### 6.5. Режимы границ и длины выходов [ядро] {#fbm-boundary-modes}

$N$ — длина входа, $L$ — длина фильтра; длина каждой полосы за один уровень:

| режим (pywt) | продолжение | длина полосы | критическая дискретизация |
|---|---|---|---|
| `zero` | $0$ вне $[0,N)$ | $\lfloor(N+L-1)/2\rfloor$ | нет |
| `constant` | повтор крайнего отсчёта | то же | нет |
| `smooth` | линейная экстраполяция по двум крайним | то же | нет |
| `symmetric` (HS) | $\dots x_1x_0\mid x_0x_1\dots$ | то же | нет |
| `reflect` (WS) | $\dots x_2x_1\mid x_0x_1x_2\dots$ | то же | нет |
| `antisymmetric` | $\dots -x_1\,{-x_0}\mid x_0x_1\dots$ | то же | нет |
| `antireflect` | $\tilde x[-n]=2x_0-x_n$ | то же | нет |
| `periodic` | периодическое, расширенное | то же | нет |
| `periodization` | круговое | $\lceil N/2\rceil$ | да |

Проверено на pywt 1.8: `idwt(dwt(x))=x` во всех 9 режимах для db2, `bior2.2`, db4 при $N\in\{13,16\}$; длины $N=13,L=4\to8$, $N=16\to9$, `periodization` — 7 и 8. Многоуровневые длины — рекурсией по той же формуле; максимальный уровень pywt $\lfloor\log_2(N/(L-1))\rfloor$.

### 6.6. Нерасширяющее симметричное продолжение [v1] {#fbm-nonexpansive-symmetric}

Критическая дискретизация, точное PR и отсутствие разрыва на краю одновременно возможны только для **линейно-фазовых** фильтров:

- нечётная длина (тип I: 5/3, 9/7) + WS-продолжение (период $2N-2$): полосы симметричны, хранится $\lceil N/2\rceil$ низких и $\lfloor N/2\rfloor$ высоких коэффициентов; так делает JPEG 2000 Part 1;
- чётная длина (тип II ФНЧ, тип IV ФВЧ: 2/6) + HS-продолжение (период $2N$): ФНЧ-полоса HS-симметрична, ФВЧ — HS-антисимметрична; $N/2+N/2$ при чётном $N$.

Матрично — квадратная обратимая $N\times N$ вида «тёплиц + Ганкель» (§2.4). Ортогональные не-хааровские фильтры с симметричным продолжением без расширения PR не дают.

**Практичная реализация** — лифтинг (§10) с зеркалированием индексов на каждом шаге: $x[-1]:=x[1]$, $x[N]:=x[N-2]$, $d[-1]:=d[0]$. Обратный проход использует то же правило, поэтому PR точное по построению при любой чётности $N$.

**Проверка.** Ровно $N$ коэффициентов; PR; симметрия продолженных полос; совпадение со свёрточной реализацией на явно продолженном сигнале.

### 6.7. Какой режим что гарантирует {#fbm-mode-guarantees}

- `periodization` — квадратная матрица и PR для любого PR-банка, артефакты на стыке.
- Нерасширяющий симметричный — квадратная матрица и PR только для линейной фазы, без артефактов разрыва.
- Остальные режимы — расширяющие ($\approx N+L-2$ коэффициентов на уровень), PR за счёт хранения всех коэффициентов, совместимы с pywt.

### 6.8. Граничные вейвлеты Коэна–Добеши–Вьяля [исследовательское] {#fbm-cdv}

Ортонормированные базисы на $[0,1]$, сохраняющие $N$ нулевых моментов у краёв: по $N$ граничных масштабирующих функций с каждой стороны, изменённые фильтры у краёв, матрицы предобусловливания; квадратная ортогональная матрица без краевых артефактов; нужны заранее вычисленные таблицы (распространяются через netlib). Упрощённая альтернатива: ортогонализация (QR) усечённых граничных строк $A$ — ортогональность сохраняется, нулевые моменты у краёв нет.

**Проверка.** $W^{\mathsf T}W=I$; детали многочленов степени $<N$ равны нулю **включая** граничные коэффициенты.

## 7. Теория вейвлетов [v1] {#wavelets}

### 7.1. Кратномасштабный анализ (MRA) {#wav-mra}

Замкнутые подпространства $\dots\subset V_1\subset V_0\subset V_{-1}\subset\dots$ в $L^2(\mathbb R)$ (больший $j$ — грубее, как уровни pywt): $f(t)\in V_j\iff f(2t)\in V_{j-1}$; $\bigcap V_j=\{0\}$, $\overline{\bigcup V_j}=L^2$; $V_0$ инвариантно относительно целых сдвигов; $\{\varphi(t-k)\}$ — базис Рисса (ортонормированный) $V_0$. Детали: $V_{j-1}=V_j\oplus W_j$. Уровень $j$ деталей соответствует масштабу $2^j$.

### 7.2. Уравнение масштабирования и вейвлет {#wav-refinement}

**Формулы** (нормировка $\sqrt2$; $h=f_0=$ `rec_lo`, $g=f_1=$ `rec_hi`):
$$\varphi(t)=\sqrt2\sum_kh[k]\varphi(2t-k),\qquad \psi(t)=\sqrt2\sum_kg[k]\varphi(2t-k).$$
В частотной области $\Phi(\omega)=m_0(\omega/2)\Phi(\omega/2)$, $m_0(\omega)=\tfrac1{\sqrt2}\sum_kh[k]e^{-ik\omega}$, $m_0(0)=1$, откуда $\Phi(\omega)=\prod_{j\ge1}m_0(\omega/2^j)$. Ортонормированность сдвигов $\iff\sum_k|\Phi(\omega+2\pi k)|^2=1$, откуда $|m_0(\omega)|^2+|m_0(\omega+\pi)|^2=1$ — необходимо, но не достаточно (нужен ещё критерий Лоутона/Коэна, §7.3).

Биортогональный случай: $\tilde\varphi$ строится по обращённому ФНЧ анализа (`dec_lo` обращённый), $\langle\varphi(\cdot-k),\tilde\varphi(\cdot-m)\rangle=\delta_{km}$. Коэффициенты $c_j[k]=\langle f,\tilde\varphi_{j,k}\rangle$, $d_j[k]=\langle f,\tilde\psi_{j,k}\rangle$ вычисляет пирамида Малла: $c_{j+1}=\downarrow2(h_0*c_j)$, $d_{j+1}=\downarrow2(h_1*c_j)$.

**Ловушка «вейвлетного преступления»** (Strang–Nguyen): отсчёты $x[n]$ — не $c_0[n]$. Для звука принимаем чисто дискретный взгляд (банк фильтров на $\ell^2$), а MRA используем для визуализации $\varphi,\psi$; койфлеты дают $x[n]\approx c_0[n]$ с высоким порядком.

### 7.3. Каскадный алгоритм и сходимость {#wav-cascade}

**Алгоритм.** $\varphi^{(i+1)}(t)=\sqrt2\sum_kh[k]\varphi^{(i)}(2t-k)$, $\varphi^{(0)}=\mathbf 1_{[0,1)}$. Дискретно: $c^{(0)}=[1]$, $c^{(i+1)}=\sqrt2\,(\uparrow2\,c^{(i)})*h$ (при суммирующей нормировке множитель $2$), $\varphi(n2^{-i})\approx c^{(i)}[n]$; эквивалентно $c^{(i)}=2^{i/2}\cdot$ИХ $\prod_{k<i}H(z^{2^k})$. Для $\psi$ — один шаг с $g$, затем каскад с $h$. Носитель $\varphi$ — $[0,L-1]$. Стоимость итерации $O(L2^i)$; для отображения хватает 10–12 итераций.

**Сходимость.** В $L^2$ — по условию E (Strang–Nguyen) для оператора перехода $T_{|m_0|^2}$: собственное число $1$ простое, остальные по модулю $<1$; на практике $\iff s>0$ (§4.8). Равномерная сходимость требует показателя Гёльдера $>0$.

**Диагностика расхождения** (для режима визуализации): $2^{-i}\sum_nc^{(i)}[n]^2$ — квадрат $L^2$-нормы итерации. Проверено: у 5/3 сходится ($2{,}1386$), при $s=0$ растёт линейно, при $s=-0{,}56$ (`bior3.1`) — в $4^{0{,}56}\approx2{,}17$ раза за шаг.

### 7.4. Метод собственного вектора: φ в двоично-рациональных точках {#wav-eigenvector}

$\varphi(n)=\sqrt2\sum_kh[k]\varphi(2n-k)$ для целых $n$: $v=Mv$, $M_{n,m}=\sqrt2\,h[2n-m]$, $n,m=0..L-1$; $v$ — собственный вектор с числом $1$, нормированный $\sum_n\varphi(n)=1$ (разбиение единицы; нужен хотя бы один нуль в $\pi$). Затем $\varphi(n+\tfrac12)=\sqrt2\sum_kh[k]\varphi(2n+1-k)$ и так далее до любого двоичного уровня — точно, без ошибки аппроксимации каскада.

**Проверка.** Спектр $M$ содержит $1,\tfrac12,\dots,2^{-(N-1)}$ при $N$ нулях в $\pi$ (проверено: db2 — $1;\,0{,}683;\,0{,}5;\,0{,}183$; db4 содержит $1;\,0{,}5;\,0{,}25;\,0{,}125$); $\sum_n\varphi(n+t)=1$ для двоичных $t$; совпадение с каскадом при $i\to\infty$.

### 7.5. Нулевые моменты ⇔ нули в π {#wav-vanishing-moments}

$\tilde\psi$ (вейвлет анализа) имеет $\tilde N$ нулевых моментов $\int t^k\tilde\psi=0$, $k<\tilde N$ $\iff$ $H_1$ имеет $\tilde N$ нулей в $z=1$ $\iff$ $F_0$ имеет $\tilde N$ нулей в $z=-1$ (так как $H_1(z)=F_0(-z)$) $\iff$ $\varphi$ воспроизводит многочлены степени $<\tilde N$ (Стрэнг–Фикс: $\Phi(2\pi k)$ имеет нуль порядка $\tilde N$ при $k\ne0$). Дискретная форма для тестов: детали отсчётов многочлена степени $<\tilde N$ равны нулю вдали от краёв. Для `biorNr.Nd` $\tilde N=N_r$ (проверено); для dbN — $N$ с обеих сторон.

### 7.6. Регулярность {#wav-regularity}

Гёльдер: $|\varphi(t)-\varphi(\tau)|\le C|t-\tau|^\alpha$ (для $\alpha\le1$, далее — для производных); Соболев: $\varphi\in H^s\iff\int(1+\omega^2)^s|\Phi|^2<\infty$; $\alpha\ge s-\tfrac12$.

Оценки: (а) точный показатель Соболева через оператор перехода, $s=N-\log_4\rho(T_{|L|^2})$ (§4.8); (б) оценка Daubechies: при $m_0=\big(\tfrac{1+e^{-i\omega}}2\big)^NL(\omega)$ и $B=\sup|L|<2^{N-1}$ функция $\varphi\in C^\alpha$ с $\alpha\ge N-1-\log_2B$; уточняется через $B_k=\sup|\prod_{j<k}L(2^j\omega)|^{1/k}$.

Значения $s$ (вычислено): Хаар $0{,}5$; db2 $1{,}0$ (Гёльдер $\approx0{,}55$); db3 $1{,}415$; db4 $1{,}776$; 9/7 — $s(\varphi)=2{,}12$, $s(\tilde\varphi)=1{,}41$; 5/3 — $1{,}5/0{,}44$; `bior3.3` — $s(\tilde\varphi)=0{,}175$ (едва в $L^2$). Асимптотически Гёльдер dbN $\approx0{,}2075N$ ($1-\log_23/2$ на нуль).

**Проверка.** Эталонные значения выше; согласование с поведением каскада.

| семейство | определяющее свойство | длина | нулевые моменты | заметки |

Формулы для частотных семейств:

- **Battle–Lemarié** порядка $m$: $\Phi(\omega)=\hat B_m(\omega)\big/\sqrt{\sum_k|\hat B_m(\omega+2\pi k)|^2}$; $m_0$ рациональна по $e^{i\omega}$ (БИХ); реализация в частотной области (периодизация, FFT) или усечённым КИХ [v2].
- **Meyer** (с точностью до фазового множителя $e^{\pm i\omega/2}$): $\Phi(\omega)=1$ при $|\omega|\le2\pi/3$, $\cos\!\big[\tfrac\pi2\nu\big(\tfrac{3|\omega|}{2\pi}-1\big)\big]$ при $2\pi/3\le|\omega|\le4\pi/3$, $0$ дальше;

Гладкость в частотной области даёт быстрое убывание во времени [v2].
- **Shannon:** $\Phi=\mathbf 1_{[-\pi,\pi]}$, $|\Psi|=\mathbf 1_{\pi\le|\omega|\le2\pi}$ — предел dbN при $N\to\infty$.

**Проверка.** Коэффициенты всех КИХ-семейств — сверка с pywt; ортогональность и PR; число нулей в $-1$; длины.

## 8. Частотные характеристики фильтров и банков [ядро] {#freq}

### 8.1. Термины {#freq-terms}

Стандартные русские термины:

- **АЧХ** — амплитудно-частотная характеристика $|H(e^{i\omega})|$.
- **ЛАЧХ** — логарифмическая АЧХ $20\lg|H|$ в дБ, обычно на логарифмической оси частот.
- **ФЧХ** — фазо-частотная характеристика $\varphi(\omega)=\arg H$.
- **АФЧХ** — комплексная $H(e^{i\omega})$ как годограф на комплексной плоскости.
- **ГВЗ** — групповое время запаздывания $\tau_g(\omega)$; **фазовая задержка** $\tau_p(\omega)$.
- **ИХ** — импульсная характеристика $h[n]$; **ПХ** — переходная характеристика $s[n]$.

«АХЧ», «АЧС», «ФЧС» стандартными терминами не являются (это, по-видимому, опечатки АЧХ/ФЧХ). Отличать **спектр сигнала** $|X(e^{i\omega})|$ от **характеристики фильтра** $|H(e^{i\omega})|$.

### 8.2. АЧХ и ЛАЧХ {#freq-magnitude}

**Вычисление.** На равномерной сетке — FFT с дополнением нулями до $K\ge8L$ (обычно 4096); на произвольных частотах (логарифмическая ось для звука) — Горнер или Гёрцель в каждой точке. Перевод в дБ с полом: $20\lg\max(|H|,10^{-300/20})$; точные нули (в $\pi$ у вейвлетных ФНЧ) отображать как $-\infty$ с меткой. Нормировка: у вейвлетного ФНЧ $|H_0(0)|=\sqrt2$ ($+3{,}01$ дБ) — переключатель «абсолютно / относительно $H(0)$». Ось: $\omega\in[0,\pi]$ или $f=\omega f_s/2\pi$; номинальная полоса деталей уровня $j$ — $[f_s/2^{j+1},f_s/2^j]$.

**Проверка.** FFT и Горнер совпадают; $|H(0)|=\lvert\sum h\rvert$, $|H(\pi)|=\lvert\sum(-1)^nh[n]\rvert$.

### 8.3. ФЧХ: свёрнутая и развёрнутая {#freq-phase}

Свёрнутая фаза — в $(-\pi,\pi]$; развёрнутая — с добавлением $2\pi$ на скачках больше $\pi$. Ловушки: (1) в нулях $H$ на окружности фаза скачет на $\pi$ (смена знака вещественной амплитуды $A(\omega)$) — это не свёртка, развёртка не должна её «исправлять»; для линейно-фазовых фильтров показывать знаковую $A(\omega)$ и линейный член отдельно; (2) редкая сетка рождает ложные скачки; (3) где $|H|$ мала (полоса задерживания), фаза — численный шум: маскировать, например, ниже $-120$ дБ относительно максимума. Линейная фаза: $\varphi=-\omega M/2$ ($+\pi/2$ для антисимметричных) плюс скачки $\pi$.

### 8.4. ГВЗ и фазовая задержка {#freq-group-delay}

**Устойчивая формула** (без дифференцирования развёрнутой фазы):
$$\tau_g(\omega)=\operatorname{Re}\frac{H_n(e^{i\omega})}{H(e^{i\omega})},\qquad H_n=\text{DTFT}\{n\,h[n]\},$$
так как $\frac d{d\omega}\ln H=-iH_n/H$ и $\varphi'=-\operatorname{Re}(H_n/H)$. Два FFT, без развёртки; не определена в нулях $H$ (пики около нулей, близких к окружности, — реальный эффект): маскировать по $|H|$. Для БИХ $B/A$: $\tau=\tau_B-\tau_A$. Единицы: отсчёты, в секунды — делением на $f_s$. Фазовая задержка $\tau_p=-\varphi_{\text{unwr}}(\omega)/\omega$ требует развёрнутой фазы с правильной ветвью при $\omega\to0$ ($\varphi(0)\in\{0,\pi\}$).

**Проверка.** Симметричный фильтр — $\tau_g\equiv M/2$; чистая задержка $z^{-k}$ — $k$; сравнение с численной производной развёрнутой фазы на гладком участке.

### 8.5. ИХ и ПХ {#freq-impulse-step}

ИХ $h[n]$ — стебли с учётом смещения Лорана; ПХ $s[n]=\sum_{k\le n}h[k]$, $s[\infty]=H(1)$. Видны выброс и звон (Гиббс): у Хаара ПХ монотонна, у db4 звенит. Для звука: симметричная ИХ даёт предзвон, минимально-фазовая — послезвон; это смазывание транзиентов.

### 8.6. Карта нулей и полюсов {#freq-zero-pole}

КИХ $H(z)=z^{-(L-1)}\cdot$(многочлен): $L-1$ нулей и полюс кратности $L-1$ в $z=0$ (причинная индексация; при отрицательных индексах — полюса в $\infty$). БИХ: устойчивость — полюса внутри круга. У вейвлетных фильтров: кластер из $N$ нулей в $-1$ (вычисленные корни расползаются по кругу радиуса $\sim u^{1/N}$ — $10^{-4}$ при $N=4$, поэтому показывать **известную** кратность, а не найденные корни), взаимные пары у линейной фазы, все нули внутри у минимальной фазы (`rec_lo` dbN). Остальные нули искать у остатка после точного деления на $(1+z^{-1})^N$.

### 8.7. Метрики полос и полуполосная симметрия {#freq-band-metrics}

- Срез $-3$ дБ: $|H(\omega_c)|=|H(0)|/\sqrt2$. **У любого ортогонального ФНЧ он ровно на $\pi/2$**: из степенной симметрии $|H_0(\pi/2)|^2=1=|H_0(0)|^2/2$ — хороший тест.
- Пульсации полосы пропускания $\delta_p=\max\big||H|/|H(0)|-1\big|$ (в дБ $20\lg\frac{1+\delta_p}{1-\delta_p}$); ослабление $A_s=-20\lg\max_{\text{стоп}}|H|/|H(0)|$; переходная полоса $\Delta\omega=\omega_s-\omega_p$.
- У максимально плоских фильтров пульсаций нет, а переходная полоса широкая: сообщать $\omega$ на уровнях $-1,-3,-20,-40$ дБ.
- Степенная симметрия (ортогональный банк, $\sqrt2$): $|H_0(\omega)|^2+|H_0(\pi-\omega)|^2=2$ (для вещественных $|H_0(\pi-\omega)|=|H_0(\omega+\pi)|$); $|H_0|^2$ — полуполосный.
- Степенная комплементарность: $|H_0(\omega)|^2+|H_1(\omega)|^2=2$. Биортогональные банки её не выполняют; показывать «дефект ортогональности» $|H_0|^2+|H_1|^2-2$.

### 8.8. Эквивалентные фильтры поддиапазонов {#freq-equivalent-filters}

По тождествам Нобла детали уровня $j$ получаются одним фильтром и $\downarrow2^j$:
$$H^{eq}_j(z)=H_1\big(z^{2^{j-1}}\big)\prod_{k=0}^{j-2}H_0\big(z^{2^k}\big),\qquad G^{eq}_J(z)=\prod_{k=0}^{J-1}H_0\big(z^{2^k}\big),$$
синтез — то же с $F_0,F_1$. Длина при $L_0=L_1=L$: $(2^j-1)(L-1)+1$. АЧХ набора $\{H^{eq}_1,\dots,H^{eq}_J,G^{eq}_J\}$ показывает октавное разбиение (номинально $[\pi/2^j,\pi/2^{j-1}]$), перекрытие соседей (потенциал наложения) и боковые лепестки от утечки $H_0$ (у Хаара $-13$ дБ). Вычисление: точное произведение многочленов или произведение DTFT на сетке $H^{eq}_j(e^{i\omega})=H_1(e^{i2^{j-1}\omega})\prod H_0(e^{i2^k\omega})$. При $\sqrt2$-нормировке у ортогональных банков $\|h^{eq}_j\|=1$.

Пакеты вейвлетов: узел $(j,n)$ — произведение $H_0/H_1$ по битам пути; **частотный порядок — код Грея**, а не естественный (Пэли), потому что $\downarrow2$ после ФВЧ зеркалит спектр.

**Проверка.** Энергия $\|h^{eq}_j\|^2=1$ (ортогональные); прямое многоуровневое DWT единичного импульса даёт те же ИХ.

### 8.9. Спектры φ и ψ {#freq-phi-psi-spectra}

$\Phi(\omega)=\prod_{j=1}^{\infty}m_0(\omega/2^j)$, $m_0=H(e^{i\omega})/H(1)$ ($H=f_0$ для $\varphi$; обращённый $h_0$ для $\tilde\varphi$, у модуля обращение не сказывается); усечение после $J$ множителей, когда $2^{-J}|\omega|$ мал ($J=20..30$); $\Psi(\omega)=m_1(\omega/2)\Phi(\omega/2)$, $m_1=F_1/\sqrt2$ (при $m_0=F_0/\sqrt2$).

Что видно: $|\Phi|$ — ФНЧ с нулями порядка $N$ в $2\pi k$, $k\ne0$ (Стрэнг–Фикс), на ЛАЧХ — глубокие провалы; $|\Psi|$ — полосовая, пик в октаве $[\pi,2\pi]$. Плоскость $|m_0|$ в $\pi$ (нуль порядка $N$) $\leftrightarrow|\Psi(\omega)|\sim|\omega|^{\tilde N}$ у нуля: на log–log графике наклон $20\tilde N$ дБ/декаду — наглядный «счётчик нулевых моментов» ($\tilde N$ — нули в $\pi$ двойственного ФНЧ).

**Проверка.** $\sum_k|\Phi(\omega+2\pi k)|^2=1$ (ортогональные, усечённая сумма); $\sum_{j\in\mathbb Z}|\Psi(2^j\omega)|^2=1$ при $\omega\neq0$ (следует из $|m_0|^2+|m_1|^2=1$ и телескопирования).

### 8.10. Частотно-временное разбиение: прямоугольники Гейзенберга {#freq-heisenberg}

Для атома $g$, $\|g\|=1$: $\bar t=\int t|g|^2$, $\sigma_t^2=\int(t-\bar t)^2|g|^2$, $\sigma_\omega^2=\frac1{2\pi}\int(\omega-\bar\omega)^2|\hat g|^2$ (для вещественных атомов — по положительным частотам, иначе $\bar\omega=0$); $\sigma_t\sigma_\omega\ge\tfrac12$, равенство — у гауссианы. Дискретный вариант для приложения — по эквивалентным фильтрам: $\bar n,\sigma_n$ по $|h|^2$, $\bar\omega,\sigma_\omega$ по $|H|^2$ на $[0,\pi]$. Точной границы $\tfrac12$ для конечных последовательностей нет — величины описательные.

Разбиения: STFT — одинаковые прямоугольники на всех частотах; DWT — $\sigma_t\propto2^j$, $\sigma_\omega\propto2^{-j}$, один коэффициент на $2^j$ отсчётов; пакеты — любое допустимое двоичное разбиение (выбирает лучший базис). У непрерывного $\psi$ Хаара $\sigma_\omega=\infty$ ($|\Psi|\sim1/\omega$) — наглядная иллюстрация плохой частотной локализации; поэтому — дискретные $\sigma$ на $[0,\pi]$. Прямоугольник рисуется с центром $(k2^j,\bar\omega_j)$ и размерами $2\sigma_t\times2\sigma_\omega$.

### 8.11. Характеристика всей цепочки анализ → синтез {#freq-full-chain}

**Один уровень.** Графики, доказывающие PR: $|T(e^{i\omega})|\equiv1$ (0 дБ), $\arg T=-\ell\omega$, ГВЗ $T$ постоянна и равна $\ell$, $|A|\equiv0$ (численно ниже $-250$ дБ в double).

**$J$ уровней.** $\hat X(z)=\sum_{k=0}^{2^J-1}A_k(z)X(zW^k)$, $W=e^{-2\pi i/2^J}$,
$$A_k(z)=\sum_{i:\ (2^J/M_i)\mid k}\frac1{M_i}F^{eq}_i(z)H^{eq}_i(zW^k),$$
где $M_i$ — прореживание поддиапазона $i$ ($2^j$ для деталей уровня $j$, $2^J$ для аппроксимации). PR: $A_0=z^{-\ell_J}$, $A_k=0$ при $k\ne0$. Показывать $|A_0|$ и $\max_k|A_k|$ (или каждую $A_k$). С коэффициентами усиления $g_i$ (обнуление, эквалайзер): $A^{(g)}_k=\sum_i\frac{g_i}{M_i}F^{eq}_iH^{eq}_i(zW^k)$ — график показывает наложение, созданное редактированием (энергия наложения — §14.6).

**Нестационарность.** При изменённых $g_i$ система периодически нестационарна с периодом $2^J$: показать $2^J$ импульсных откликов (импульс в фазах $0..2^J-1$) — их различие и есть наложение.

**Проверка.** Теоретические $A_k$ совпадают с измеренными: отклики цепочки на $\delta[n-m]$, $m=0..2^J-1$, связаны с $A_k$ через DFT по фазе.

## 9. Классические частотно-избирательные фильтры [v1] {#classic}

### 9.1. Виды фильтров и спецификация {#cls-types}

ФНЧ (нижних частот), ФВЧ (верхних), ПФ (полосовой), РФ (режекторный, заграждающий), узкополосный режекторный (notch), фазовый (всепропускающий, all-pass). КИХ (FIR) и БИХ (IIR). Спецификация: края $\omega_p,\omega_s$, допуски $\delta_p,\delta_s$ (или пульсации $A_p$ дБ и ослабление $A_s$ дБ).

### 9.2. КИХ с линейной фазой: что реализует каждый тип {#cls-fir-types}

| тип | ФНЧ | ФВЧ | ПФ | РФ | дифференциатор / Гильберт |
|---|---|---|---|---|---|
| I | да | да | да | да | нет / нет |
| II | да | нет ($H(\pi)=0$) | да | нет | нет / нет |
| III | нет | нет ($H(0)=H(\pi)=0$) | да | нет | да / да |
| IV | нет ($H(0)=0$) | да | да | нет | да / да |

### 9.3. Метод окон и окно Кайзера {#cls-window-method}

**Формулы.** Идеальный ФНЧ, сдвинутый в $M/2$: $h_d[n]=\dfrac{\sin\omega_c(n-M/2)}{\pi(n-M/2)}$ (при $n=M/2$ — $\omega_c/\pi$), $h=h_dw$, $\omega_c=(\omega_p+\omega_s)/2$. Окна ($n=0..M$): прямоугольное; Ханна $0{,}5-0{,}5\cos\frac{2\pi n}M$; Хэмминга $0{,}54-0{,}46\cos\frac{2\pi n}M$; Блэкмана $0{,}42-0{,}5\cos\frac{2\pi n}M+0{,}08\cos\frac{4\pi n}M$.

| окно | боковой лепесток | ширина главного лепестка | ошибка фильтра | $\beta$ эквив. Кайзера | переход эквив. Кайзера |
|---|---|---|---|---|---|
| прямоугольное | −13 дБ | $4\pi/(M+1)$ | −21 дБ | 0 | $1{,}81\pi/M$ |
| Ханна | −31 дБ | $8\pi/M$ | −44 дБ | 3,86 | $5{,}01\pi/M$ |
| Хэмминга | −41 дБ | $8\pi/M$ | −53 дБ | 4,86 | $6{,}27\pi/M$ |
| Блэкмана | −57 дБ | $12\pi/M$ | −74 дБ | 7,04 | $9{,}19\pi/M$ |

(Oppenheim–Schafer.) **Кайзер:** $w[n]=I_0\big(\beta\sqrt{1-((n-M/2)/(M/2))^2}\big)/I_0(\beta)$; при $A=-20\lg\delta$, $\delta=\min(\delta_p,\delta_s)$:
$$\beta=\begin{cases}0{,}1102(A-8{,}7),&A>50\\0{,}5842(A-21)^{0{,}4}+0{,}07886(A-21),&21\le A\le50\\0,&A<21\end{cases}\qquad M=\frac{A-8}{2{,}285\,\Delta\omega}.$$
Метод окон даёт $\delta_p\approx\delta_s$. $I_0$ — степенной ряд (около 30 членов при $\beta\le20$).

**Проверка.** Измеренные ослабление и переход согласуются с формулами; симметрия коэффициентов.

### 9.4. Частотная выборка {#cls-frequency-sampling}

Задать $A(\omega_k)$ в $\omega_k=2\pi k/L$ (с линейной фазой), обратное DFT; 1–3 переходных отсчёта оптимизируются для уменьшения пульсаций. Точное совпадение в узлах, пульсации между ними. Дёшево, уступает оптимальным методам; удобно для произвольных кривых (эквалайзер).

### 9.5. Метод наименьших квадратов {#cls-least-squares}

Минимизировать $\int_{\text{полосы}}W(\omega)(A(\omega)-D(\omega))^2d\omega$, $A(\omega)=\sum_{k=0}^Ka_k\cos k\omega$ (тип I, $M=2K$). Нормальные уравнения $Qa=b$:
$$Q_{kl}=\int W\cos k\omega\cos l\omega\,d\omega=\tfrac12\int W\big[\cos(k-l)\omega+\cos(k+l)\omega\big]d\omega,\quad b_k=\int WD\cos k\omega\,d\omega$$
— «тёплиц + Ганкель» (§2.4); интегралы в замкнутой форме для кусочно-постоянных $W,D$; решать Холецким ($Q$ SPD). Минимизирует энергию ошибки: суммарная ошибка меньше, чем у равноволнового, но всплески у краёв полос.

### 9.6. Паркс–Макклеллан (Ремез, равноволновой) {#cls-parks-mcclellan}

Минимизировать $\max_\omega W(\omega)|A(\omega)-D(\omega)|$. Теорема об альтернансе: $A$ (тип I, $K+1$ коэффициент) оптимальна $\iff$ ошибка имеет не менее $K+2$ чередующихся экстремумов. Алгоритм Ремеза: начальные $K+2$ частоты → решение для $a$ и $\delta$ (барицентрическая интерполяция Лагранжа) → новые экстремумы на плотной сетке ($\ge16(K+1)$ точек) → повтор до стабилизации. Оценка длины (Кайзер): $M\approx\dfrac{-10\lg(\delta_p\delta_s)-13}{2{,}324\,\Delta\omega}$. Веса: $W=1$ в полосе пропускания, $\delta_p/\delta_s$ в задерживании. Ловушки: несходимость для очень длинных фильтров и широких «безразличных» зон, немонотонные переходные полосы в многополосных задачах — проверять число альтернансов.

Для банков: при $\omega_p+\omega_s=\pi$ и $\delta_p=\delta_s$ оптимальный фильтр получается полуполосным (приём Vaidyanathan–Nguyen); подъём центрального отвода на $\delta_s$ делает $P\ge0$ на окружности, после чего спектральная факторизация даёт ортогональный банк с крутыми срезами, но с одним нулём в $\pi$ (процедура Smith–Barnwell) [v2].

### 9.7. ФВЧ, ПФ, РФ из прототипа ФНЧ {#cls-transformations}

- **Спектральная инверсия** (только тип I, $M$ чётно): $h_{\text{ФВЧ}}[n]=\delta[n-M/2]-h_{\text{ФНЧ}}[n]$, $A_{\text{ФВЧ}}=1-A_{\text{ФНЧ}}$.
- **Модуляция:** $h_{\text{ФВЧ}}[n]=(-1)^nh_{\text{ФНЧ}}[n]$, $H_{\text{ФВЧ}}(\omega)=H_{\text{ФНЧ}}(\omega-\pi)$ — зеркало относительно $\pi/2$, $\omega_c\to\pi-\omega_c$; работает для всех типов (II → IV). Это и есть связь $H_1(z)=\pm F_0(-z)$ в банках.
- **ПФ:** $h_{\text{ПФ}}[n]=2\cos(\omega_0(n-M/2))\,h_{\text{ФНЧ}}[n]$ — сдвиг в $\pm\omega_0$, ширина полосы $2\omega_c$; или разность двух ФНЧ одной длины и с одним окном.
- **РФ:** $h_{\text{РФ}}[n]=\delta[n-M/2]-h_{\text{ПФ}}[n]$ (тип I).

### 9.8. Фазовые (all-pass) и режекторные (notch) {#cls-allpass-notch}

Фазовый первого порядка: $A(z)=\dfrac{-a+z^{-1}}{1-az^{-1}}$, $|a|<1$, $|A(e^{i\omega})|=1$; комплексные пары — секциями второго порядка. Применения: выравнивание фазы, дробная задержка, пары Гильберта, БИХ-полуполосные из фазовых: $H_0=\tfrac12[A_0(z^2)+z^{-1}A_1(z^2)]$ — степенно-комплементарный БИХ-банк [v2].

Режекторный: $H(z)=\dfrac{1-2\cos\omega_0z^{-1}+z^{-2}}{1-2r\cos\omega_0z^{-1}+r^2z^{-2}}$, ширина по $-3$ дБ $\approx2(1-r)$ рад; эквивалентно $\tfrac12(1+A_2(z))$ с фазовым второго порядка. Пример — фон 50 Гц. КИХ-режекторный (только нули на окружности) получается широким.

### 9.9. Аналоговые прототипы БИХ {#cls-iir-prototypes}

- **Баттерворт:** $|H(j\Omega)|^2=1/(1+(\Omega/\Omega_c)^{2N})$; максимально плоский в $0$; полюса равномерно на окружности радиуса $\Omega_c$ в левой полуплоскости; $N\ge\dfrac{\lg\big[(10^{A_s/10}-1)/(10^{A_p/10}-1)\big]}{2\lg(\Omega_s/\Omega_p)}$.
- **Чебышёв I:** $1/(1+\varepsilon^2T_N^2(\Omega/\Omega_p))$ — равноволновая полоса пропускания (пульсации $10\lg(1+\varepsilon^2)$ дБ), монотонное задерживание, полюса на эллипсе; $N\ge\dfrac{\operatorname{arcch}\sqrt{(10^{A_s/10}-1)/(10^{A_p/10}-1)}}{\operatorname{arcch}(\Omega_s/\Omega_p)}$.
- **Чебышёв II:** $1/\big(1+1/(\varepsilon^2T_N^2(\Omega_s/\Omega))\big)$ — плоская полоса пропускания, равноволновое задерживание, нули на мнимой оси.
- **Эллиптический (Кауэр):** равноволновой в обеих полосах, минимальный порядок для заданной спецификации; эллиптические функции Якоби.
- **Бессель:** максимально плоская ГВЗ в $0$ (обратные многочлены Бесселя), хорошая переходная характеристика; плоскость ГВЗ разрушается деформацией билинейного преобразования (использовать с передискретизацией или проектировать цифровую плоскую задержку напрямую).

### 9.10. Аналог → цифра: билинейное преобразование и инвариантность ИХ {#cls-bilinear}

**Билинейное:** $s=\frac2T\frac{1-z^{-1}}{1+z^{-1}}$; мнимая ось переходит в окружность с деформацией $\Omega=\frac2T\tan\frac\omega2$; левая полуплоскость — внутрь круга (устойчивость сохраняется); наложения нет. **Предыскажение:** $\Omega_c=\frac2T\tan\frac{\omega_c}2$ для всех критических частот до расчёта прототипа ($T$ сокращается). **Инвариантность ИХ:** $h[n]=Th_a(nT)$, $s_k\to e^{s_kT}$, $H(e^{i\omega})=\sum_kH_a\big(j(\omega-2\pi k)/T\big)$ — с наложением; годится только для хорошо ограниченных ФНЧ/ПФ, непригодна для ФВЧ/РФ. Преобразования ФНЧ → ФВЧ/ПФ/РФ — в аналоговой области ($s\to\Omega_c/s$, $s\to(s^2+\Omega_0^2)/(Bs)$) или цифровыми фазовыми подстановками (Константинидис).

### 9.11. Реализация: биквадратные секции, устойчивость {#cls-biquads}

$H(z)=g\prod_k\dfrac{b_{0k}+b_{1k}z^{-1}+b_{2k}z^{-2}}{1+a_{1k}z^{-1}+a_{2k}z^{-2}}$: каждой паре полюсов — ближайшая пара нулей, секции упорядочены по радиусу полюсов, усиление распределено; транспонированная прямая форма II. Высокий порядок одним многочленом не реализовывать: чувствительность полюса $\partial p_i/\partial a_k\sim1/\prod_{j\ne i}(p_i-p_j)$ взрывается при скоплении полюсов (узкополосный ФНЧ — полюса у $z=1$). Устойчивость: все $|p_k|<1$; для секции $1+a_1z^{-1}+a_2z^{-2}$ — треугольник $|a_2|<1$, $|a_1|<1+a_2$. Проверять после квантования коэффициентов (float32).

### 9.12. Нуль-фазовая фильтрация вперёд–назад {#cls-filtfilt}

$y=R\big(h*R(h*x)\big)$, $R$ — обращение времени: характеристика $|H(e^{i\omega})|^2$, нулевая фаза, ослабление в дБ удваивается; некаузально (офлайн). Краевые переходные процессы: продолжение сигнала (нечётное отражение порядка $3\times$ порядка фильтра) и начальные условия установившегося режима (как в `scipy.signal.filtfilt`). Для линейно-фазового КИХ нулевая фаза — просто сдвиг на $M/2$.

### 9.13. Связь с вейвлетными банками {#cls-wavelet-relation}

1. Двухканальный банк — комплементарная пара ФНЧ/ФВЧ вокруг $\pi/2$; ортогональный: $|H_0|^2+|H_1|^2=2$, $-3$ дБ ровно на $\pi/2$; QMF-зеркальность $|H_1(\omega)|=|H_0(\pi-\omega)|$ — модуляция §9.7.
2. Максимально плоский фильтр Daubechies — КИХ-аналог Баттерворта (плоский в $0$ и $\pi$, без пульсаций, широкий переход); более крутые банки — равноволновые полуполосные + факторизация, ценой нулевых моментов.
3. Почему КИХ: точное PR с КИХ-обратным ($\det$ — одночлен), конечный носитель (компактные вейвлеты), возможна линейная фаза (биортогональные), безусловная устойчивость, точные конечные матрицы. БИХ-ортогональные банки существуют (на фазовых звеньях, на основе Баттерворта), но синтез некаузален или бесконечен, а края сложнее [v2 / исследовательское].
4. Поддиапазон вейвлета — плохой полосовой фильтр (переходы перекрываются, §8.8). Для частотно-избирательного эквалайзера нужны классические КИХ/БИХ или STFT; приложение показывает оба подхода рядом.

## 10. Лифтинг [v1] {#lifting}

### 10.1. Многочлены Лорана и алгоритм Евклида {#lift-euclid}

Степень $|p|$ = (наибольший показатель − наименьший). Деление $p=qd+r$ с $|r|<|d|$ **неединственно** (можно сокращать члены с любого конца). НОД по Евклиду: $a_0=a$, $b_0=b$; $a_{i+1}=b_i$, $b_{i+1}=a_i\bmod b_i$ до $b_n=0$; $a_n$ — НОД с точностью до одночлена $cz^k$.

### 10.2. Факторизация Daubechies–Sweldens {#lift-factorisation}

**Теорема.** Полифазная матрица КИХ-фильтров с $\det=1$ раскладывается как
$$H_p(z)=\begin{pmatrix}K&0\\0&1/K\end{pmatrix}\prod_{i=1}^{m}\begin{pmatrix}1&U_i(z)\\0&1\end{pmatrix}\begin{pmatrix}1&0\\-P_i(z)&1\end{pmatrix}.$$
Доказательство — Евклид по полифазным компонентам ФНЧ (взаимно просты, так как $\det=1$) и один завершающий шаг для ФВЧ. Если $\det H_p=cz^{-k}$, сначала нормировать: ФВЧ умножить на $z^k/c$. Разложение не единственно — выбирать с короткими и малыми по модулю коэффициентами шагами.

**Алгоритм анализа** (наша запись §0.5, строки — $s,d$): ленивое разбиение $x^{(0)},x^{(1)}$; предсказание $d=x^{(1)}-P(z)x^{(0)}$; обновление $s=x^{(0)}+U(z)d$; масштаб $s\leftarrow Ks$, $d\leftarrow d/K$. Синтез — шаги в обратном порядке с обратными знаками; обратимость не зависит от того, что именно вычисляют $P$ и $U$ (в том числе с округлением).

**Проверка.** Перемножение множителей восстанавливает $H_p$; $\det=1$.

### 10.3. LeGall 5/3 и целочисленная версия {#lift-53}

$$d[n]=x[2n+1]-\tfrac12\big(x[2n]+x[2n+2]\big),\qquad s[n]=x[2n]+\tfrac14\big(d[n-1]+d[n]\big).$$
Эквивалентный ФНЧ $(-1,2,6,2,-1)/8$ (центр в $2n$), ФВЧ $(-\tfrac12,1,-\tfrac12)$ (центр в $2n+1$) — суммирующая нормировка, $K=1$; $P(z)=\tfrac12(1+z)$, $U(z)=\tfrac14(1+z^{-1})$. При $K=\sqrt2$ — `bior2.2` с точностью до знака и сдвига.

**Целочисленная (JPEG 2000, без потерь):** $d[n]=x[2n+1]-\lfloor(x[2n]+x[2n+2])/2\rfloor$, $s[n]=x[2n]+\lfloor(d[n-1]+d[n]+2)/4\rfloor$; обратно $x[2n]=s[n]-\lfloor(d[n-1]+d[n]+2)/4\rfloor$, $x[2n+1]=d[n]+\lfloor(x[2n]+x[2n+2])/2\rfloor$. Края — WS-зеркалирование индексов. Запас разрядности: детали требуют примерно одного дополнительного бита на уровень.

**Проверка.** Точный круговой проход для случайных int16/int32, включая крайние значения (тест переполнения); вещественная версия = свёрточная `bior2.2` с поправкой нормировки.

### 10.4. CDF 9/7 {#lift-97}

$$\begin{aligned}d&\leftarrow d+\alpha(s_n+s_{n+1}),& s&\leftarrow s+\beta(d_{n-1}+d_n),\\ d&\leftarrow d+\gamma(s_n+s_{n+1}),& s&\leftarrow s+\delta(d_{n-1}+d_n),\\ s&\leftarrow\zeta s,& d&\leftarrow d/\zeta,\end{aligned}$$
$\alpha=-1{,}586134342$, $\beta=-0{,}05298011854$, $\gamma=0{,}8829110762$, $\delta=0{,}4435068522$, $\zeta=1{,}149604398$ (Daubechies–Sweldens 1998). Проверено: эквивалентный ФНЧ этих шагов совпадает с `bior4.4.dec_lo` до 9 знаков (сумма $\sqrt2$), ФВЧ $=-$`dec_hi`. JPEG 2000 масштабирует полосы иначе, поэтому её $K$ отличается нормировкой. Опубликованные 10-значные константы дают отклонение $\sim3\cdot10^{-10}$ (проверено) — для полной точности double их нужно вычислить из фильтра алгоритмом Евклида.

### 10.5. Выгоды и ловушки {#lift-benefits}

Выгоды: работа на месте (чётные и нечётные в одном массиве); асимптотически примерно вдвое меньше умножений для длинных фильтров (Daubechies–Sweldens); целочисленные обратимые преобразования (Calderbank–Daubechies–Sweldens–Yeo 1998) — округление внутри шагов не нарушает обратимости; симметричные края тривиальны (§6.6); удобно для SIMD. Ловушки: последовательная зависимость шагов (меньше параллелизма на шаг); для Хаара выигрыша нет; округление отличается от свёрточного (оба $\sim u$); большие коэффициенты шагов ($|\alpha|\approx1{,}59$) немного усиливают ошибки — разные факторизации одного банка численно неравноценны; целочисленный лифтинг нелинеен, частотный анализ для него приближённый.

**Проверка.** Лифтинг = свёртка на случайных сигналах (периодические и симметричные края) до $10^{-14}$.

### 10.6. Вейвлеты второго поколения {#lift-second-generation}

Лифтинг без трансляционной и масштабной инвариантности (Sweldens): неравномерные отсчёты, интервалы, взвешенные меры, графы; предсказание — интерполяционный многочлен по соседям, обновление сохраняет моменты. Конструирование новых вейвлетов из ленивого: предсказание $N$-точечной интерполяцией Деслорье–Дюбюка (факторизация 1/7 из §4.8 — ровно предсказание без обновления по 4 точкам), затем обновление для $\tilde N$ двойственных моментов [исследовательское].

## 11. Варианты преобразований {#transforms}

### 11.1. DWT, пирамида Малла [ядро] {#dwt-mallat}

**Алгоритм.** $a_0=x$; $a_j=\downarrow2(h_0*a_{j-1})$, $d_j=\downarrow2(h_1*a_{j-1})$, $j=1..J$; синтез в обратном порядке. Стоимость $\sum_j(N/2^j)(L_0+L_1)\approx N(L_0+L_1)$ умножений, память $O(N)$; максимум уровней $\lfloor\log_2(N/(L-1))\rfloor$; раскладка $[a_J,d_J,\dots,d_1]$. **Нет инвариантности к сдвигу:** сдвиг входа на 1 отсчёт сильно перераспределяет энергию между уровнями — показывать в приложении.

**Проверка.** PR по всем режимам; совпадение с `pywt.wavedec/waverec`; Парсеваль для ортогональных с периодизацией.

### 11.2. SWT / à trous / MODWT [v1] {#swt-modwt}

**SWT.** Без прореживания; фильтры уровня $j$ разрежены: $h^{(j)}(z)=H(z^{2^{j-1}})$; $a_j=h_0^{(j)}*a_{j-1}$, $d_j=h_1^{(j)}*a_{j-1}$; избыточность $J+1$; стоимость $O(NLJ)$; эквивариантность к (круговому) сдвигу. Обратное: $a_{j-1}=\tfrac12\big(f_0^{(j)}*a_j+f_1^{(j)}*d_j\big)$ с выравниванием задержки $\ell\cdot2^{j-1}$ на каждом уровне. pywt `swt` — периодическое продолжение, $2^J\mid N$. SWT = DWT всех $2^J$ круговых сдвигов, организованное без повторов.

**MODWT** (Percival–Walden 2000): фильтры $\tilde h=h/\sqrt2$, тогда $|\tilde H_0|^2+|\tilde H_1|^2=1$ и $\|x\|^2=\sum_j\|\tilde W_j\|^2+\|\tilde V_J\|^2$ точно; любая $N$. Для отображения коэффициенты сдвигаются на ГВЗ эквивалентного фильтра, чтобы совпасть с событиями во времени. **MRA-разложение** $x=\sum_jD_j+S_J$, $D_j$ — синтез одного уровня: аддитивно, каждая компонента — ЛИС-фильтрация; идеально для отображения и для обнуления поддиапазона без наложения.

**Проверка.** Энергетическое тождество MODWT; $\sum D_j+S_J=x$; эквивариантность к сдвигу.

### 11.3. Пакеты вейвлетов и лучший базис [v1] {#wavelet-packets}

Полное дерево глубины $J$: $2^J$ листьев по $N/2^J$; стоимость $O(NLJ)$. Порядок: естественный (Пэли) или частотный (код Грея — `order='freq'` в pywt), см. §8.8. **Лучший базис** (Coifman–Wickerhauser 1992): аддитивная стоимость $\mathcal M(c)=\sum_k\mu(|c_k|)$, $\mu(0)=0$: энтропийная $-\sum c_k^2\log c_k^2$ (с $0\log0=0$, нормировать на $\|x\|^2$), лог-энергия $\sum\log c_k^2$ (защита от нулей), $\ell^p$ ($\sum|c_k|^p$, $p<2$), счётчик порога $\#\{|c_k|>\varepsilon\}$. Снизу вверх: узел заменяется детьми, если $\mathcal M(\text{дети})<\mathcal M(\text{узел})$; $O(NJ)$ после построения дерева; оптимум среди всех допустимых базисов (их число растёт двукратно экспоненциально). Корректно для ортогональных банков (стоимости сравнимы между узлами), для биортогональных — приближённо.

**Проверка.** PR из любого допустимого базиса; найденный базис не хуже полного разложения и корня по стоимости; совпадение с перебором при $J\le4$.

### 11.4. M-канальные банки [v2] {#m-band}

$M$ каналов, $\downarrow M$; PR $\iff F_pE=z^{-k}I$ ($\det$ — одночлен для КИХ). Косинусно-модулированные банки (псевдо-QMF, MDCT/TDAC как перекрывающееся преобразование): $h_k[n]=2p[n]\cos\!\big(\tfrac\pi M(k+\tfrac12)(n-\tfrac{L-1}2)+(-1)^k\tfrac\pi4\big)$ — контекст MP3/AAC. M-канальные вейвлеты: одна $\varphi$, $M-1$ вейвлетов, растяжение $M$. Реализация на общем полифазном ядре.

### 11.5. Двухдревесное комплексное DWT (Kingsbury) [v2] {#dtcwt}

Два вещественных DWT-дерева $a,b$. Уровень 1 — два разных набора («почти симметричные» биортогональные) или один набор со сдвигом на отсчёт. Уровни $\ge2$ — q-shift-фильтры: $h_b[n]=h_a[L-1-n]$, где $h_a$ имеет ГВЗ $\approx\tfrac14$ отсчёта, поэтому деревья расходятся на $\tfrac12$ отсчёта на каждом уровне, $\psi_b\approx\mathcal H\{\psi_a\}$ (преобразование Гильберта), $\psi_a+i\psi_b$ почти аналитичен. Избыточность 2 (1D), приближённая инвариантность к сдвигу, наложение между соседними уровнями сильно подавлено. Для звука — гладкие огибающие поддиапазонов, детекция атак, редактирование поддиапазонов с меньшим наложением. Нужны таблицы Kingsbury (near_sym_a/b, qshift_a…d, как в Python-пакете `dtcwt`).

**Проверка.** PR каждого дерева; разность ГВЗ эквивалентных фильтров $\approx\tfrac12$ отсчёта входного уровня; метрика инвариантности: вариация энергии уровня $j$ при сдвигах $0..2^j-1$ — единицы процентов против больших значений у DWT.

### 11.6. Непрерывное вейвлет-преобразование (CWT) [v1] {#cwt}

**Определение.** $W(a,b)=\frac1{\sqrt a}\int x(t)\psi^*\big(\tfrac{t-b}a\big)dt$ ($L^2$-нормировка: одинаковая энергия по масштабам) или $\frac1a\int\cdots$ ($L^1$: синусоида амплитуды $A$ даёт $|W|$, не зависящий от масштаба, — удобнее для звука). Допустимость $C_\psi=\int_0^\infty|\Psi(\omega)|^2\frac{d\omega}\omega<\infty$ ($\Rightarrow\Psi(0)=0$); обращение $x=\frac1{C_\psi}\iint W\psi_{a,b}\frac{da\,db}{a^2}$; формула Морле с одним интегралом: $x(t)=\operatorname{Re}\frac1{C'_\psi}\int W(a,t)a^{-3/2}da$, $C'_\psi=\int_0^\infty\Psi^*(\omega)\frac{d\omega}\omega$.

**Вейвлеты** (Torrence–Compo 1998, табл. 1; $\mathcal H$ — функция Хевисайда):

| вейвлет | $\psi(t)$ | $\Psi(s\omega)$ | длина волны Фурье $\lambda$ | время e-спада |
|---|---|---|---|---|
| Морле, $\omega_0$ | $\pi^{-1/4}e^{i\omega_0t}e^{-t^2/2}$ | $\pi^{-1/4}\mathcal H(\omega)e^{-(s\omega-\omega_0)^2/2}$ | $\frac{4\pi s}{\omega_0+\sqrt{2+\omega_0^2}}$ ($1{,}033s$ при $\omega_0=6$) | $\sqrt2s$ |
| Пол, $m$ | $\frac{2^mi^mm!}{\sqrt{\pi(2m)!}}(1-it)^{-(m+1)}$ | $\frac{2^m}{\sqrt{m(2m-1)!}}\mathcal H(\omega)(s\omega)^me^{-s\omega}$ | $\frac{4\pi s}{2m+1}$ | $s/\sqrt2$ |
| DoG, $m$ | $\frac{(-1)^{m+1}}{\sqrt{\Gamma(m+1/2)}}\frac{d^m}{dt^m}e^{-t^2/2}$ | $-\frac{i^m}{\sqrt{\Gamma(m+1/2)}}(s\omega)^me^{-(s\omega)^2/2}$ | $\frac{2\pi s}{\sqrt{m+1/2}}$ | $\sqrt2s$ |

«Мексиканская шляпа» — DoG при $m=2$: $\psi=\frac2{\sqrt3\pi^{1/4}}(1-t^2)e^{-t^2/2}$. Морле при $\omega_0=6$ допустим лишь приближённо (остаток $\sim e^{-\omega_0^2/2}$); строго допустимый вариант: $\pi^{-1/4}(e^{i\omega_0t}-e^{-\omega_0^2/2})e^{-t^2/2}$.

**Алгоритм через FFT** (T&C, ур. 4): $X_k=\text{DFT}(x)$, $\omega_k=\pm2\pi k/(N\delta t)$; $W_n(s)=\sum_kX_k\Psi^*(s\omega_k)e^{i\omega_kn\delta t}$ с нормировкой $\Psi\leftarrow\sqrt{2\pi s/\delta t}\,\Psi_0$. Один FFT входа и один IFFT на масштаб: $O(N_sN\log N)$. Масштабы $s_j=s_02^{j\,\delta j}$, $s_0\approx2\delta t$; для звука $\delta j=1/12..1/48$ (голоса на октаву). Дополнение до степени двойки $\ge2N$ против кругового заворота. **Конус влияния** (COI): зона $|b-\text{край}|<\tau_s(a)$ искажена краями — штриховать. Масштаб ↔ частота: $f=1/\lambda(s)$. Приближённое обращение (T&C, ур. 11): $x_n=\frac{\delta j\,\delta t^{1/2}}{C_\delta\,\psi_0(0)}\sum_j\frac{\operatorname{Re}W_n(s_j)}{s_j^{1/2}}$, $C_\delta=0{,}776$ для Морле с $\omega_0=6$, $\psi_0(0)=\pi^{-1/4}$.

**Ловушки.** Недопустимость Морле при малых $\omega_0$; аналитические вейвлеты требуют одностороннего $\Psi$ (комплексный $W$, модуль — огибающая); наложение на малых масштабах ($\Psi(s\omega)$ не мал у Найквиста); память: 10 с при 44,1 кГц × 200 масштабов × 16 байт $\approx1{,}4$ ГБ — считать по видимому окну и прореживать по времени для отображения.

**Проверка.** Синусоида даёт гребень на $s$ с $1/\lambda(s)=f$; обращение с относительной ошибкой в единицы процентов; энергия масштабов белого шума ровная при $L^2$-нормировке.

### 11.7. Синхросжатие [v2] {#synchrosqueezing}

(Daubechies–Lu–Wu 2011.) Для аналитического $\psi$ мгновенная угловая частота $\omega_x(a,b)=\operatorname{Re}\big(-i\,\partial_bW_x/W_x\big)$ при $|W_x|>\gamma$ (в Гц — делить на $2\pi$); $\partial_bW$ вычисляется тем же FFT с $\Psi$, умноженным на $i\omega$ (один дополнительный IFFT на масштаб). Перераспределение: $T_x(\omega_l,b)=\sum_{a_k:|\omega_x(a_k,b)-\omega_l|\le\Delta\omega/2}W_x(a_k,b)a_k^{-3/2}\Delta a_k$. Восстановление моды в полосе: $x(b)\approx\operatorname{Re}\big[C_\psi^{-1}\sum_{l\in\text{полоса}}T_x(\omega_l,b)\Delta\omega\big]$, $C_\psi=\tfrac12\int_0^\infty\Psi^*(\xi)\frac{d\xi}\xi$. Резкая локализация AM–FM компонент при сохранении обратимости; порог $\gamma$ (несколько $\sigma$ шума) критичен.

**Проверка.** На ЛЧМ-сигнале гребень следует истинной мгновенной частоте; ошибка восстановления.

### 11.8. Вейвлет-рассеяние (Mallat) [исследовательское] {#scattering}

$S_0x=x*\phi_J$, $S_1x(\lambda_1)=|x*\psi_{\lambda_1}|*\phi_J$, $S_2x(\lambda_1,\lambda_2)=\big||x*\psi_{\lambda_1}|*\psi_{\lambda_2}\big|*\phi_J$ ($\lambda_2$ грубее $\lambda_1$): инвариантность к сдвигам до $2^J$, липшицева устойчивость к малым деформациям, сохранение энергии по порядкам. Для звука — банк Морле с $Q\approx8..16$ на первом порядке и $Q=1$ на втором; $S_1$ близко к мел-спектрограмме. Реализация на FFT-банках из CWT.

### 11.9. STFT / Габор для сравнения [v1] {#stft}

$X(m,k)=\sum_nx[n]w[n-mR]e^{-2\pi ikn/K}$; разрешение задаётся длиной окна $N_w$: $\Delta t\approx N_w/f_s$, $\Delta f\sim f_s/N_w$ (с множителем ширины главного лепестка окна); гауссово окно минимизирует $\sigma_t\sigma_\omega=\tfrac12$. PR: условие COLA $\sum_mw[n-mR]=\text{const}$ для OLA-синтеза или WOLA $\sum_mw_a[n-mR]w_s[n-mR]=\text{const}$ (периодический Ханн с перекрытием 50 % удовлетворяет COLA, его корень — WOLA). STFT — равномерный модулированный банк с избыточностью $N_w/R$. Против DWT: равномерное разбиение против постоянной добротности; лучше для гармоник, хуже для низкочастотных транзиентов; DWT критически дискретизировано. Приложение показывает оба на одном сигнале.

**Проверка.** COLA для выбранной пары окно/шаг; PR STFT→ISTFT до $10^{-13}$.

## 12. Применения к звуку [v1 / v2] {#audio}

### 12.1. Шумоподавление [v1] {#audio-denoising}

**Модель.** $y=x+\sigma e$, $e$ — белый гауссов. Ортонормированное DWT сохраняет белизну шума с тем же $\sigma$.

**Оценка шума:** $\hat\sigma=\operatorname{median}(|d_1[k]|)/0{,}6745$ по самому мелкому уровню ($0{,}6745=\Phi^{-1}(3/4)$ — медиана $|N(0,1)|$); робастна к разреженному сигналу. Для биортогональных банков дисперсия шума уровня $j$ равна $\sigma^2\|h^{eq}_{1,j}\|^2$ — пороги масштабировать нормами. Для окрашенного шума — свой $\hat\sigma_j$ на каждом уровне.

**Пороги.**

- VisuShrink: $\lambda=\sigma\sqrt{2\ln N}$ — шум удаляется с высокой вероятностью, сигнал пересглаживается.
- SureShrink (Donoho–Johnstone 1995): на уровне $j$ (коэффициенты нормированы на $\sigma$) минимизировать $\mathrm{SURE}(\lambda)=N_j-2\#\{k:|y_k|\le\lambda\}+\sum_k\min(|y_k|,\lambda)^2$ по кандидатам $\lambda\in\{0\}\cup\{|y_k|:|y_k|\le\sqrt{2\ln N_j}\}$ (между узлами SURE возрастает, поэтому минимум — в узле), $O(N_j\log N_j)$ сортировкой и префиксными суммами; гибрид: при $s^2=(\sum y_k^2-N_j)/N_j\le(\log_2N_j)^{3/2}/\sqrt{N_j}$ брать универсальный порог.
- BayesShrink (Chang–Yu–Vetterli 2000): $\lambda=\sigma^2/\hat\sigma_X$, $\hat\sigma_X=\sqrt{\max(\hat\sigma_Y^2-\sigma^2,0)}$, $\hat\sigma_Y^2=\frac1{N_j}\sum y_k^2$; при $\hat\sigma_X=0$ — $\lambda=\max|y_k|$ (подавить полосу).

**Функции сжатия.** Жёсткая $\eta_H=y\,\mathbf 1\{|y|>\lambda\}$; мягкая $\eta_S=\operatorname{sign}(y)(|y|-\lambda)_+$; неотрицательная гаррота (Gao 1998) $\eta_G=(y-\lambda^2/y)\mathbf 1\{|y|>\lambda\}$; firm (Gao–Bruce 1997), $\lambda_1<\lambda_2$: $0$ при $|y|\le\lambda_1$, $\operatorname{sign}(y)\lambda_2\frac{|y|-\lambda_1}{\lambda_2-\lambda_1}$ при $\lambda_1<|y|\le\lambda_2$, $y$ при $|y|>\lambda_2$. Мягкая — непрерывна, но смещает большие коэффициенты на $\lambda$; жёсткая — меньше смещение, больше дисперсия и «музыкальный шум»; гаррота и firm — компромисс. Аппроксимацию $a_J$ обычно не трогают.

**Циклический сдвиг** (Coifman–Donoho 1995): $\hat x=\operatorname{avg}_sS_{-s}D(S_sy)$; по всем $N$ сдвигам — через SWT за $O(NLJ)$; устраняет псевдо-Гиббс у транзиентов; эквивалентно порогу в области SWT (с периодическими краями).

**Особенности звука.** Блочная обработка длинных файлов (кадры $2^k$ с перекрытием и сшивкой), музыкальный шум, пользовательский множитель порога $0{,}5..1$, сохранение атак.

**Проверка.** Тестовые сигналы Donoho–Johnstone (Blocks, Bumps, HeaviSine, Doppler) с известным $\sigma$: $\hat\sigma$ в пределах 5 % при $N=2^{14}$; прирост SNR; $\lambda=0$ — тождество; сверка с pywt / `skimage.restoration.denoise_wavelet` на одинаковых настройках.

### 12.2. Сжатие [v1 / v2] {#audio-compression}

Концентрация энергии; сохранение $k$ наибольших: для ортонормированных ошибка равна сумме квадратов отброшенных (наилучшее $k$-членное приближение по Парсевалю); для биортогональных ранжировать $|c|\cdot\|f^{eq}\|$ (нормы синтезирующих функций). Квантование с мёртвой зоной $q=\operatorname{sign}(c)\lfloor|c|/\Delta\rfloor$, восстановление $(q+\rho\operatorname{sign}q)\Delta$, $\rho\approx\tfrac12$; биты $\approx$ энтропия индексов; при высоких скоростях $D\approx\Delta^2/12$ на ненулевой коэффициент. Целочисленный 5/3 + энтропийный кодер — сжатие без потерь [v2]; психоакустические пороги — [исследовательское].

**Проверка.** Ошибка равна сумме отброшенных квадратов (ортонормированные) с точностью $10^{-12}$; кривая «скорость–искажение» монотонна.

### 12.3. Эквализация по полосам и обнуление поддиапазонов: почему появляется наложение [ядро] {#audio-subband-zeroing}

Это основная функция старого кода. При усилениях $g_j$ на поддиапазонах прореженного DWT система становится периодически нестационарной (§8.11). Для двух каналов, обнуляя детали:
$$\hat X=\tfrac12F_0(z)\big[H_0(z)X(z)+H_0(-z)X(-z)\big]:$$
член $\tfrac12F_0(z)H_0(-z)X(-z)$ больше не компенсируется. Его величина $\tfrac12|F_0(e^{i\omega})H_0(e^{i(\omega+\pi)})|$ максимальна в переходной полосе около $\pi/2$: у Хаара $\tfrac12|\sin\omega|$ ($-6$ дБ на $\pi/2$), у db8 намного меньше, но не ноль. На слух: содержимое у краёв полос отражается на зеркальные частоты (негармоничные тоны), результат зависит от положения сигнала по модулю $2^J$ (нестационарность), длинные фильтры синтеза дают предэхо и звон. Обнуление уровня $j$ создаёт наложение у краёв $\pi/2^j$ и $\pi/2^{j-1}$ с компонентами на частоте $2^j$.

**Как уменьшить.**

1. SWT/MODWT-MRA: $x=\sum_jD_j+S_J$, обнуление $D_j$ — ЛИС-фильтрация характеристикой $1-H^{\text{MRA}}_j(\omega)$; наложения нет, остаётся лишь широкий переход эквивалентного фильтра.
2. Пакеты вейвлетов с длинными (крутыми) фильтрами — db20/sym20: наложение уменьшается (не исчезает), полосы уже.
3. Плавные усиления (переход от 1 к 0 через соседние полосы) вместо жёсткого нуля.
4. DTCWT — наложение значительно подавлено.
5. Для чистого эквалайзера — классические фильтры (§9) или STFT.

**Проверка.** Энергия наложения (§14.6) для каждой стратегии; график $A^{(g)}_k$; для MRA-варианта наложение равно нулю с точностью округления.

### 12.4. Детекция транзиентов и атак [v1] {#audio-onsets}

Энергия мелких уровней $e_j[k]=d_j[k]^2$ (для временного разрешения — SWT) со сглаживанием; функция детекции $\mathrm{ODF}[n]=\sum_jw_j\max\big(0,\Delta\log(\varepsilon+E_j[n])\big)$ (однополупериодный поток лог-энергий полос); выбор пиков с адаптивным порогом (медиана $+\delta$) и минимальным интервалом. Модульные максимумы по масштабам (Mallat–Hwang): особенности дают линии максимумов, убывание $|W|\sim a^{\alpha+1/2}$ оценивает локальный показатель Гёльдера $\alpha$ (щелчок или ступенька).

**Проверка.** Синтетические щелчки и затухающие тоны — точность времени атаки до $\pm$ одного шага кадра; F-мера на размеченном наборе (позже).

### 12.5. Энергетические признаки по полосам [v1] {#audio-band-energy}

$E_j=\sum_kd_j[k]^2$; доли $E_j/\sum E$; лог-энергии; покадрово (например, 2048 отсчётов с шагом 512) — «вейвлетная спектрограмма»; для отображения делить на длину полосы (мощность на отсчёт). Для ортонормированного банка с периодизацией $\sum E_j+\|a_J\|^2=\|x\|^2$.

### 12.6. Стерео [v1] {#audio-stereo}

Поканально — одинаковые фильтры и уровни дают выровненные коэффициенты. Mid/side: $M=(L+R)/2$, $S=(L-R)/2$ (обратно $L=M+S$, $R=M-S$) или ортонормированно $(L\pm R)/\sqrt2$. Линейное преобразование коммутирует с вейвлетным, но не с порогом: $M$ и $S$ шумоподавлять отдельно (в $S$ шум часто доминирует); для коррелированного шума — совместный порог по $\sqrt{c_L^2+c_R^2}$; при обнулении поддиапазонов применять одну маску к обоим каналам, чтобы сохранить стереобазу. Форматы WAV (int16/24/float, перемежение) приводятся к double в $[-1,1)$.

## 13. Численные вопросы [ядро] {#numerics}

### 13.1. Форматы и точность {#num-formats}

float32: $u=2^{-24}\approx6\cdot10^{-8}$; float64: $u=2^{-53}\approx1{,}1\cdot10^{-16}$; x87 long double ($2^{-64}$) не переносим (нет на ARM и MSVC); эталоны — `__float128`, Boost.Multiprecision, MPFR. Рекомендация: double для обработки и проектирования; float32 — только буферы отображения и путь реального времени с документированной ошибкой.

### 13.2. Рост ошибки по уровням {#num-error-growth}

Одна свёртка: $|\mathrm{fl}(y)-y|\le\gamma_L\sum|h||x|$, $\gamma_L\approx Lu$. Уровень анализ + синтез добавляет $\approx cLu\|x\|\kappa$. Ортонормированные банки ошибки не усиливают: рост линейный по $J$ в худшем случае, $\sqrt J$ статистически. Биортогональные усиливают на нормы синтеза; число обусловленности многоуровневой матрицы — 2,0…3,2 (`bior2.2`, $J=1..7$), 1,3…1,5 (9/7), 4…50 (`bior3.1`, проверено). Ожидаемая ошибка PR в double — $10^{-15}..10^{-14}$ относительно при $J=10$ (ортогональные), в float32 — $\sim10^{-6}$. Допуск тестов: $100\,J\,L\,u\,\|x\|_\infty$.

Компенсированное (Кэхэн–Ноймайер) или попарное суммирование — для энергий (Парсеваль на $10^7$ отсчётов при наивной сумме даёт ошибку $\sim Nu$). FMA меняет результаты побитно между компиляторами и процессорами — тесты на допусках, а не на побитовом равенстве (кроме целочисленного лифтинга и точной рациональной арифметики). Денормализованные числа в затухающих БИХ — включать FTZ/DAZ в пути реального времени.

### 13.3. Точная арифметика как эталон {#num-exact-reference}

Рациональная арифметика (Boost.Multiprecision `cpp_rational` или GMP `mpq`) для фильтров с рациональными коэффициентами в суммирующей нормировке: Хаар, LeGall 5/3, сплайновые CDF (`bior1.x`, `2.x`, `3.x` — коэффициенты $B_p$ целые). При целом входе DWT/IDWT точны, восстановление обязано совпасть побитно; реализация в double сравнивается с этим эталоном с допуском. Иррациональные фильтры (dbN) — коэффициенты из спектральной факторизации в MPFR на 200–300 бит; для D4 возможна точная арифметика в $\mathbb Q(\sqrt3)$ (пары $a+b\sqrt3$).

### 13.4. Обусловленность биортогональных пар {#num-conditioning}

$\kappa(A)=\sup_\omega\sigma_{\max}(H_p)/\inf_\omega\sigma_{\min}(H_p)$ при нормировке $\sqrt2$ у обоих ФНЧ. Вычислено: Хаар и dbN — 1; `bior1.3` — 1,28; 9/7 — 1,32; `bior6.8` — 1,33; 5/3 — 2,0; `bior3.1` и `bior3.3` — 4,0; невейвлетные факторизации §4.8 — до 10,9. Шум квантованных коэффициентов в синтезе пропорционален $\|f^{eq}\|$ — важно для сжатия и шумоподавления.

### 13.5. Поиск корней для спектральной факторизации {#num-root-finding}

Собственные числа сопровождающей матрицы (LAPACK `dhseqr`, Eigen) обратно устойчивы для многочлена, но кратные и скученные корни получают ошибку $\sim u^{1/m}$. Меры: удалить известные корни ($-1$) точно; искать в переменной $y=\sin^2(\omega/2)$ (степень $p-1$); уточнять Ньютоном по исходному многочлену; или **Aberth–Ehrlich** — одновременная итерация
$$z_k\leftarrow z_k-\frac{w_k}{1-w_k\sum_{j\ne k}\frac1{z_k-z_j}},\qquad w_k=\frac{p(z_k)}{p'(z_k)},$$
кубическая сходимость, все корни сразу, без дефляции; начальные приближения на окружности радиуса из оценок Коши/Фудзивары (так работает MPSolve, с адаптивной точностью). Дефляция по одному корню накапливает ошибки; если она нужна — удалять корни в порядке возрастания модуля (прямая дефляция устойчива для малых корней) и уточнять каждый по исходному многочлену. После факторизации: собрать произведение (сопряжённые пары — вещественные квадратичные множители, перемножать в порядке возрастания модуля), сравнить с $P$ (относительно $10^{-13}$), перенормировать.

### 13.6. Детерминированность и производительность {#num-determinism}

SIMD-свёртки (AVX2/NEON) с фиксированным порядком накопления для воспроизводимости; библиотека FFT (pocketfft / FFTW / KissFFT) с кешированием планов; потоки — по каналам и уровням; без денормализованных чисел.

## 14. Метрики качества [ядро] {#metrics}

### 14.1. Ошибка восстановления {#met-reconstruction}

$e=x-\hat x$: $\max|e|$, $\mathrm{RMS}=\sqrt{\overline{e^2}}$, относительная $\|e\|_2/\|x\|_2$; для тестов точности — в единицах последнего разряда (ulp).

### 14.2. SNR, PSNR, SegSNR {#met-snr}

$\mathrm{SNR}=10\lg\frac{\sum x^2}{\sum e^2}$ дБ; $\mathrm{PSNR}=10\lg\frac{\text{peak}^2}{\mathrm{MSE}}$, peak $=1$ (float, полная шкала) или $32767$ (int16) — указывать явно; $\mathrm{SegSNR}=\frac1M\sum_m\operatorname{clamp}\big(10\lg\frac{\sum_{\text{кадр }m}x^2}{\sum_{\text{кадр }m}e^2},-10,35\big)$ дБ по кадрам 15–30 мс, тихие кадры пропускать. Для шумоподавления — прирост $\Delta\mathrm{SNR}$.

### 14.3. Парсеваль и границы Рисса {#met-parseval}

Ортонормированный банк с периодизацией: $\sum x^2=\sum_j\sum_kd_j[k]^2+\sum a_J^2$ с точностью округления (относительно $10^{-14}$ с компенсированным суммированием). Другие режимы границ — равенства нет. Биортогональные: $A\|x\|^2\le\sum|c|^2\le B\|x\|^2$ с границами из §6.4 — проверять неравенство.

### 14.4. Выигрыш кодирования {#met-coding-gain}

Для ортонормированного банка, долей полос $\alpha_k=N_k/N$ и дисперсий $\sigma_k^2$: $G=\dfrac{\sum_k\alpha_k\sigma_k^2}{\prod_k(\sigma_k^2)^{\alpha_k}}$ (отношение арифметического и геометрического средних). Эталон — AR(1), $\rho=0{,}95$: $\sigma_k^2=\frac1{2\pi}\int S_x(\omega)|H^{eq}_k(e^{i\omega})|^2d\omega$, $S_x=\sigma_w^2/|1-\rho e^{-i\omega}|^2$; предел $G_\infty=\sigma_x^2/\exp\big(\frac1{2\pi}\int\ln S_x\big)=1/(1-\rho^2)\approx10{,}1$ дБ. Показывать $G$ для каждого семейства и числа уровней.

### 14.5. Частотные проверки PR {#met-frequency-checks}

$\max_\omega\big||T(e^{i\omega})|-1\big|$ и $\max_\omega|A(e^{i\omega})|$ на сетке 8192 точек — ожидается $\le10^{-14}$; дефект степенной комплементарности для ортогональных; графики §8.

### 14.6. Энергия наложения и неинвариантность к сдвигу {#met-alias-energy}

Для изменённого банка: $E_{\text{alias}}=\dfrac{\sum_{k\ne0}\frac1{2\pi}\int|A_k|^2d\omega}{\frac1{2\pi}\int|A_0|^2d\omega}$ — для белого входа отношение мощности наложения к мощности ЛИС-части. Для конкретного входа: $\hat x_{\text{alias}}=\hat x-a_0*x$ ($a_0$ — ИХ $A_0$), энергия относительно $\|\hat x\|^2$ в дБ. Неинвариантность к сдвигу: $\max_s\|S_{-s}\Phi(S_sx)-\Phi(x)\|/\|\Phi(x)\|$.

### 14.7. Прочие {#met-other}

Логарифмическое спектральное расстояние (LSD), спектральная плоскостность; перцептивные метрики (PEAQ, ViSQOL) — [исследовательское].

## 15. Сводный план проверок [ядро] {#test-plan}

1. **Фильтры:** коэффициенты = pywt (после обрезки нулей, со смещением); число нулей в $-1$ точным делением; ортогональность $\sum h[n]h[n+2k]=\delta_k$; линейная фаза — симметрия и ГВЗ $M/2$; $-3$ дБ ортогонального ФНЧ ровно на $\pi/2$.
2. **PR банка:** $T=z^{-\ell}$, $A=0$ как многочлены; $\det H_p$ — одночлен; $F_pH_p=I$; таблица §4.8 полностью ($P_0$, $s$, $\kappa$, рост каскада).
3. **Матрицы:** $T_hx$ = свёртка; спектр циркулянта = FFT; спектр периодизованной матрицы анализа = SVD $H_p$ на сетке; $WW^{\mathsf T}=I$ для Хаара $N=8$ и для db3; DCT-II диагонализует HS «тёплиц + Ганкель».
4. **Границы:** 9 режимов pywt — PR, длины, совпадение коэффициентов; нерасширяющий симметричный — $N$ коэффициентов и PR при нечётных и чётных $N$; $N<L$ и максимальный уровень.
5. **Преобразования:** DWT/IDWT = pywt; SWT — эквивариантность, энергия MODWT, $\sum D_j+S_J=x$; пакеты — PR из любого базиса, лучший базис против перебора; лифтинг = свёртка, целочисленный — побитный круговой проход; CWT — гребень синусоиды и приближённое обращение.
6. **Частотный анализ:** ГВЗ по формуле отношения = $M/2$ для симметричных; $\sum|\Phi(\omega+2\pi k)|^2=1$, $\sum_j|\Psi(2^j\omega)|^2=1$; теоретические $A_k$ = измеренные по откликам на импульсы.
7. **Приложения:** $\hat\sigma$ по MAD на тестовых сигналах; SURE-порог против перебора; энергия наложения при обнулении: DWT > пакеты с длинными фильтрами > MRA (≈0).
8. **Численность:** эталон в рациональной арифметике для Хаара, 5/3 и `bior*`; MPFR-эталон для dbN; допуски $100\,JLu\|x\|_\infty$; Парсеваль с компенсированным суммированием.
9. **Резамплинг:** 160/147 — уровень копий и наложения ниже спецификации; $L/L$ — тождество; сверка с `resample_poly`.
10. **Режим объяснений:** все числа §5.2–5.4 воспроизводятся точно (суммирующая нормировка).
