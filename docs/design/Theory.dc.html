Назначение: разложить x на октавные полосы d₁…d_J и a_J без потери информации.
── Формулы ───────────────────────────────────────────────────────────────────────────────
aj[k] = ∑n h0[n] · aj−1[2k + 1 − n], dj[k] = ∑n h1[n] · aj−1[2k + 1 − n]
aj−1[m] = ∑k ( f0[m − 2k] · aj[k] + f1[m − 2k] · dj[k] ), a0 = x
aⱼ[k] = ∑ h₀[n] · aⱼ₋₁[2k + 1 − n] dⱼ[k] = ∑ h₁[n] · aⱼ₋₁[2k + 1 − n]
n n
aⱼ₋₁[m] = ∑ ( f₀[m − 2k] · aⱼ[k] + f₁[m − 2k] · dⱼ[k] ), a₀ = x

── Алгоритм и стоимость ──────────────────────────────────────────────────────────────────
1. a ← x 2. для j = 1…J: aⱼ = ↓2(h₀ ∗ aⱼ₋₁), dⱼ = ↓2(h₁ ∗ aⱼ₋₁) 3. края — режим продолжения
стоимость ≈ N·(L₀ + L₁) умножений, память O(N), уровней не больше ⌊log₂(N/(L − 1))⌋
