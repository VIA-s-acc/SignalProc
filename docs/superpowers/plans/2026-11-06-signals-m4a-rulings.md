# M4a — decisions made during execution

The plan `2026-11-06-signals-m4a.md` was executed inline by one implementer, then reviewed once as a whole branch. Every place the implementation departs from the plan, or settles something the plan left open, is recorded below with its reason and what it costs if wrong. The plan's own «Границы M4a» rulings 1–10 stay in the plan.

## Final review

- Final review: Opus, whole branch (2 critical, 6 important, 7 minor). Re-graded by effect: minors 1 (ticker keeps 30 Hz wake-ups after leaving a tab — idle CPU limit) and 3 (✓ on step 1 is not computed — spec anti-goal) raised to Important.

- Final: fixed C1 designer keeps the previous p's bank when p changes between equal group counts (2↔3, 4↔5, 6↔7) and saves it under the new name — "changing p to one with the same group count rebuilds the bank" RED (title db4, h0 length 8) → GREEN, suite 418/418.
- Final: fixed C2 a toggle during a new decomposition published bands of the old data, a stale data job reset the newer job id, and the cursor panel could read past a component — "a toggle during a new decomposition never publishes the old bands" RED (7 components for 4 bands) → GREEN, suite 418/418.
- Final: fixed I1 Esc could not stop a decomposition — "escape cancels a running decomposition" RED → GREEN, suite 418/418; «разложение прервано — r пересчитать».
- Final: fixed I2 jump mode was cancelled by redraw events and mouse moves — "jump mode survives redraw events and mouse moves" RED → GREEN, suite 418/418.
- Final: fixed I3 a lost audio device left the player «playing» forever — "a lost device stops playback with a reason and the next play restarts it" and "a lost audio device is reported once" RED → GREEN, suite 418/418.
- Final: fixed I4 fractions mode failed |H₀|²+|H₁|² and step 9 hard-coded A₁ᵀA₁ = I — "fractions mode keeps power complementarity and the matrix identity honest" RED → GREEN, suite 418/418.
- Final: fixed I5 an unknown wavelet stayed in the decomposition options next to old data — "an unknown wavelet keeps the current decomposition and says why" RED → GREEN, suite 418/418; «Объяснение» no longer passes a user bank's name to other tabs — "facts carry no check mark and a user bank does not leak into other tabs" RED → GREEN.
