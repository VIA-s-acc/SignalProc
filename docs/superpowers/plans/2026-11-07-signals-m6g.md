# Signals M6g: операции над сигналом [v1] — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** закрыть оставшиеся пункты [v1] §7.3:
- тестовые сигналы Донохо–Джонстона в блоке `gen`;
- ограничение, квантование с dither, μ-law;
- корреляция, огибающая и мгновенная частота через Гильберта, кепстр, DCT, ISTFT;
- cycle spinning, THD, онсеты, выгрузка CSV/JSON.

**Architecture:**
- **Ядро.** Точечные операции — `src/core/process/ops.{hpp,cpp}`. Анализ — `src/core/analysis.{hpp,cpp}` на pocketfft. Все вычисления сверяются с numpy/scipy/scikit-image эталонами из `tools/gen_golden.py`, файл `tests/golden/ops.json`.
- **Конвейер.** Новые блоки регистрируются в `src/pipeline/blocks_dsp.cpp`: `clip`, `quantize`, `mulaw`, `xcorr`, `envelope`, `inst_freq`, `cepstrum`, `dct`, `idct`, `thd`, `onsets`, `export`. У блока `threshold` появляется параметр `shifts` (cycle spinning). Новые виды `gen`: `blocks`, `bumps`, `heavisine`, `doppler`.

**Tech Stack:** C++23, pocketfft, Catch2, PyWavelets 1.8, scipy 1.16, scikit-image 0.25.

**Spec:** `docs/03-design.md` §7.3 [v1]; `docs/02-theory.md` §11 (спектральный анализ), §14 (обработка звука).

**Решения плана (моё решение — пользователь может оспорить):**
1. **STFT/ISTFT — в ядре, без пары блоков.** Порт `PortType` не умеет комплексные значения; ISTFT проверяется круговым проходом и эталоном `scipy.signal.istft`. Блок появится вместе с комплексным портом (M7).
2. **Кадрирование — часть STFT** (`stft_frames` уже режет окна), отдельного блока нет.
3. **Онсеты — спектральный поток** с медианным порогом. Эталон — синтетические щелчки с известными временами (±1 шаг кадра), librosa не нужен.

## Review Focus

1. **μ-law на |x| > 1 и на NaN**: кодирование ограничивает вход, NaN не протекает дальше.
2. **Квантование 1 бит и 24 бита**: уровни верные, dither детерминирован по `seed`.
3. **xcorr разных длин и пустых входов**: длина `full` = n + m − 1, ошибка вместо падения.
4. **Мгновенная частота около нулей огибающей**: без NaN и бесконечностей.
5. **`export` в несуществующую папку и путь с кириллицей**: понятная ошибка, файл не портится.

### Task 1: точечные операции и сигналы Донохо–Джонстона

**Files:** Create `src/core/process/ops.{hpp,cpp}`, `tests/core/test_ops.cpp`. Modify `src/pipeline/blocks_basic.cpp` (`gen`), `src/pipeline/blocks_dsp.cpp`, `tools/gen_golden.py` (`ops_json`), i18n.

**Interfaces — Produces:**
- `std::vector<double> clip(std::span<const double> x, double limit)` — жёсткое ограничение ±limit.
- `Result<std::vector<double>> quantize(std::span<const double> x, int bits, bool dither, std::uint64_t seed)`:
  - шаг Δ = 2^(1−bits), уровни —1…1 − Δ, округление к ближайшему;
  - TPDF-dither ±Δ — сумма двух равномерных на [−Δ/2, Δ/2];
  - bits вне 1…32 — ошибка.
- `std::vector<double> mulaw_encode(std::span<const double> x, double mu = 255)`: F(x) = sgn(x)·ln(1+μ|x|)/ln(1+μ), вход ограничен ±1, NaN → 0.
- `std::vector<double> mulaw_decode(std::span<const double> y, double mu = 255)` — обратная функция.

**Tests:**
- `mu-law matches the G.711 companding curve` — против эталона numpy;
- `mu-law round trip is exact to 1e-12 and clips outside ±1`;
- `quantize without dither matches numpy rounding at 1, 8, 16 and 24 bits`;
- `dithered quantization is reproducible and its error stays within one step`;
- `gen makes the Donoho–Johnstone signals` — блок `gen` с `kind = doppler` равен `io::donoho_johnstone`.

### Task 2: анализ — корреляция, Гильберт, кепстр, DCT, ISTFT

**Files:** Create `src/core/analysis.{hpp,cpp}`, `tests/core/test_analysis.cpp`. Modify `blocks_dsp.cpp`, `gen_golden.py`, i18n.

**Interfaces — Produces:**
- `enum class CorrelationMode { full, same, valid }`; `Result<std::vector<double>> correlate(std::span<const double> x, std::span<const double> y, CorrelationMode)` = `scipy.signal.correlate`. Через FFT при n·m > 2¹⁶.
- `std::vector<std::complex<double>> analytic_signal(std::span<const double> x)` = `scipy.signal.hilbert`.
- `std::vector<double> envelope(std::span<const double> x)` = |analytic|.
- `std::vector<double> instantaneous_frequency(std::span<const double> x, double fs)` = diff(unwrap(angle))·fs/2π, длина n − 1. Там, где огибающая < 10⁻¹² от пика, повторяется предыдущее значение.
- `std::vector<double> real_cepstrum(std::span<const double> x)` = real(ifft(log(|fft(x)| + ε))), ε = 10⁻¹² от пика.
- `std::vector<double> dct2(std::span<const double>)`, `idct2(...)` = `scipy.fft.dct/idct(type=2, norm="ortho")`.
- `Result<std::vector<double>> istft(...)` = `scipy.signal.istft` (Hann, nperseg n, noverlap n − hop). Вход — комплексные кадры из нового `stft_complex` в `spectral.hpp`.

**Tests:** каждая функция против scipy на 3 сигналах, включая нечётные длины и n = 1. Сверх того:
- `istft(stft(x))` восстанавливает x до 10⁻¹² внутри;
- `correlate` разных длин даёт n + m − 1;
- мгновенная частота синуса 1 кГц — 1000 ± 10⁻⁶ Гц вне краёв.

**Blocks:**
- `xcorr` — два входа, параметры `mode`, `normalize`;
- `envelope`, `inst_freq`, `cepstrum`, `dct`, `idct`.

### Task 3: измерения, cycle spinning, выгрузка

**Files:** Modify `src/core/process/shrink.{hpp,cpp}` (`cycle_spin`), `src/core/analysis.*` (`thd`, `onsets`), `blocks_dsp.cpp`, `src/pipeline/blocks_basic.cpp` (`export`), i18n.

**Interfaces — Produces:**
- `struct Thd { double f0, thd, thd_db; std::vector<double> harmonic_db; }`; `Result<Thd> thd(std::span<const double> x, double fs, int harmonics = 5)`:
  - окно Блэкмана–Харриса, пик основного тона с параболическим уточнением;
  - мощность гармоник — сумма ±3 бинов вокруг k·f0.
- `std::vector<double> onsets(std::span<const double> x, double fs, std::size_t n = 1024, std::size_t hop = 256)` — времена в секундах; спектральный поток положительных разностей; пик выше медианы окна 0,5 с × 1,5 + δ.
- `Result<std::vector<double>> cycle_spin(std::span<const double> x, int shifts, const std::function<Result<std::vector<double>>(std::span<const double>)>& denoise)` — среднее по циклическим сдвигам 0…shifts−1, как `skimage.restoration.cycle_spin`.
- Блок `export`: вход signal | coeffs | report; параметры `path`, `format` (`csv` | `json`). Запись атомарна, через временный файл.

**Tests:**
- `thd of a tone with known harmonics` (1 %, 0,1 % — до 10⁻³ отн.);
- `onsets find synthetic clicks within one hop`;
- `cycle spinning matches skimage` — эталон из `gen_golden.py`;
- `export writes csv and json that read back`, и запись в несуществующую папку — ошибка без файла.
