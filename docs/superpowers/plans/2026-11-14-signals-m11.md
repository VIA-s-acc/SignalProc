# M11 «Мост в Python» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Signals выгружает и загружает сигналы, коэффициенты и отчёты в `.npy`/`.npz`, пишет по графу `.sig` скрипт или тетрадь на numpy, scipy и pywt, которые сверяют каждый щуп с программой, и показывает живой предпросмотр в VS Code; затем выпуск 0.9.0.

**Architecture:** `io/npy` — свой формат `.npy` и ZIP через miniz, который работает только с памятью (файлы читаются и пишутся своими потоками). `io/npy_audio` и `pipeline/npz_values` раскладывают значения по ключам и приводят детали к знаку pywt. Новая библиотека `signals_python`: таблица Python-форм блоков (по файлу на группу, как `blocks_*.cpp`), функции на numpy в `resources/python/*.py` (встраиваются в программу) и сборщик `build_script`. Он выполняет граф со щупом на каждом выходе и собирает текст по узлам. Тест моста: Catch2 пишет скрипты всех примеров и графов всех блоков, затем один процесс Python (`tools/bridge/run_scripts.py`) выполняет их все.

**Tech Stack:** C++23, CMake, Catch2, CLI11, nlohmann/json, fmt, FTXUI 7.0.3, miniz 3.0.2 (MIT), Python 3.12 с numpy 2.3.5, scipy 1.16.2, PyWavelets 1.8.0, matplotlib 3.10.9, Node 20 (`node --test`), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-14-signals-m11-python-bridge-design.md`

## Global Constraints

- Сборка с `-Werror` на clang и на GCC 16 с `-fno-range-for-ext-temps`; без идентификаторов `near` и `far` (MSVC).
- Комментарии в коде — только если без них код сломают; на английском. Имена, тексты тестов, сообщения инструментов и скриптов `tools/` — на английском. Текст интерфейса и комментарии сгенерированного скрипта — через i18n (`resources/i18n/ru.json`, `en.json`), на обоих языках.
- Панели: Tab, `z`, масштаб графиков, узкая раскладка 80×24, листание, никакой тихой обрезки — для каждого нового вопроса и сообщения.
- Каждая возможность доходит до CLI, интерфейса, блоков, документов (`docs/user/*`, `keys.md`), `blocks.md` и `editors/vscode/data/blocks.*.json` (перегенерировать) и CHANGELOG `[Unreleased]`.
- Скрипт зависит только от numpy, scipy и PyWavelets; тетрадь — ещё от matplotlib и IPython. `dtcwt`, `ssqueezepy`, `skimage` в скрипт не попадают.
- `.npz` открывается `np.load(..., allow_pickle=False)`; запись без сжатия, чтение — со сжатием (deflate) и без. ZIP — miniz 3.0.2 через FetchContent.
- Сверка: `max|a − b| ≤ tol · max(1, max|b|)`; `tol` = 10⁻¹². Слабее — только у блоков таблицы §5.1 спецификации: `iir` и `remez` — 10⁻⁸; `firls`, `lms`, `sst_band` и `sst_ridge` — 10⁻¹⁰; `cepstrum` — 10⁻⁹. Щуп получает самый слабый допуск выше по графу. Целые и строки сравниваются точно.
- Вне Signals детали `dwt`, `swt`, `wpt` — в знаке pywt; ключ `detail_sign`.
- С `coeffs_file` блоков 137; «136» в спецификации — число до этапа. Тесты полноты обходят `block_types()`, а не число.
- Коммиты — короткая фраза около 5 слов, без трейлеров и упоминаний помощника.
- Ветки стопкой: `m11-npz` (PR 1; от `m11-spec`, несёт спецификацию и план) → `m11-gen` → `m11-forms` → `m11-notebook` → `m11-preview` → `m11-review` → `m11-release`. Слияние и тег — только с согласия пользователя, по одному PR.
- Сборки — как в прошлых этапах: clang в `val-rel`, GCC 16 в `val-gcc`; тесты — `val-rel/tests/signals_tests "[тег]"`.

## Review Focus

1. **Настоящие файлы numpy.** `np.savez` пишет каждый элемент с полем ZIP64 (`force_zip64=True`), `savez_compressed` сжимает deflate. Ожидание: оба файла открываются. Тест — фикстуры, записанные самим numpy (Task 1).
2. **Путь с кириллицей и пробелом** (`Практика 1/данные.npz`) на всех ОС. Ожидание: запись и чтение работают. Тест — папка `данные с пробелом` (Task 1).
3. **Массив `(N, C)`** из soundfile, например `(48000, 2)`. Он двумерный, но не `(C, N)`. Ожидание: ошибка с формой и подсказкой `x.T`, а не 48000 каналов по 2 отсчёта. Правило: больше 64 строк — ошибка. Тест в Task 2.
4. **Имена узлов, совпадающие с именами Python:** `lambda`, `print`, `np`, `pywt`, `D`, `verify`, а также имена, отличающиеся только регистром. Ожидание: скрипт выполняется, переменная получает `_` в конце. Тест в Task 8.
5. **Запуск скрипта из другой папки** и путь с пробелом: `python "../Практика 1/first_steps.py"`. Ожидание: `.npz` и WAV ищутся рядом со скриптом. Тест моста запускает каждый скрипт, когда текущая папка — корень временной папки, а скрипт лежит в подпапке с пробелом (Task 12).
