# Signals M7e: конвейер и окна — аудит и доводка

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** по просьбе пользователя:
- довести все окна до общих правил (фокус, `z`, масштаб, узкая раскладка, без молчаливой обрезки, всё листается колесом и клавишами, всё доступно с клавиатуры);
- сделать «Конвейер» понятным и удобным;
- собрать на нём учебный банк Хаара, как на «Объяснении», в один и несколько уровней.

**Architecture:** правки экранов и блоков; новые блоки `samples` и `add`; новые параметры `downsample.phase`, `upsample.anti_image`, `check.delay`; примеры в `examples/`.

**Tech Stack:** C++23, FTXUI, Catch2.

**Spec:** `docs/03-design.md` §8 (TUI), §8.7 (конвейер); память `signals-panel-modes`.

**Решения плана (моё решение — пользователь может оспорить):**
1. Учебный банк собирается из обычных блоков: `samples` → `convolve(haar.h0)` → `downsample(m=2, anti_alias=no, phase=1)` → `upsample(anti_image=no)` → `convolve(haar.f0)` → `add` → `check(delay=auto)`. Отдельного блока «банк» нет: смысл примера — увидеть каждый шаг.
2. `check(delay=auto)` ищет задержку восстановления и пишет её в отчёт, как ℓ на «Объяснении».

## Global Constraints

- Всё из M7d и правила памяти `signals-panel-modes`.

## Review Focus

1. Пример Хаара на 8 отсчётах даёт a, d и x̂ те же, что «Объяснение».
2. Два уровня: задержки ветвей выровнены, PR до 10⁻¹².
3. Списки и тексты «Конвейера» листаются колесом и клавишами и показывают «▲/▼ ещё N».
4. Заголовки панелей с длинным текстом кончаются «…».
5. Узкая раскладка 80×24 на всех экранах без обрезки.

### Task A: блоки и примеры для учебного банка

- `samples(values="4 6 10 12 8 6 5 5", rate=8)` — сигнал из перечисленных отсчётов.
- `add(a, b)` с `op` = add / sub — сумматор ⊕; длина — большая из двух, недостающее — нули.
- `downsample.phase` (0…m−1) — какие отсчёты оставить; `upsample.anti_image` (yes/no) — без фильтра это вставка нулей.
- `check.delay` (auto или число) — задержка `in` относительно `ref`; в отчёте поле `delay`.
- Примеры:
  - `examples/haar_bank.sig` — один уровень на x из «Объяснения»;
  - `examples/haar_two_levels.sig` — два уровня анализа и синтеза;
  - `examples/dwt_levels.sig` — `dwt` на 3 уровня со щупами на всех полосах и `idwt`.
- Тест: каждый пример запускается, все `check` проходят.
- Палитра: «Открыть пример…» — список примеров.

### Task B: «Конвейер»

- «Текст .sig», «Запуск», «Инспектор», список блоков: листание колесом и клавишами, «▲/▼ ещё N».
- Строка состояния, заголовок «Запуска», имена узлов, строки CLI — «…» или перенос, а не обрезка.
- Строка щупов — «…», если щупов много.
- В списке блоков — однострочное описание выбранного блока: входы → выходы.
