# Signals M8b: тон и время [v2] — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** строка M8b из §13:
- оценка основного тона;
- растяжение во времени без смены высоты;
- сдвиг высоты;
- блоки конвейера и вид на «Спектре».

**Architecture:**
- **Растяжение и сдвиг** — `src/core/tempo.*`:
  - фазовый вокодер как `librosa.effects.time_stretch`;
  - он же с фазовой синхронизацией (identity phase locking, Laroche–Dolson);
  - WSOLA во временной области;
  - FFT-ресемплинг как `scipy.signal.resample`;
  - сдвиг высоты = растяжение в 2^(n/12) раз и ресемплинг обратно (как `librosa.effects.pitch_shift(res_type="fft")`).
- **Основной тон** — YIN переезжает из `blocks_analysis.cpp` в `src/core/pitch.*`, чтобы им пользовались блок `pitch`, новый вид и тесты.
- **Блоки** — `src/pipeline/blocks_tempo.cpp`: `time_stretch`, `pitch_shift`, `speed`.
- **Вид** — подвкладка «Спектр ▸ Тон и время» (`tempo_model.*`, `tempo_screen.*`) по образцу «Ресемплинга».

**Tech Stack:** C++23, pocketfft, numpy и scipy 1.16 для эталонов; librosa — только для разовой сверки numpy-порта.

**Spec:** `docs/03-design.md` §13, строка M8b.

**Решения плана (моё решение — пользователь может оспорить):**
1. Эталон вокодера — numpy-порт `librosa.effects.time_stretch` в `tools/gen_golden.py`. Порт один раз сверяется с настоящей librosa в отдельном окружении. librosa не попадает в `requirements.txt`: она тянет numba и llvmlite.
2. Ресемплинг в сдвиге высоты — FFT (`scipy.signal.resample`), а не soxr по умолчанию в librosa: soxr не воспроизвести точно.
3. `rate` — как в librosa: во сколько раз быстрее; 2 — вдвое короче. Диапазон 0,1…10.
4. `speed` — «как пластинка»: темп и высота меняются вместе; это нужно для сравнения на уроке.
5. Фазовая синхронизация и WSOLA не имеют общепринятого эталона. Они проверяются свойствами: длина, тон до цента, точное восстановление при `rate = 1`.

## Global Constraints

- Всё из M8a. Комментарии в коде — только там, где без них код сломают; в коде всё по-английски.
- Перед пушем — сборка с `-DSIGNALS_WERROR=ON` на clang и на GCC 16 с `-fno-range-for-ext-temps`.
- Вокодер и ресемплинг совпадают с эталоном до 10⁻¹².
- Сдвиг на октаву (±12) возвращает тон до 1 цента.

## Review Focus

1. **Пустой или очень короткий вход** (короче окна): понятная ошибка или корректный короткий выход, без выхода за границы.
2. **`rate` на краях диапазона** (0,1 и 10) и сдвиг на ±24 полутона: длина выхода точна, без NaN.
3. **`hop > n_fft`, нечётное `n_fft`, NOLA** нарушена: ошибка с причиной.
4. **Тишина и постоянный сигнал** в WSOLA и в фазовой синхронизации: без деления на ноль.
5. **Стерео:** каналы обрабатываются одинаково, длины совпадают.

### Task 1: ядро растяжения и сдвига

- `enum class StretchMethod { vocoder, locked, wsola }`.
- `struct StretchOptions { StretchMethod method = StretchMethod::vocoder; std::size_t n_fft = 2048, hop = 512; }`.
- `Result<std::vector<double>> time_stretch(std::span<const double> x, double rate, const StretchOptions& o, ProgressSink* progress = nullptr)` — длина выхода `round(len / rate)`.
- `Result<std::vector<double>> fft_resample(std::span<const double> x, std::size_t num)` — как `scipy.signal.resample`.
- `Result<std::vector<double>> pitch_shift(std::span<const double> x, double semitones, const StretchOptions& o, ProgressSink* progress = nullptr)` — длина равна входной.
- Отказ: пустой вход; `rate` не конечен или вне 0,1…10; `n_fft` нечётно или меньше 16; `hop` = 0 или больше `n_fft`.
- Эталоны `tempo.json`: смесь тонов, 4000 отсчётов, 8 кГц, `n_fft = 512`, `hop = 128`; `rate` 0,5, 0,8, 1,25, 2; сдвиги −12, −5, 3,5, 12; ресемплинг вверх и вниз при чётной и нечётной длине.
- Тесты: совпадение с эталоном; `rate = 1` восстанавливает вход для всех методов; тон 220 Гц после растяжения в 1,5 и 0,75 раза — те же 220 Гц до 1 цента; ±12 полутонов дают 440 и 110 Гц до 1 цента.

### Task 2: YIN в ядре

- `struct YinOptions { std::size_t frame = 2048, hop = 512; double fmin = 60, fmax = 1000, threshold = 0.1; }`.
- `Result<std::vector<double>> yin_track(std::span<const double> x, double fs, const YinOptions& o, ProgressSink* progress = nullptr)` — 0 там, где тон не найден.
- `double median_f0(std::span<const double> track)` — медиана по звонким кадрам.
- Блок `pitch` переходит на `yin_track`; его эталоны не меняются.
