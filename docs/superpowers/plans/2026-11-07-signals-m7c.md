# Signals M7c: полировка экранов — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** вторая часть отложенных замечаний M6–M7b — те, что видны на экранах «Спектр», «Обработка», «Разложение» и «Ресемплинг», и английские формы числа.

**Architecture:** точечные правки экранов; новых модулей нет.

**Tech Stack:** C++23, FTXUI, Catch2.

**Spec:** `docs/03-design.md` §13 M7 «Полировка»; ledgers M6b–M7b (`Final: minor (deferred)`).

**Решения плана (моё решение — пользователь может оспорить):**
1. Протяжка за край графика доходит до края данных: конец вида, fs/2 сверху, нижняя частота оси снизу.
2. Копии наложения без фильтра рисуются с уровнем 1/M по мощности, чтобы их сумма равнялась спектру после ↓M.

## Global Constraints

- Всё из M7b.

## Review Focus

1. **Протяжка за край в увеличенном виде:** конец рамки — конец вида, а не файла.
2. **Рамка, частично видимая после сдвига вида,** рисуется обрезанной, а не исчезает.
3. **Отмена после протяжки λ на «Обработке»** возвращает значение до протяжки одним `u`.
4. **Повтор отменённой задачи пакетов** не сбрасывает выбор полос.
5. **Английский режим** для новых единиц.

---

### Task 1: «Спектр»

- Протяжка за край графика: t — до конца вида, f — до fs/2 или нижней частоты оси.
- Рамка целиком вне вида не рисуется полосой у края.
- Средний уровень рамки меньше одного столбца или бина берётся по ближайшему бину, а не «—».

### Task 2: «Обработка»

- Протяжка λ — один шаг отмены: `u` возвращает значение до протяжки; возврат к строке нажатия не теряется.
- `u` снимает подсветку пресета, если восстановленное состояние ему не равно.
- Вторая строка панели инструментов на 80×24 обрезается с многоточием.

### Task 3: «Разложение»

- Имена узлов пакетов на уровнях от 9 не налезают на столбец частот.
- Повтор отменённой задачи пакетов или скалограммы — по клику на вид, без `r` и без сброса полос; панель прослушивания не пишет «отменено» после повтора.

### Task 4: «Ресемплинг»

- Копии X((ω − 2πk)/M) без фильтра — с уровнем −10·log₁₀M дБ.
- В L/M при M > L АЧХ фильтра видна и на панели «до», где лежит её срез.

### Task 5: тексты

- `ellipsize` считает ширину без комбинирующих знаков.
- Английские «1 samples», «1 taps», «1 threads» — через `tr_count`.
