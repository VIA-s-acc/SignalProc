> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перевести репозиторий `SignalProc` на C++. Собрать ядро банков фильтров — многочлены Лорана, проектирование по $P_p(z)$, все 106 вейвлетов PyWavelets, DWT во всех 9 режимах границ, матрицы. Плюс CLI с самопроверкой. Всё совпадает с PyWavelets.

## Global Constraints

- C++23, расширения компилятора выключены (`CMAKE_CXX_EXTENSIONS OFF`). CMake ≥ 3.28. Зависимости — FetchContent, версии строго из Tech Stack.
- `double` во всех расчётах. Без `-ffast-math`.
- Только пермиссивные зависимости. Лицензия проекта — MIT.
- Код, идентификаторы, имена тестов, сообщения ассертов и комментарии — на английском. Строки для человека в CLI — через словарь i18n (`resources/i18n/ru.json`).
- Комментарий пишется, только если без него код сломают «упрощением» (правило пользователя).
- Знаки ФВЧ по Strang–Nguyen: $H_1(z)=F_0(-z)$, $F_1(z)=-H_0(-z)$. Связь с pywt: `dec_lo = h0`, `rec_lo = f0`, `dec_hi = −h1`, `rec_hi = −f1`.
- Фаза прореживания как в pywt: после полной свёртки берутся нечётные отсчёты. Режим совместимости воспроизводит `pywt.dwt/idwt/wavedec/waverec` с точностью $10^{-12}$. Знак деталей задаётся настройкой `pywt_detail_sign`.
- Нормировка по умолчанию — $\sum h_0=\sqrt2$.
- Фильтр хранит смещение (индекс первого коэффициента). Задержка $\ell$ вычисляется из $P_0(z)-P_0(-z)=2z^{-\ell}$ и никогда не задаётся константой.
- Порядок коэффициентов — $[a_J, d_J, \dots, d_1]$.
- Ошибки в `core` — через `std::expected` (`Result<T>`). Исключения в горячих путях не используются.
- Каждая проверка возвращает именованный `CheckResult`, а не `bool`.
- Допуск по умолчанию — $100\,J\,L\,u\,\|x\|_\infty$, где $u=2^{-53}$.
- Коммит — одно короткое предложение (~5 слов), без `Co-Authored-By`. `git push` — только с согласия пользователя.

## Review Focus

Пять входов, которых не касаются основные тесты задач, но которые первыми ударят по пользователю. Каждый закреплён тестом в задаче-владельце.

1. **Нечётная длина сигнала.** `waverec(wavedec(x))` должен вернуть ровно N отсчётов. pywt возвращает N+1 — это известная ловушка. Тест в Task 11.
2. **NaN или Inf во входе.** Проверка с NaN обязана быть проваленной, а не ✓. Тест в Task 8.
3. **Число уровней за пределами** `[1, dwt_max_level]`, включая `levels = 0` и N = L − 1. Ожидается ошибка `level_out_of_range` с понятным сообщением, а не мусор. Тест в Task 11.
4. **Неверные имена вейвлетов:** `"db0"`, `"db39"`, `"sym1"`, `"bior2.3"`, `"DB2"`, `" db2"`. Ожидается ошибка `unknown_wavelet`. Тест в Task 15.
5. **Код возврата `signals check`.** Если провалилась хотя бы одна проверка, код ≠ 0 — на это опирается CI. Тест в Task 18.

### Task 5: Скаляры, ошибки, многочлены Лорана

**Files:**

**Interfaces:**
- Produces (`error.hpp`): `enum class Errc { invalid_argument, level_out_of_range, length_mismatch, not_perfect_reconstruction, unknown_wavelet, no_convergence };` `struct Error { Errc code; std::string message; };` `template <class T> using Result = std::expected<T, Error>;`
- Produces (`scalar.hpp`): `using Rational = boost::multiprecision::cpp_rational;` `using Float256 = boost::multiprecision::number<boost::multiprecision::cpp_bin_float<256, boost::multiprecision::digit_base_2>>;`
- Produces (`laurent.hpp`, всё в `signals::core`):
  - `template <class T> struct BasicLaurent { std::vector<T> coeffs; std::ptrdiff_t offset = 0; std::ptrdiff_t first() const; std::ptrdiff_t last() const; T at(std::ptrdiff_t n) const; bool operator==(const BasicLaurent&) const = default; };` — `coeffs[k]` — коэффициент при $z^{-(\text{offset}+k)}$; `at` вне носителя возвращает 0.
  - `using Laurent = BasicLaurent<double>;`
  - Свободные шаблоны, все принимают `const&` и возвращают новый объект: `multiply`, `add`, `subtract`, `scale(p, T)`, `power(p, int)`, `shift(p, std::ptrdiff_t k)` ($z^{-k}p$), `alternate(p)` ($p(-z)$: $c_n\to(-1)^n c_n$ по **абсолютному** $n$), `reverse(p)` ($p(z^{-1})$), `trim(p, T tol)` (срезать нули по краям, сохраняя смещение), `template <class To, class From> BasicLaurent<To> convert(const BasicLaurent<From>&)`.
  - Только для `double`: `std::complex<double> evaluate(const Laurent& p, double omega)` ($\sum c_n e^{-i\omega n}$); `struct Monomial { double coef; std::ptrdiff_t exponent; }; std::optional<Monomial> as_monomial(const Laurent& p, double tol);`

### Task 9: Банк фильтров и проверка PR

**Files:**
- Create: `src/core/bank.hpp`, `src/core/bank.cpp`
- Test: `tests/core/test_bank.cpp`

**Interfaces:**
- Consumes: `BasicLaurent`, `alternate`, `multiply`, `as_monomial` (Task 5); `CheckResult` (Task 8).
- Produces: `template <class T> struct BasicFilterBank { std::string name; BasicLaurent<T> h0, h1, f0, f1; std::size_t length() const; };` `using FilterBank = BasicFilterBank<double>;`
  - **Раскладка pywt:** у всех четырёх фильтров `offset == 0` и одна чётная длина `L`; центр $P_0=F_0H_0$ — в индексе $L-1$. На этом стоит индексация DWT в Task 10.
- Produces: `template <class T> Result<BasicFilterBank<T>> make_bank(std::string name, BasicLaurent<T> h0, BasicLaurent<T> f0, double pr_tol = 1e-12);`
  - Выводит `h1 = alternate(f0)`, `f1 = scale(alternate(h0), -1)`. Для `Rational` сравнение точное, `pr_tol` не используется.
  - **Правило раскладки pywt.** Проверено скриптом на всех 106 вейвлетах pywt 1.8.0: результат побитно равен их массивам.
    1. Найти $\ell$ из $P_0(z)-P_0(-z)=2z^{-\ell}$ по фильтрам **как они даны**, со смещениями. Если это не одночлен с коэффициентом 2 при допуске `pr_tol` — ошибка `not_perfect_reconstruction`.
    2. Только после этого обрезать нули по краям. $a_h, a_f$ — абсолютные индексы первых ненулевых отсчётов, $n_h, n_f$ — длины, $\ell_{rel}=\ell-a_h-a_f$.
       Порядок шагов 1 и 2 важен: у `dmey` `dec_lo` начинается с нуля, а `rec_lo` нет. Если обрезать раньше, чётность сдвигов разойдётся и PR пропадёт — та же ловушка, что в ошибке 10 ревизии.
    3. $L$ — наименьшее чётное число $\ge\max(n_h,n_f)$.
    4. $s_h=\lceil (L-n_h)/2\rceil$, $s_f=L-1-\ell_{rel}-s_h$. Если $s_f<0$ или $s_f+n_f>L$ — увеличить $L$ на 2 и повторить шаг 4.
    5. Поставить первый ненулевой отсчёт `h0` в индекс $s_h$, `f0` — в $s_f$, `offset = 0`, дополнить нулями до длины $L$.
  - Для фильтров, уже разложенных как в pywt, функция идемпотентна.
- Produces: `template <class T> BasicFilterBank<T> bank_from_pywt(std::string name, std::vector<T> dec_lo, std::vector<T> dec_hi, std::vector<T> rec_lo, std::vector<T> rec_hi);` — `h1 = −dec_hi`, `f1 = −rec_hi`, без проверок.
- Produces: `struct PrReport { CheckResult alias; CheckResult distortion; std::optional<std::ptrdiff_t> delay; };` `PrReport check_pr(const FilterBank&, double tol = 1e-12);` — `alias` = max |коэфф.| у $\tfrac12[F_0H_0(-z)+F_1H_1(-z)]$; `distortion` = расстояние $\tfrac12[F_0H_0+F_1H_1]$ до ближайшего $z^{-\ell}$.
