# M10 «Лёгкий вход» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Signals ставится одной командой на macOS, Linux и Windows (скрипты и свой tap Homebrew), первый запуск ведёт к примеру, README на двух языках показывает каждый экран картинками, которые рисует сама программа.

**Architecture:** Дерево CLI11 выносится в функцию, по нему строятся дополнения и man-страница. Упаковка выпуска — один скрипт `packaging/package.sh`, его же используют проверки установки в CI. Стартовая панель — оверлей оболочки по образцу `TerminalCheck`. Кадр `ftxui::Screen` переводится в SVG, инструмент `signals-gallery` проигрывает сценарии экранов и пишет картинки.

**Tech Stack:** C++23, CLI11, FTXUI 7.0.3, Catch2, CMake, POSIX sh, PowerShell 5.1, Ruby (формула Homebrew), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-14-signals-m10-easy-entry-design.md`

## Global Constraints

- Сборка с `-Werror` на clang и на GCC 16 с `-fno-range-for-ext-temps`; без идентификаторов `near` и `far` (Windows).
- Комментарии в коде — только если без них код сломают; на английском. Имена, тексты тестов, сообщения инструментов и скриптов — на английском. Текст интерфейса — через i18n, ключи в `resources/i18n/ru.json` и `en.json`.
- Панели интерфейса: мышь, узкая раскладка 80×24, без тихой обрезки, листание при нехватке места.
- Скрипты установки не просят `sudo` и не пишут вне домашней папки по умолчанию; ставят только после сверки SHA-256.
- Архив macOS называется `signals-vX.Y.Z-macos-universal.tar.gz`; архивы старых выпусков не трогаются.
- Размер кадра галереи 150×44; статичная картинка до 300 КБ, анимация до 1,5 МБ, все картинки одного языка до 8 МБ.
- Коммиты — короткая фраза около 5 слов, без трейлеров и упоминаний помощника.
- Ветки стопкой: `m10-entry` (PR 1) → `m10-install` (PR 2) → `m10-start` (PR 3) → `m10-gallery` (PR 4) → `m10-readme` (PR 5).

## Review Focus

1. `curl … | sh`: сценарий читается из stdin, поэтому любая команда, читающая stdin, съест остаток скрипта. Ожидание: скрипт не читает stdin. Тест: `test_install.sh` запускает скрипт через `cat install.sh | sh`, не `sh install.sh` (Задача 4).
2. Пробел в пути установки или в `HOME`. Ожидание: установка проходит. Тест: сценарий с `SIGNALS_INSTALL_DIR="$tmp/dir with space"` (Задача 4).
3. Повторный запуск `install.ps1`. Ожидание: папка в `PATH` пользователя один раз. Тест: два запуска подряд, счёт вхождений = 1 (Задача 5).
4. Стартовая панель в терминале без цвета и с ASCII-знаками и в 80×24. Ожидание: все три пункта и строка клавиш видны, ничего не обрезано. Тест в Задаче 9.
5. Кадр с пустыми ячейками-продолжениями и с `<`, `&`, `"` в тексте экрана. Ожидание: валидный SVG, сетка не съезжает. Тесты в Задаче 10.
