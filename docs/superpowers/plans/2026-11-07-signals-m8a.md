## Review Focus

1. **LMS с μ, при котором фильтр расходится:** ошибка с подсказкой уменьшить μ, а не сигнал из NaN.
2. **NLMS на тишине:** без деления на ноль.
3. **Шумовой участок короче одного окна или длиннее сигнала:** понятная ошибка.
4. **Ядро деконволюции длиннее сигнала или пустое:** ошибка; нули |H| не дают бесконечностей.
5. **Гохберг–Семенцул на почти вырожденной матрице:** отказ Левинсона с причиной, а не inf.

### Task 1: LMS и NLMS

- `enum class AdaptiveRule { lms, nlms }`.
- `struct AdaptiveResult { std::vector<double> y, e, w; }`.
- `Result<AdaptiveResult> adaptive_filter(std::span<const double> x, std::span<const double> d, std::size_t taps, double mu, AdaptiveRule rule, double eps = 1e-8)`.
- На шаге n:
  - u = (x[n], x[n−1], …, x[n−L+1]), до начала сигнала — нули;
  - y[n] = wᵀu, e[n] = d[n] − y[n];
  - LMS: w += μ·e[n]·u; NLMS: w += μ·e[n]·u / (eps + uᵀu).
- Отказ:
  - длины x и d различаются;
  - L = 0 или L больше длины;
  - μ ≤ 0;
  - неконечный выход — «фильтр расходится: уменьшите μ».
- Эталоны (`adaptive.json`): идентификация системы (d = h ⊛ x + шум) и подавление помехи для LMS и NLMS.
- Блок `lms`:
  - входы `x` (опорный) и `d` (желаемый), выходы `e` (ошибка — очищенный сигнал) и `y` (оценка);
  - параметры `taps` (32, 1…4096), `mu` (0,1, 10⁻⁶…2), `rule` (`nlms`, `lms`).

### Task 2: винер, спектральное вычитание, деконволюция

- `Result<std::vector<double>> wiener_local(std::span<const double> x, std::size_t size, std::optional<double> noise = {})` — как `scipy.signal.wiener` в 1-D. Размер нечётный.
- `struct SpectralSubtraction { double alpha = 2, beta = 0.01; std::size_t n = 512, hop = 128; }`.
- `Result<std::vector<double>> spectral_subtract(std::span<const double> x, std::span<const double> noise, const SpectralSubtraction& o)`:
  - P = max(|X|² − α·N̄, β·N̄), фаза сохраняется;
  - N̄ — средняя по кадрам мощность STFT шума.
- `Result<std::vector<double>> wiener_deconvolve(std::span<const double> y, std::span<const double> h, double snr_db)`: X = Y·H̄ / (|H|² + 10^(−snr/10)).
- Эталоны (`restoration.json`): scipy.signal.wiener; numpy со scipy.signal.stft/istft; numpy fft.
- Блоки:
  - `wiener` с параметрами `size` (5) и `noise` (0 — оценить по сигналу);
  - `spectral_subtract` со входами `x` и `noise` (необязательный) и параметрами `alpha`, `beta`, `n`, `noise_s`;
  - `deconvolve` со входами `y` и `h` и параметром `snr_db` (30).

### Task 3: Гохберг–Семенцул

- `Result<Eigen::MatrixXd> toeplitz_inverse(std::span<const double> r)` для симметричной T(r):
  - x — решение T x = e₁ через `levinson_solve`;
  - T⁻¹ = (A·Aᵀ − B·Bᵀ)/x₀, где A — нижнетреугольная тёплицева с первым столбцом x, B — с первым столбцом (0, x_{n−1}, …, x₁).
- Эталон: `numpy.linalg.inv(scipy.linalg.toeplitz(r))` для автокорреляции h₀ db4 и случайной положительно определённой.
- «Матрица»: под проверкой Левинсона — строка «T⁻¹ по Гохбергу–Семенцулу» с max|T·T⁻¹ − I|.
