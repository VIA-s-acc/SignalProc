# Signals M6f: лифтинг, спектры φ/ψ и Ψ̂ CWT, «Банк ▸ Блок-схема» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** закрыть оставшиеся заглушки M6:
- лифтинг LeGall 5/3 (вещественный и целочисленный JPEG 2000) и CDF 9/7 в ядре, с блоками конвейера `lift53`/`ilift53`;
- группы библиотеки «Фильтров» «Спектры φ / ψ» и «CWT»;
- вкладка «Банк ▸ Блок-схема» — живая схема одного уровня банка со щупами на проводах.

**Architecture:**
- **Лифтинг** (`src/core/lifting.{hpp,cpp}`): шаги предсказания и обновления по §10.3–10.4, края — WS-зеркалирование. Целочисленный 5/3 работает на `std::int64_t` с проверкой запаса разрядности.
- **Спектры** (`src/core/wavelet/spectra.{hpp,cpp}`):
  - Φ(ω) = ∏ m₀(ω/2ʲ), усечение при 2⁻ᴶ|ω| < 1e-9 (§8.9);
  - Ψ(ω) = m₁(ω/2)·Φ(ω/2);
  - Ψ̂ для `morl`, `mexh`, `cmor` — БПФ `wavefun` из M6b.
  - В библиотеке «Фильтров» это обычные элементы с АЧХ на оси ω ∈ [0, 8π].
- **Блок-схема** (`src/tui/screens/diagram_screen.{hpp,cpp}`):
  - анализ H₀/H₁ → ↓2 → ↑2 → F₀/F₁ → ⊕ для банка из «Конструктора» или вейвлета палитры;
  - вход — фрагмент открытого файла или импульс;
  - клик по проводу открывает щуп «время / спектр / числа»;
  - `P` — полифазный вид (тождества благородных).

**Spec:** `docs/03-design.md` §7.1, §7.2 [v1] «Спектры φ и ψ, … Ψ̂ для CWT», §7.3 [ядро] «лифтинг», §7.3 [v1] «целочисленный 5/3», §8; `docs/02-theory.md` §8.9, §10.3, §10.4; `docs/research/visualization.md` §3.1, §7.5.

**Решения плана (моё решение — пользователь может оспорить):**
1. **Константы 9/7 вычисляются из `bior4.4`** факторизацией (§10.4 предупреждает о погрешности опубликованных 10 знаков). Совпадение со свёрткой `bior4.4` — до 1e-12.
2. **Схема рисуется для одного уровня.** Дерево Малла уже показано на «Разложении», «Конвейер» строит любые деревья.
3. **Анимация «точки бегут»** — не в этом этапе. Подсветка блока под курсором и щупы есть.

## Global Constraints

- Тексты — в `ru.json` и `en.json`; карточки «Под капотом» `lifting` и `phi_psi`.

## Review Focus

1. **Нечётная длина и длина 1–2** для лифтинга: края WS не выходят за массив.
2. **Целочисленное переполнение:** int32 на 10 уровнях — ошибка с понятным текстом, а не мусор.
3. **Φ для банков без нуля в −1:** произведение не сходится; отказ с причиной.
4. **Клик по проводу при смене банка** во время расчёта щупа.
5. **Схема на 80×24:** блоки не налезают, щуп в отдельной панели.
