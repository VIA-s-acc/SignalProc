# Signals M6i: вид «Ресемплинг» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** последний экран M6 — ↓M, ↑L и L/M крупным планом (`docs/research/visualization.md` §7.11). Видно, куда складывается спектр, что делает фильтр АА и подавления изображений, куда попадёт тон.

**Architecture:**
- **Модель** — `src/tui/screens/resample_model.{hpp,cpp}`, расчёт синхронный, кэш по параметрам.
  - Вход: фрагмент открытого файла 8192 отсчёта (выделение «Сигнала» или окрестность самого громкого места) или синтетика — тон f или свип, fs = 48 кГц.
  - Выход: `core::upfirdn` с фильтром `core::anti_alias_filter(max(L, M))` или без него (обход). Частоту среза можно сдвинуть множителем.
  - Спектры по Уэлчу (`core::welch_psd`) до и после.
  - Для ↓M без фильтра — M копий X((ω − 2πk)/M) по отдельности, как слагаемые наложения.
- **Экран** — `src/tui/screens/resample_screen.{hpp,cpp}`, вложенная вкладка «2 Спектр ▸ Ресемплинг» рядом со спектрограммой. Панели:
  - спектр до, с линиями складывания k·fs′/2, полосой, которая сложится, и АЧХ фильтра;
  - спектр после, где каждая копия своим цветом;
  - для ↑L — отсчёты во времени с нулями между ними;
  - показания: fs, fs′, куда попадёт тон f, подавление АА в полосе складывания.
- **Навигация:** `spectrum` → «Спектр ▸ Спектрограмма», `resample` → «Спектр ▸ Ресемплинг».

**Spec:** `docs/03-design.md` §7.3 [ядро] «↓M, ↑M, L/M», §8.3 (каталог экранов); `docs/research/visualization.md` §7.11; `docs/02-theory.md` §4 (многоскоростная обработка).

**Решения плана (моё решение — пользователь может оспорить):**
1. **Вложенная вкладка «Спектра»**, а не десятая вкладка: девять вкладок закреплены в §8.
2. **Фильтр — тот же Кайзер, что в блоках `downsample/upsample/resample`**, чтобы экран показывал то, что делает конвейер.

## Global Constraints

- Всё из M6h.
- Тексты — в `ru.json` и `en.json`; `F1` открывает карточку `downsample` или `upsample`.
- Раскладка на 150×44 и 80×24.

## Review Focus

1. **M = L** (например, 3/3): fs′ = fs, без деления на ноль в формуле складывания.
2. **Тон точно на fs′/2 и выше fs/2**: формула складывания даёт правильную частоту.
3. **Файл короче 8192 отсчётов** и пустой файл: понятное сообщение.
4. **Смена файла во время просмотра**: вид пересчитывается.
5. **80×24:** панели не налезают.

### Task 1: модель ресемплинга

- `double folded_frequency(double f, double fs_out)` — |((f + fs′/2) mod fs′) − fs′/2|.
- `struct ResampleOptions { Mode mode; std::size_t m = 2, l = 2; Filter filter = on; double cutoff = 1.0; Source source = tone; double tone_hz = 1000; }`.
- `Result<ResampleView> compute_resample(const ResampleOptions&, std::span<const double> x, double fs)`: спектры, копии, АЧХ фильтра, показания.
- Тесты:
  - тон 7 кГц при ↓4 и fs = 48 кГц без фильтра даёт пик на 5 кГц, с фильтром — подавление ≥ 70 дБ;
  - ↑3 даёт два «изображения»;
  - L/M 3/2 даёт fs′ = 72 кГц;
  - формула складывания на краях.

### Task 2: экран «Ресемплинг»

- Панели, чипы режимов и клавиши: `m` — режим, `[ ]` — M, `{ }` — L, `a` — фильтр, `s` — источник, `f/F` — частота тона.
- Вложенная вкладка в `app_screens.cpp` и маршруты в `shell.cpp`.
- Тесты экрана: 150×44 и 80×24 без наложений, переключение режимов, F1, снимки.
