# Signals M7b: полировка по отложенным замечаниям — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** закрыть отложенные замечания ревью M6a–M7a, которые видит пользователь: неверные формы слов, неверные подписи и подсказки, неверные числа в сводках, медленные клики на длинных файлах.

**Architecture:** точечные правки в существующих модулях. Новое — только функция `tr_count` в `i18n` для русских форм числа (один, два–четыре, пять и больше).

**Tech Stack:** C++23, FTXUI, Catch2.

**Spec:** `docs/03-design.md` §13 M7 «Полировка»; ledgers M6a–M7a (`Final: minor (deferred)`).

**Решения плана (моё решение — пользователь может оспорить):**
1. Берутся замечания, которые пользователь видит или получает неверный результат. Недостижимые из интерфейса проверки ядра (`firls` с отрицательными весами, Бессель выше 36-го порядка) остаются отложенными.
2. Формы числа — словами-единицами: `unit.pole` = «{n} полюс / полюса / полюсов». Фраза собирает единицы: «БИХ: {poles}, {sections}».

## Global Constraints

- Всё из M7a. Комментарии в коде только там, где без них код сломают.
- Английский словарь покрывает каждый русский ключ с теми же плейсхолдерами (существующий тест).

## Review Focus

1. **Числа 11–14, 111, 0** в русских формах: «11 полюсов», «21 полюс», «0 полюсов».
2. **Английский режим** после перевода фраз на единицы: «1 pole», «2 poles», без кириллицы.
3. **Фоновая перестройка пакетов:** клик по узлу во время прошлой перестройки не теряет ни один клик и не показывает устаревший базис.
4. **Кэш уровня рамки на «Спектре»:** смена файла, канала или N не показывает старый уровень.
5. **Онсеты на коротком сигнале** (короче двух кадров) — пусто, без деления на ноль.

### Task 1: формы числа

- `std::string tr_count(std::string_view key, long long n, std::string_view shown = {})` в `src/i18n/i18n.hpp`: ключи `key.one`, `key.few`, `key.many`; `{n}` заменяется на `shown` или на `n`. Русское правило: n mod 10 = 1 и n mod 100 ≠ 11 → one; n mod 10 ∈ 2…4 и n mod 100 ∉ 12…14 → few; иначе many. Английское: 1 → one, иначе many.
- Тест ключей ищет и `tr_count("…"` и требует все три формы.
- Перевести на единицы: полюсы и биквады («Фильтры»), копии и отводы («Ресемплинг»), варианты и итерации («Конструктор»), полосы («Разложение»), кадры и отсчёты («Сигнал», «Спектр»), уровни и отсчёты (`lift53`, `bad_band`), разбиения (`signals design`), ядра в строке состояния (родительный: «от 1 ядра», «от 8 ядер»), «прорежен в 2 раза».
- Тесты: правило на 0, 1, 2, 4, 5, 11, 12, 14, 21, 22, 25, 101, 111; экранный тест «4 полюса, 2 биквада».

### Task 2: подписи и подсказки

- `idwt`/`iswt`/`ilift53` называют правильное обратное преобразование по `transform` коэффициентов (`lift53` → `ilift53`).
- Заголовок спектра на «Матрице» не пишет «AᵀA», когда значения — σ(A).
- Карточка матрицы для «Тёплиц + Ганкель» не говорит «не квадратная».
- «Ресемплинг»: строка «обход» в ↑L говорит об изображениях, а не о копиях; `F1` в L/M открывает карточку ↑, когда L > M.
- Справка `signals denoise --rule` перечисляет все четыре правила.
- Сохранение своего фильтра показывает, под каким именем файл сохранён.

### Task 3: числа и ядро

- «Обработка»: удалённая энергия не уходит ниже 0 % и выше 100 %; «сохранено» не считает заглушённые полосы.
- Онсеты отмечаются в начале скачка (без смещения на −n/4).
- `istft` отказывает при нарушении NOLA; `xcorr` отказывает при разной частоте дискретизации.
- `display_width` не считает комбинирующие знаки столбцом (Φ̃, Ψ̂).

### Task 4: отклик

- Пакеты: перестройка после клика по узлу и `B`/`W` идёт задачей в фоне, а не в потоке интерфейса.
- «Спектр»: средний уровень рамки кэшируется по рамке и виду; Уэлч не пересчитывается при смене N.
