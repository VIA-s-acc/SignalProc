# Signals M7a: документация пользователя — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** документация пользователя из §13 M7, которая не устаревает: справочники генерируются из кода, тест сверяет файлы с генератором.

**Architecture:**
- `signals blocks [--markdown]` печатает блоки конвейера: порты, параметры, значения по умолчанию, диапазоны и варианты. Источник — реестр блоков и словарь i18n.
- `signals keys [--markdown]` печатает клавиши каждой вкладки и вложенной вкладки. Источник — `hints()` экранов, тех же, что в TUI.
- Файлы `docs/user/blocks.md`, `blocks.en.md`, `keys.md`, `keys.en.md` проверяются тестом против генераторов.
- README ссылается на них вместо ручных списков.

**Spec:** `docs/03-design.md` §13 M7 «документация пользователя».

## Global Constraints

- Тексты справочников — через i18n; файлы генерируются, руками не правятся.

## Review Focus

1. Новый блок или клавиша без перегенерации — тест падает с подсказкой, какую команду запустить.
2. Английская версия не содержит кириллицы.
3. Символ `|` в значениях не ломает таблицу Markdown.
