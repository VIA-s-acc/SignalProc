# Практическое занятие 1: свёртка, матрица Тёплица и простейшие фильтры

Пример учебной работы с Signals. В ноутбуке [`Практическое_занятие_1.ipynb`](Практическое_занятие_1.ipynb) задания решены на Python (numpy и matplotlib), а в приложении те же задания повторены в Signals: через командную строку и по шагам в интерфейсе.

Графы к приложению:

- [`zadanie1.sig`](zadanie1.sig): полная свёртка $x=[2,-1,3,1]$ с $h_0=[1/2,1/2]$ и $h_1=[1/2,-1/2]$;
- [`zadanie5.sig`](zadanie5.sig): сумма двух синусоид через те же фильтры и пики спектра входа и выходов.

```bash
cd examples/prak1
signals run zadanie1.sig
signals tui
```

В интерфейсе: `8`, `o`, `zadanie1.sig`, `Enter`, `r`, затем `v` два раза, чтобы щуп показал отсчёты числами.
