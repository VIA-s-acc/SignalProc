# Энтропия полосы квантованных коэффициентов

Сигнал `x` — `gen` с `kind=doppler`, `rate=1024`, `duration=1`. Его раскладывают `dwt` (`wavelet=db4`, `levels=5`, `ext=periodization`) и квантуют коэффициенты блоком `coeff_quantize` с `mode=bits`, `bits={{b}}`. Блок `coeff_stats` считает по полосам энтропию Шеннона в битах. Чему равна энтропия полосы $d_3$? Допуск 0,005 бита.

Энтропию `coeff_stats` считает по распределению энергии: $p_i = c_i^2 / \sum_k c_k^2$, $H = -\sum_i p_i \log_2 p_i$. Это та же стоимость, по которой `wpt` выбирает лучший базис.

## Подсказки {#hints}

1. Соберите `gen → dwt → coeff_quantize → coeff_stats` и запустите; в отчёте у полосы `d3` поле `entropy`.
2. Границы значений: если вся энергия в одном коэффициенте, $H = 0$; если она поровну во всех $L$ коэффициентах полосы, $H = \log_2 L$. Длина $d_3$ при 1024 отсчётах и периодизации равна 128, значит $H \le 7$ бит.
3. Сравните с другими полосами: чем гуще энергия собрана в немногих коэффициентах, тем меньше $H$.

## Разбор {#solution}

Энтропия $d_3$ при `bits` = {{b}}: {{expected}} бит.

Энтропия энергии — мера того, насколько вейвлет-коэффициенты разрежены: малая $H$ означает, что почти вся энергия в немногих коэффициентах, и их достаточно оставить при сжатии ({#audio-compression}). Квантование почти не меняет это число: оно округляет коэффициенты, но крупные остаются крупными, а мелкие уходят в ноль и не вносят вклада в энергию. Поэтому у полос деталей гладкого сигнала $H$ заметно ниже предельных $\log_2 L$.
