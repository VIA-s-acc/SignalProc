# Компоненты КМА складываются в сигнал

Кратномасштабный анализ (КМА) возвращает каждую полосу разложения во временную область: блок `mra` с `component=d1` даёт вклад деталей первого уровня в виде сигнала той же длины. Соберите КМА сигнала `x = [{{x}}]`: после `dwt` (Хаар, 3 уровня, узел `w`) возьмите компоненты всех полос — $a_3, d_3, d_2, d_1$ — и сложите блоками `add`. Сумма — узел `sum`; она должна совпасть с `x`. Узлы `x` и `w` не меняйте. Заготовка берёт только $d_1$.

## Цели {#goals}

1. Сумма равна входу: $\max|\mathrm{sum} - x| \le 10^{-12}$ без задержки — на вашем сигнале и на скрытых.
2. В графе не меньше четырёх блоков `mra`.
3. Каждый путь от `x` к `sum` проходит через `mra`.
4. Без блоков обратного преобразования (`idwt`, `iswt` и подобных).

## Подсказки {#hints}

1. У `add` два входа, `a` и `b`; четыре компоненты складываются в три сумматора, например $(a_3 + d_3) + (d_2 + d_1)$.
2. Блок `mra` выбирает полосу параметром `component`: `a3`, `d3`, `d2`, `d1`. Все четыре берут вход `w`.
3. Если одной полосы не хватает, ошибка будет ровно равна вкладу этой полосы: проверьте, что подключены все четыре.

## Разбор {#solution}

Ошибка на эталонном решении: {{m.err}}.

Разложение линейно, и каждая компонента — результат синтеза из одной полосы при нулевых остальных. Поэтому сумма $a_3 + d_3 + d_2 + d_1$ — синтез из всех полос, то есть сам сигнал. Это и есть КМА: сигнал распадается на независимые по масштабу слагаемые, каждое видно во времени, и их можно править по отдельности ({#wav-mra}). Если убрать одну, пропадёт её масштаб из сигнала.
