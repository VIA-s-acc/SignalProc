# Частота чирпа в заданный момент

Линейный чирп: `chirp` с `method=linear`, частота растёт от $f_0 = {{f0}}$ Гц до $f_1 = {{f1}}$ Гц за 1 с при `rate=1000`. На какой частоте, в герцах, он звучит в момент $t = {{k}}$ мс (отсчёт с номером {{k}})? Прочитайте её с гребня синхросжатого CWT: блок `sst_ridge` с `lo=30`, `hi=480`, выход `freq`. Допуск 2 %.

## Подсказки {#hints}

1. Соберите `chirp → sst_ridge` и откройте щуп на порте `freq`: это мгновенная частота сильнейшей составляющей для каждого отсчёта.
2. Нужный отсчёт — номер {{k}}; блок `cut` с `begin={{k}}` и `end` на единицу больше оставит один отсчёт.
3. Сверьтесь с формулой: у линейного чирпа частота растёт равномерно, $f(t) = f_0 + (f_1 - f_0)\,t / T$.

## Разбор {#solution}

Гребень даёт {{expected}} Гц.

Формула даёт $f_0 + (f_1 - f_0)\cdot {{k}}/1000$ при $f_0 = {{f0}}$ и $f_1 = {{f1}}$: линейный закон — одна и та же прибавка в герцах за равное время. Гребень CWT находит её без формулы, как положение максимума на скалограмме в каждый момент; синхросжатие стягивает размытый максимум в узкую линию, и частота читается точнее ({#cwt}, {#synchrosqueezing}). У самых краёв сигнала гребень менее надёжен, поэтому момент взят из середины.
