# Многочлен без деталей

Сигнал $x$ — значения многочлена второй степени $x[n] = \alpha n^2 + \beta n + \gamma$ при $n = 0 \dots 31$: `x = [{{x}}]`. Заготовка раскладывает его одноуровневым `dwt` вейвлетом Хаара. Подберите вейвлет блока `w` так, чтобы внутренние коэффициенты детали $d_1$ — отсчёты 8…11, их выдаёт узел `mid` — были нулевыми с точностью $10^{-9}$. Узлы `x` и `mid` не меняйте; нули в `mid` должны получаться из самого вейвлета, а не из правки полос.

## Цели {#goals}

1. Наибольший из внутренних коэффициентов $d_1$ (узел `mid`) не больше $10^{-9}$.
2. В графе остаётся блок `dwt`.
3. Без блоков, которые гасят или правят полосы: `gain`, `affine`, `multiply`, `band_edit`, `threshold`, `denoise`, `keep_largest`, `mra`.

## Подсказки {#hints}

1. Деталь обнуляет многочлены степени ниже числа нулевых моментов вейвлета: вейвлет с $p$ нулевыми моментами не видит многочленов степени меньше $p$, см. {#wav-vanishing-moments}.
2. Хаар имеет один нулевой момент и видит только константу. Сколько моментов нужно для степени 2? Число нулей в $z = -1$ печатает `signals filter info db3`.
3. Вейвлеты семейства `dbN` имеют $N$ нулевых моментов. Не берите слишком длинные: окно 8…11 должно лежать вдали от краёв, а у вейвлета длиннее 16 отводов его уже затрагивает граница.

## Разбор {#solution}

Подходит `db3`: у неё три нуля в $z = -1$, то есть три нулевых момента, а многочлен второй степени лежит в их пространстве, значит деталь внутри сигнала равна нулю с точностью до ошибки округления. `db2` с двумя моментами убирает линейную часть, но квадратичная остаётся, а Хаар не снимает и линейную. У краёв деталь не нулевая: продолжение сигнала за границей уже не многочлен. Поэтому проверка смотрит только на внутренние отсчёты. Подробнее — {#wav-vanishing-moments}.
