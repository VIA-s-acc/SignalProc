# Значение φ(1) у db2

Масштабирующая функция $\varphi$ вейвлета `db2` удовлетворяет уравнению двух масштабов $\varphi(t) = \sqrt2 \sum_k h[k]\,\varphi(2t - k)$ с нормировкой $\int\varphi = 1$ и носителем $[0, 3]$. Найдите $\varphi(1)$ с точностью $10^{-6}$. Ответ — число; выражения вроде `sqrt(3)` принимаются.

## Подсказки {#hints}

1. В целых точках уравнение двух масштабов — линейная система для вектора $v_n = \varphi(n)$, $n = 0 \dots 3$: $v = Mv$ с $M_{n,m} = \sqrt2\,h[2n - m]$. Нужен собственный вектор с собственным числом 1, см. {#wav-eigenvector}.
2. На краях носителя $\varphi(0) = \varphi(3) = 0$, а сумма значений в целых точках равна 1 (разбиение единицы). Остаются два неизвестных $\varphi(1)$ и $\varphi(2)$.
3. Каскадный алгоритм ({#wav-cascade}, клавиша `c` в конструкторе банка) показывает $\varphi$ приближённо и сходится медленно: на глаз вы получите только две цифры. Для шести цифр решайте систему точно.

## Разбор {#solution}

$\varphi(1) = {{expected}}$. Подставьте $t = 1$ и $t = 2$ в уравнение двух масштабов с $h = \tfrac{1}{4\sqrt2}\,(1 + \sqrt3,\ 3 + \sqrt3,\ 3 - \sqrt3,\ 1 - \sqrt3)$: получится система из двух уравнений на $\varphi(1)$ и $\varphi(2)$, а условие $\varphi(1) + \varphi(2) = 1$ выбирает нужное решение. Второе значение — $\varphi(2) = (1 - \sqrt3)/2 \approx -0{,}366$: функция принимает и отрицательные значения. Каскад из единичной дельты после десяти шагов даёт около 1,32, то есть сходится к тому же числу, но медленно (гладкость $\varphi$ у `db2` невелика). Подробнее — {#wav-eigenvector}.
