# Полифазная свёртка без ↓2

Нужно получить $y = \downarrow 2\,(h * x)$: свёртку сигнала `x` с фильтром $h$, из которой оставлены отсчёты с чётными номерами. Фильтр имеет четыре отвода: $h_0 = {{h0}}$, $h_1 = {{h1}}$, $h_2 = {{h2}}$, $h_3 = {{h3}}$. Считать нужно полифазно: сигнал и фильтр разделены на чётные и нечётные части, все фильтры работают на половинной частоте, а блока `downsample` в графе нет. Выход — узел `y`. Узел `x` не меняйте: проверка подаст в него и другие сигналы.

В заготовке уже есть разделение сигнала блоком `polyphase` и два фильтра по два отвода: чётные отводы $h_0, h_2$ для чётной части сигнала, нечётные $h_1, h_3$ для нечётной. Результат пока неверен.

## Цели {#goals}

1. Выход `y` совпадает с $\downarrow 2\,(h * x)$ до $10^{-12}$ — на вашем сигнале и на скрытых.
2. В графе нет `downsample`, `resample` и готовых вейвлет-блоков.
3. Каждый путь от `x` к `y` проходит через блок `polyphase`.

## Подсказки {#hints}

1. Выход $(h*x)[2n] = \sum_j h[j]\,x[2n-j]$ разбивается на чётные $j = 2k$ и нечётные $j = 2k+1$ отводы. Чётные отводы умножаются на $x[2(n-k)]$ — на чётную часть сигнала.
2. Нечётные отводы умножаются на $x[2(n-k)-1]$, а это нечётная часть $x[2m+1]$ со сдвигом: $m = n - k - 1$. Значит, нечётная ветвь должна быть задержана на один отсчёт на половинной частоте.
3. Блок `delay` с `samples=1` ставится перед фильтром `fo` в нечётной ветви; ветви складываются блоком `add`.

## Разбор {#solution}

Граф: `x → polyphase`; `even → fir_taps({{h0}} {{h2}}) → add.a`; `odd → delay(1) → fir_taps({{h1}} {{h3}}) → add.b`.

Тип-1 полифазное разложение фильтра $H(z) = E_0(z^2) + z^{-1}E_1(z^2)$, сигнала — $X(z) = X_0(z^2) + z^{-1}X_1(z^2)$. Чётные отсчёты произведения: $Y(z) = E_0(z)X_0(z) + z^{-1}E_1(z)X_1(z)$. Задержка $z^{-1}$ у нечётной ветви появляется потому, что $z^{-1} \cdot z^{-1} = z^{-2}$ — это уже сдвиг на целый отсчёт половинной частоты. Умножений вдвое меньше, чем при ↓2 после полной свёртки: выбрасываемые отсчёты не вычисляются. См. {#multirate-polyphase} и {#conv-polyphase}.
