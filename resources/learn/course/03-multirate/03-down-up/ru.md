# Прореживание, затем растяжение

Сигнал `x = [{{x}}]` проходит ↓2, а затем ↑2, оба блока без фильтров. ↓2 оставляет отсчёты с чётными номерами $x[0], x[2], \dots$ (фаза 0, как у блока `downsample` по умолчанию); ↑2 вставляет ноль после каждого отсчёта. Запишите результат: 8 чисел через пробел.

## Подсказки {#hints}

1. После ↓2 останутся четыре отсчёта: $x[0], x[2], x[4], x[6]$.
2. ↑2 ставит их на чётные места, а на нечётных будут нули: $y[2n] = x[2n]$, $y[2n+1] = 0$.
3. Проверка: отсчёты с нечётными номерами исходного сигнала теряются безвозвратно.

## Разбор {#solution}

$y = [{{expected}}]$.

В частотной записи $Y(z) = \tfrac12\left[X(z) + X(-z)\right]$: к сигналу добавляется его зеркальная копия, а нечётные отсчёты стираются. Именно эта пара «↓2, ↑2» стоит в каждой ветви банка фильтров из {#multirate-down-up}; в {#conv-pywt} описано, как фаза прореживания сдвигает результат.
