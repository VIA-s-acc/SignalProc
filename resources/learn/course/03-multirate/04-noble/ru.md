# Тождество Нобла

Ветвь A: фильтр $H(z^2)$ на полной частоте, затем ↓2. Ветвь B: сначала ↓2, затем фильтр $H(z)$ на половинной частоте. Здесь $H(z) = {{h0}} + {{h1}}z^{-1} + {{h2}}z^{-2}$, то есть отводы `h = [{{h0}} {{h1}} {{h2}}]`. Тождество Нобла утверждает, что ветви дают один и тот же результат. Соберите их так, чтобы это сошлось точно.

Узлы: в ветви A фильтр `ha`, затем `ya`; в ветви B прореживание `db`, затем фильтр `yb`. Выходы — `ya` и `yb`. Узлы `x` и `yb` не меняйте: в `x` проверка подаст и другие сигналы. Фильтры блоком `fir_taps`, прореживание без встроенного ФНЧ.

## Цели {#goals}

1. Выход фильтра `ha` совпадает с откликом $H(z^2)$ на входе `x` до $10^{-12}$ — на вашем сигнале и на скрытых.
2. Выходы `ya` и `yb` совпадают до $10^{-12}$ без сдвига.
3. В графе не меньше двух блоков `downsample`.
4. Каждый путь от `x` к `yb` проходит через прореживание ↓2.

## Подсказки {#hints}

1. Подстановка $z \to z^2$ ставит между отводами фильтра по одному нулю: из $h_0, h_1, h_2$ получается $h_0, 0, h_1, 0, h_2$.
2. Обе ветви должны брать одни и те же отсчёты. Фаза прореживания `phase` в заготовке в ветвях разная: выровняйте её.
3. Если цель 1 выполнена, а цель 2 нет, дело в ветви B: фильтр `yb` менять нельзя, значит, поправить нужно `db`.

## Разбор {#solution}

Граф: `x → fir_taps(taps="{{h0}} 0 {{h1}} 0 {{h2}}") → ↓2 → ya` и `x → ↓2 → fir_taps(taps="{{h0}} {{h1}} {{h2}}") → yb`, обе фазы равны 0. Расхождение ветвей на эталонном решении: {{m.match}}.

Выход ветви A: $y_A[n] = \sum_k h[k]\,x[2n - 2k + p]$, где $p$ — фаза. Выход ветви B: $y_B[n] = \sum_k h[k]\,x_p[n-k]$ с $x_p[n] = x[2n+p]$, то есть то же самое. Фаза должна быть общей: с разными $p$ ветви берут разные отсчёты. Фильтр на половинной частоте дешевле вдвое по умножениям, поэтому тождество используют для переноса фильтров через ↓2. См. {#multirate-noble}.
