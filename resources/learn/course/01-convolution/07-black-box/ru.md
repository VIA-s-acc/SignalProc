# Импульсная характеристика чёрного ящика

В заготовке собран небольшой граф: сигнал `x` идёт по двум веткам, которые складываются, и узел `y` оставляет первые 6 отсчётов. Граф линейный и не зависит от сдвига по времени, поэтому его полностью описывает импульсная характеристика $h[n]$ — отклик на единичный импульс $\delta = [1\ 0\ 0\ \dots]$.

Найдите первые 6 отсчётов $h[0], \dots, h[5]$ этого графа. Ответ — 6 чисел через пробел.

## Подсказки {#hints}

1. Самый прямой путь: замените значения узла `x` на `1 0 0 0 0 0 0 0`, запустите граф (`r`) и прочитайте щуп `y`.
2. Можно и без запуска: отклик суммы равен сумме откликов ветвей. Какой отклик у `fir_taps` с отводами `1 {{a}}`, и какой у цепочки «задержка, умножение»?
3. Если оба отклика попадают на один и тот же номер, они складываются.

## Разбор {#solution}

$h = [{{expected}}]$. Верхняя ветка — `fir_taps` с отводами `1 {{a}}`: её отклик на импульс — сами отводы, то есть $1$ в нуле и ${{a}}$ в позиции 1. Нижняя ветка задерживает импульс на $d = {{d}}$ и умножает на $k = {{k}}$: отклик {{k}} в позиции {{d}}. Сумматор складывает отклики по отсчётам, и если позиции совпадают, значения суммируются. Для линейной системы, не зависящей от сдвига, этого достаточно: отклик на любой вход — свёртка с $h$, раздел {#lti-convolution}.
