# Банк Хаара с испорченным f₁

В банке Хаара из задания 4.3 синтезирующий фильтр $f_1$ испорчен: после него стоит блок `invert`, то есть знак ветви деталей изменён. Вход `x = [{{x}}]`, выход банка — узел `sum`. Чему равна ошибка $\max|\hat x - x|$ по всем отсчётам (задержка нулевая)? Ответ — число; допуск $10^{-9}$.

## Подсказки {#hints}

1. Исправный банк возвращает $\hat x = x_{\text{low}} + x_{\text{high}}$, где $x_{\text{low}}$ — вклад ветви $a$, а $x_{\text{high}}$ — вклад ветви $d$. Испорченный даёт $x_{\text{low}} - x_{\text{high}}$.
2. Значит, $\hat x - x = -2\,x_{\text{high}}$. Для одной пары $(x[2n], x[2n+1])$ вклад деталей равен $\pm\tfrac12\,(x[2n+1] - x[2n])$ на двух соседних отсчётах.
3. Ошибка на паре равна $|x[2n+1] - x[2n]|$ на обоих её отсчётах; остаётся взять наибольшую по всем парам. Запустите граф и сверьтесь с проверкой `check` с `kind=error`.

## Разбор {#solution}

Ошибка: {{expected}}.

Сумма $x_{\text{low}} + x_{\text{high}}$ восстанавливает сигнал, потому что наложение двух ветвей взаимно сокращается ({#fb-distortion-alias}). Смена знака у $f_1$ ломает сокращение: $x_{\text{high}}$ входит с минусом, и ошибка равна удвоенному вкладу деталей, то есть $\max_n |x[2n+1] - x[2n]|$. Если бы сигнал был константой на каждой паре, детали были бы нулевыми, и такая поломка осталась бы незамеченной.
