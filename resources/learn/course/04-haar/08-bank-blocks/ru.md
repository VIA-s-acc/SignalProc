# Банк в своих блоках

В графе — двухуровневый банк Хаара из задания 4.6, собранный из отдельных узлов: два одинаковых шага анализа и два одинаковых шага синтеза. Вынесите шаг анализа и шаг синтеза в свои блоки (`block`) и соберите тот же банк из вызовов: каждый блок вызывается дважды. Выход банка — узел `y`; он должен вернуть вход `x = [{{x}}]` без искажений. Узел `x` не меняйте: проверка подаст в него и другие сигналы из 16 отсчётов.

## Цели {#goals}

1. Полное восстановление: $\max|\hat x - x| \le 10^{-12}$ с учётом задержки — на вашем сигнале и на скрытых.
2. В графе есть свой блок, который вызывается не меньше двух раз.
3. В раскрытом графе не меньше четырёх блоков `downsample` и четырёх блоков `upsample`.
4. Без готовых вейвлет-преобразований.

## Подсказки {#hints}

1. Шаг анализа — это $h_0 \to \downarrow 2$ и $h_1 \to \downarrow 2$ от одного входа: у блока один вход `x` и два выхода `a` и `d`. Шаг синтеза — ↑2, $f_0$, $f_1$ и сумма: два входа `a`, `d` и выход `y`.
2. Быстрее всего — отметить узлы одного шага клавишей `m` и свернуть их клавишей `b`: программа сама сделает порты из проводов через границу. Второй вызов добавьте из списка `a` — блок там в группе своих блоков. Правила записи — в разделе {#sig-own-blocks}.
3. Соединения: `x → an1`, `an1.a → an2`, выходы `an2` — во внутренний синтез, его выход и `an1.d` — во внешний синтез `y`. Проверка смотрит внутрь вызовов, поэтому четыре ↓2 и четыре ↑2 считаются по раскрытому графу.

## Разбор {#solution}

Ошибка восстановления на эталонном решении: {{m.err}}.

Блок `analysis` описывает один шаг $h_0, h_1, \downarrow 2$, блок `synthesis` — один шаг $\uparrow 2, f_0, f_1, +$. Двухуровневый банк — те же шаги, вызванные дважды: внешний анализ раскладывает $x$, внутренний — приближение $a_1$, а синтез идёт в обратном порядке. При раскрытии вызовы превращаются ровно в те узлы, что были в графе, поэтому числа не меняются ({#haar-multilevel}). Параметр `w` со значением `haar` по умолчанию позволяет вызвать те же блоки с другим вейвлетом, не трогая определений. Один большой блок со всем банком внутри вызывается лишь раз и цель про два вызова не проходит.
