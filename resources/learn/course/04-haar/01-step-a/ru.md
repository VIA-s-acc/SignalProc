# Haar: коэффициенты a вручную

Один шаг анализа Хаара: сигнал `x = [{{x}}]` проходит через фильтр $h_0$ (полная свёртка, $h_0 = [\tfrac{1}{\sqrt2}, \tfrac{1}{\sqrt2}]$), затем остаются отсчёты по нечётным местам: $\downarrow 2$ с `phase=1`, как в программе и в PyWavelets ({#conv-pywt}). Найдите коэффициенты приближения $a$. Ответ — вектор из чисел через пробел; число может быть выражением, например `sqrt(2)/2`. Допуск $10^{-9}$.

## Подсказки {#hints}

1. Полная свёртка с $h_0$ даёт $y[k] = \tfrac{1}{\sqrt2}\,(x[k] + x[k-1])$, где $x[-1] = 0$.
2. `phase=1` оставляет $y[1], y[3], y[5], y[7]$: в каждом из них суммируются две соседние пары без нулевых краёв.
3. Значит, $a[n]$ зависит только от $x[2n]$ и $x[2n+1]$. Проверка: $\sum a^2$ не больше $\sum x^2$, а вместе с деталями из задания 4.2 они равны.

## Разбор {#solution}

$a = [{{expected}}]$.

$a[n] = (x[2n] + x[2n+1])/\sqrt2$: каждая пара соседних отсчётов заменяется их суммой, делённой на $\sqrt2$. Это шаг {#haar-walkthrough}. Фаза 1 выбрана так, что в выходе нет краевых отсчётов с половиной пары: свёртка длиннее входа на один отсчёт, и лишний хвост при нечётной фазе отбрасывается.
