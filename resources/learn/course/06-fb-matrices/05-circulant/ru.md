# Собственные числа циркулянта

Фильтр `h = [{{a}} {{b}} {{c}}]`, дополненный нулём до длины $N = 4$, задаёт циркулянт $C(h)$ размера $4 \times 4$: круговую свёртку с $h$. Найдите модули его собственных чисел $|\lambda_0|, |\lambda_1|, |\lambda_2|, |\lambda_3|$ в порядке частот $k = 0, 1, 2, 3$. Ответ — четыре числа через пробел; допустимы выражения вроде `sqrt(5)`. Допуск $10^{-6}$.

## Подсказки {#hints}

1. Все циркулянты диагонализует одно и то же преобразование Фурье, а собственные числа $C(h)$ — это ДПФ вектора $h$: $\lambda_k = \sum_n h[n]\, e^{-2\pi i kn/N}$, см. {#toeplitz-circulant}.
2. При $N = 4$ множители $e^{-2\pi i kn/4}$ принимают значения $1, -i, -1, i$. Для $k = 0$ это сумма отсчётов, для $k = 2$ знакочередующаяся сумма; для $k = 1$ и $k = 3$ нужен модуль комплексного числа.
3. Циркулянт нормален, поэтому его сингулярные числа — те же модули $|\lambda_k|$. Вкладка «Матрица» показывает их по убыванию (клавиша `s`), но порядок по $k$ придётся восстановить самому.

## Разбор {#solution}

Ответ: {{expected}} (модули для $k = 0, 1, 2, 3$). Здесь $\lambda_0 = h_0 + h_1 + h_2$, $\lambda_2 = h_0 - h_1 + h_2$, а $\lambda_{1,3} = h_0 - h_2 \mp i\,h_1$, так что $|\lambda_1| = |\lambda_3| = \sqrt{(h_0 - h_2)^2 + h_1^2}$. Вещественный фильтр даёт сопряжённую пару на $k$ и $N - k$ с равными модулями. Собственные числа циркулянта — значения частотной характеристики $H(e^{i\omega})$ в $N$ равноотстоящих точках: спектр матрицы и частотная характеристика фильтра — одно и то же. См. {#toeplitz-circulant} и {#fbm-periodization}.
