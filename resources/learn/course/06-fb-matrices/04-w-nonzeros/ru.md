# Ненулевые элементы многоуровневой W

Многоуровневая матрица $W_J$ банка Хаара для сигнала из $N = {{n}}$ отсчётов и $J = {{j}}$ уровней (периодизация) — квадратная $N \times N$; её строки — базисные функции $a_J, d_J, \dots, d_1$. Сколько в ней ненулевых элементов? Ответ — целое число.

## Подсказки {#hints}

1. Столбец $j$ матрицы — коэффициенты всех полос для единичного импульса в позиции $j$. Сколько ненулевых коэффициентов в каждой полосе, если вейвлет — Хаар? См. {#fbm-multilevel}.
2. Сосчитайте по строкам: строка полосы $d_k$ имеет носитель длины $2^k$, строка $a_J$ — длины $2^J$; сколько строк в каждой полосе?
3. Проверьте на вкладке «Матрица»: операция «многоуровневая», вейвлет Хаара, нужные $N$ и $J$.

## Разбор {#solution}

Ненулевых элементов {{expected}}. Каждый из $J$ детальных уровней даёт $N$ ненулевых элементов: $N/2^k$ строк по $2^k$ штук. Те же $N$ даёт полоса $a_J$: $N/2^J$ строк по $2^J$. Итого $N(J + 1)$; плотная матрица содержала бы $N^2$ элементов, поэтому доля ненулевых — $(J + 1)/N$. Ту же цифру даёт столбцовый подсчёт: у каждого импульса ровно один ненулевой коэффициент в каждой из $J + 1$ полос. Подробнее — {#fbm-multilevel}.
