# Энергия после матрицы анализа

Матрица анализа $A$ банка `{{wv}}` при $N = 16$ с периодизацией — квадратная, $16 \times 16$: вектор $Ax$ собирает все коэффициенты полос $a$ и $d$ одного уровня. Для сигнала `x = [{{x}}]` найдите квадрат нормы $\|Ax\|^2 = \sum_k (Ax)_k^2$ — суммарную энергию всех коэффициентов. Ответ — число.

## Подсказки {#hints}

1. Банк `{{wv}}` ортогональный. Откройте вкладку «Матрица» и сравните $A^{\mathsf T}A$ с единичной матрицей, см. {#fbm-periodization}.
2. Для ортогональной матрицы $\|Ax\|^2 = x^{\mathsf T}A^{\mathsf T}Ax$. Чему это равно, если $A^{\mathsf T}A = I$?
3. Получившееся число вычисляется по $x$ в уме или на калькуляторе, сами коэффициенты искать не нужно. Сверьтесь прогоном в «Конвейере»: `dwt` с периодизацией, один уровень.

## Разбор {#solution}

$\|Ax\|^2 = {{expected}}$. Банк ортогональный, поэтому $A^{\mathsf T}A = I$ и $\|Ax\|^2 = x^{\mathsf T}x = \sum_n x[n]^2$: энергия отсчётов сохраняется при любом числе нулевых моментов и любой длине фильтра — это равенство Парсеваля для преобразования с периодизацией, где матрица квадратная. Для биортогонального банка оно уже не выполняется: там $A^{\mathsf T}A \ne I$. См. {#fbm-periodization} и {#met-parseval}.
