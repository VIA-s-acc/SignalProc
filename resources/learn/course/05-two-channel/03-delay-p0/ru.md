# Задержка ℓ из полуполосного P₀

После выбора синтеза $F_0(z) = H_1(-z)$, $F_1(z) = -H_0(-z)$ полное восстановление равносильно условию $P_0(z) - P_0(-z) = 2z^{-\ell}$ для $P_0 = F_0 H_0$ ({#fb-alias-cancellation}). Пусть $P_0$ — симметричный многочлен степени {{deg}} по $z^{-1}$ (его коэффициенты $p_0[k] = p_0[{{deg}} - k]$, полная свёртка, без прореживания). Чему равна задержка $\ell$? Ответ — целое число.

## Подсказки {#hints}

1. Условие значит: у $P_0$ ровно один ненулевой коэффициент с нечётным номером, $p_0[\ell] = 1$; чётные коэффициенты любые.
2. Симметрия $p_0[k] = p_0[{{deg}} - k]$ переводит нечётный коэффициент в нечётный. Единственный нечётный коэффициент должен перейти сам в себя.
3. Значит, он стоит в центре многочлена. Сравните с банком db2 из задания 4.4: там степень равна 6, и банк отстаёт на $\ell - 1$ отсчётов, а не на $\ell$ — из-за фазы прореживания.

## Разбор {#solution}

$\ell = {{expected}}$.

Симметричный многочлен степени $n$ симметричен относительно индекса $n/2$, поэтому единственный нечётный коэффициент стоит в центре: $\ell = n/2$, и для этого $n/2$ должно быть нечётным. Для $n = 6$ это $\ell = 3$: так у db2 и у всякого фильтра длины $L = 4$, где $n = 2L - 2$ и $\ell = L - 1$. В задании 4.4 измерена задержка 2 — на отсчёт меньше, потому что прореживание с `phase=1` берёт $x[2n+1]$ и тем самым опережает сигнал; без фазового сдвига (`phase=0`) измеренная задержка равна $\ell$ ({#fb-distortion-alias}).
