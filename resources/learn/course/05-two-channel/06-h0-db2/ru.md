# h₀ ортогонального разбиения db2

Среди 20 разбиений $P_0$ степени 6 есть два ортогональных, зеркальных друг другу, с $H_0$ и $F_0$ длины 4. Найдите отводы $h_0$ фильтра анализа db2 в том порядке, в каком их хранит программа (`db2.h0`): четыре числа по порядку времени, первое отрицательное. Нормировка $\sum h_0 = \sqrt2$, $\sum h_0^2 = 1$. Сверьтесь с `signals filter info db2`. Допуск $10^{-9}$.

## Подсказки {#hints}

1. У $H_0$ два нуля в $z = -1$: $H_0 \propto (1 + z^{-1})^2 (1 - s z^{-1})$ с одним корнем $s$ из пары $\{r, 1/r\}$, $r = 2 - \sqrt3$.
2. Для ортогонального банка $\sum h_0[n]h_0[n+2k] = \delta_k$ ({#fb-cqf}): при нормировке $\sum h_0 = \sqrt2$ сумма квадратов равна 1, а сумма $h_0[0]h_0[2] + h_0[1]h_0[3]$ равна нулю.
3. Каждый отвод содержит $\sqrt3$ в первой степени: решите систему из условия суммы и ортогональности. Если вышло зеркальное решение (первый отвод положителен), запишите его в обратном порядке.

## Разбор {#solution}

$h_0 = [{{expected}}]$.

Это $\dfrac{1}{4\sqrt2}\left(1 - \sqrt3,\ 3 - \sqrt3,\ 3 + \sqrt3,\ 1 + \sqrt3\right)$. Сумма: $\tfrac{8}{4\sqrt2} = \sqrt2$; сумма квадратов: 1; $h_0[0]h_0[2] + h_0[1]h_0[3] = 0$. Второе ортогональное разбиение — тот же фильтр, записанный в обратном порядке; в ответ оно не засчитывается.
