## Назначение

Записать сигнал в WAV-файл целочисленным PCM (16, 24 или 32 бита) или float32. Целочисленная запись квантует отсчёты, при желании добавляет дизеринг и считает, сколько отсчётов вышло за шкалу и было срезано.

## Формулы

Квантование на $b$ бит со срезом (насыщением) и дизерингом $\delta$:

$$q[n] = \min\left(2^{b-1}-1,\; \max\left(-2^{b-1},\; \operatorname{round}\left(2^{b-1}\,x[n] + \delta[n]\right)\right)\right)$$

$$\delta[n] = u_1[n] - u_2[n], \qquad u_1,\, u_2 \text{ независимы и равномерны на } [0, 1)$$

Разность двух равномерных величин имеет треугольную плотность на $(-1, 1)$ шагов (дизеринг TPDF); без дизеринга $\delta = 0$. Шаг квантования — один младший разряд, $\Delta = 1$. Мощность шума квантования в $\Delta^2$:

$$\sigma_0^2 = \frac{1}{12}, \qquad \sigma_{\mathrm{TPDF}}^2 = \frac{1}{12} + \frac{1}{6} = \frac{1}{4}$$

Отношение сигнал/шум для синуса полной шкалы:

$$\mathrm{SNR}_0 \approx 6{,}02\,b + 1{,}76 \;\text{дБ}, \qquad \mathrm{SNR}_{\mathrm{TPDF}} \approx 6{,}02\,b - 3{,}01 \;\text{дБ}$$

Float32 не квантуется и не срезается: $y[n] = \operatorname{fl}_{32}(x[n])$, $\lvert y - x \rvert \le 2^{-24} \lvert x \rvert$.

## Алгоритм и стоимость

1. Проверка до записи: от 1 до 256 каналов одной длины, целая положительная частота дискретизации, все отсчёты конечны. Иначе ошибка, и файл не создаётся.
2. Формат переводится в пару (тег, число бит): поддержаны pcm_s16, pcm_s24, pcm_s32 и float32.
3. Кадры идут блоками по $2^{16}$; в кадре отсчёты каналов следуют друг за другом, каждый масштабируется на $2^{b-1}$, получает дизеринг, округляется, срезается и пишется в порядке little-endian.
4. Выход за шкалу приводит к насыщению и увеличивает счётчик срезанных отсчётов; обёртки с переполнением нет.
5. При сбое записи удаляется только файл, созданный этим вызовом, чужой файл по тому же пути остаётся.

Время $O(N\,C)$, память — один блок $2^{16}\,C\,b/8$ байт. Дизеринг тратит два числа mt19937_64 на отсчёт; зерно фиксировано, поэтому два запуска дают один и тот же файл.

## С числами этого блока

Формат {{block.format}}, дизеринг TPDF: {{block.dither}}. Шаг квантования — $\Delta = 2^{1-b}$ от полной шкалы, где $b$ — число бит формата. Без дизеринга шум имеет мощность $\Delta^2/12$ и коррелирует с сигналом; с дизерингом — $\Delta^2/4$, но он не зависит от сигнала.

Срезано отсчётов: {{metric.clipped}}. Не ноль означает, что сигнал вышел за $[-1, 1)$; срезанные отсчёты искажены, их нужно было уменьшить усилением или нормализацией до записи.

## Проверки

—

Тесты проверяют, что целочисленные форматы возвращают сигнал с точностью до половины младшего разряда, а float32 — до точности float. Выход за шкалу срезается и считается, но не оборачивается. Не конечные отсчёты и неверные буферы или форматы отклоняются до записи, файл не появляется. Запись по умолчанию 24-битная. Дизеринг детерминирован по зерну, мал по амплитуде и не смещает среднее. Неудачная запись не удаляет уже существующий файл. Высокие частоты дискретизации и предельное число каналов проходят туда и обратно.

## Реализация

Квантование одного отсчёта: масштаб, дизеринг TPDF, округление и насыщение со счётчиком срезов.

```cpp
        double v = x * scale_;
        if (dither_) {
            const double d1 = uniform_(rng_);
            const double d2 = uniform_(rng_);
            v += d1 - d2;
        }
        double q = std::round(v);
        if (q < -scale_) {
            q = -scale_;
            ++clipped_;
        } else if (q > scale_ - 1.0) {
            q = scale_ - 1.0;
            ++clipped_;
        }
        put(static_cast<std::uint64_t>(static_cast<std::int64_t>(q)), out);
```
