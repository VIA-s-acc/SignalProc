## Назначение

Менять во времени один параметр звука по закону медленного генератора (LFO) или самого входа: `tremolo` — громкость, `modulated_delay` — задержку (хорус, флэнжер, вибрато), `phaser` — фазу цепочки фазовых звеньев, `am` и `fm` — амплитуду и частоту несущей, которую модулирует вход.

## Формулы

Фаза LFO частоты $f_r$ считается по номеру отсчёта: $\phi_k = 2\pi f_r k/f_s$, $\tau = \phi_k \bmod 2\pi$. Формы: синус $L = \sin\phi_k$; меандр $L = 1$ при $\tau < \pi$, иначе $-1$; треугольник $L = 2\tau/\pi - 1$ при $\tau < \pi$, иначе $3 - 2\tau/\pi$ (начинается с $-1$, как `scipy.signal.sawtooth(φ, 0.5)`).

Тремоло с глубиной $D$ — усиление ходит между $1 - D$ и $1$:

$$y_k = x_k\big(1 - \tfrac12 D\,(1 - L(\phi_k))\big)$$

Модулированная задержка (LFO всегда синус) от $B$ до $B + \Delta$ мс, линейная интерполяция по линии $v$, где $v[i] = 0$ при $i < 0$:

$$d_k = \max\big(1, (B + \Delta\,\tfrac{1 + \sin\phi_k}{2})\,f_s/1000\big), \qquad i = \lfloor k - d_k \rfloor, \quad \alpha = k - d_k - i$$

$$w_k = (1-\alpha)\,v[i] + \alpha\,v[i+1], \qquad v_k = x_k + g\,w_k, \qquad y_k = (1-m)\,x_k + m\,w_k$$

Хорус: $g = 0$; флэнжер: $g$ = `feedback`; вибрато: $g = 0$ и $m = 1$ (параметр `mix` не действует).

Фэйзер: частота излома скользит геометрически от $f_{lo}$ к $f_{hi}$ и обратно, коэффициент пересчитывается на каждом отсчёте:

$$f_c(k) = f_{lo}\big(f_{hi}/f_{lo}\big)^{(1 - \cos\phi_k)/2}, \qquad a_k = \frac{t - 1}{t + 1}, \quad t = \tan\frac{\pi f_c(k)}{f_s}$$

$S$ одинаковых звеньев $A(z) = \dfrac{a + z^{-1}}{1 + a z^{-1}}$, $\lvert A\rvert = 1$, фаза $-\pi/2$ на $f_c$ (у §9.8 знак коэффициента обратный: $a_{\text{книга}} = -a$). Вход цепочки $u_k = x_k + g\,s_{k-1}$, где $s$ — выход последнего звена, выход $y_k = (1-m)\,x_k + m\,s_k$. При $m = 1/2$ и $g = 0$ провалы там, где фаза цепочки равна нечётному кратному $\pi$: $\lfloor S/2 \rfloor$ провалов внутри полосы.

AM и FM — вход $x$ модулирует несущую $f_c$ с девиацией $\Delta f$:

$$y_k^{\mathrm{AM}} = (1 + D\,x_k)\cos\frac{2\pi f_c k}{f_s}, \qquad y_k^{\mathrm{FM}} = \cos\Big(\frac{2\pi f_c k}{f_s} + \frac{2\pi\,\Delta f}{f_s}\sum_{j=0}^{k-1} x_j\Big)$$

У AM спектр — линия несущей и копии $\tfrac{D}{2}X$ на $\pm f_c$; при $D\max\lvert x\rvert > 1$ огибающая меняет знак (перемодуляция). У FM сумма идёт до $k-1$: текущий отсчёт входит в фазу следующего; мгновенная частота $f_c + \Delta f\,x_k$, для тона $f_m$ индекс $\beta = \Delta f/f_m$, полоса по Карсону $\approx 2(\Delta f + f_m)$.

## Алгоритм и стоимость

1. Фаза LFO и несущей вычисляется заново из $k$, без накопления, поэтому не дрейфует.
2. Тремоло и AM — одно умножение на отсчёт; FM копит бегущую сумму входа.
3. Модулированная задержка пишет в линию длины всего сигнала и читает её между двумя соседними отсчётами.
4. Фэйзер на каждом отсчёте берёт один $\tan$, затем прогоняет $S$ звеньев прямой формы, сохраняя их состояние.
5. Каналы обрабатываются независимо; без частоты дискретизации блоки отказывают, фэйзер — также при $f_{lo}$ или $f_{hi}$ не ниже Найквиста.

Стоимость $O(N)$ на канал для тремоло, задержки, AM и FM и $O(SN)$ для фэйзера; память $O(N)$ (выход и линия задержки).

## Проверки

- `tremolo` (три формы, 7 Гц, глубина 0,8), `modulated_delay` (хорус, два флэнжера, в том числе с обратной связью $-0{,}8$ и базой 0, вибрато) и `phaser` (4 звена 200–2000 Гц; 12 звеньев 3000→100 Гц с обратной связью $-0{,}7$) совпадают с построчными эталонами на Python из `tools/gen_golden.py` до $10^{-12}$.
- `am` совпадает с `(1 + 0.6x)·cos` на numpy до $10^{-12}$, `fm` — с формулой через `cumsum` без текущего отсчёта до $10^{-10}$; при нулевом входе `fm` даёт чистую несущую до $10^{-15}$.
- Вибрато не зависит от `mix`; `mix` = 0 у задержки и глубина 0 у тремоло возвращают вход точно; фэйзер отклоняет `max_hz` = 4000 при $f_s$ = 8000; без частоты дискретизации `tremolo` и `fm` отказывают.

## Реализация

Шаг фэйзера: новый коэффициент из скользящей частоты излома и проход по цепочке фазовых звеньев.

```cpp
        const double fc = lo * std::pow(hi / lo, (1 - std::cos(phase(rate, k, fs))) / 2);
        const double t = std::tan(kPi * fc / fs);
        const double a = (t - 1) / (t + 1);
        double u = x[k] + feedback * last;
        for (std::size_t s = 0; s < stages; ++s) {
            const double v = a * (u - ys[s]) + xs[s];
            xs[s] = u;
            ys[s] = v;
            u = v;
        }
```
