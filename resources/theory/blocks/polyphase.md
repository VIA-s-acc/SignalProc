## Назначение

Разложить сигнал на чётные и нечётные отсчёты и собрать обратно: `polyphase` выдаёт две фазы на половинной частоте, `ipolyphase` чередует их в исходный сигнал. Это основа полифазной записи банков фильтров и быстрых дециматоров.

## Формулы

Фазы сигнала длины $N$, как в §0.5:

$$e[n] = x[2n], \qquad o[n] = x[2n+1], \qquad X(z) = E(z^2) + z^{-1} O(z^2)$$

Длины $\lceil N/2\rceil$ и $\lfloor N/2\rfloor$, частота каждой фазы $f_s/2$. Фильтра нет, поэтому каждая фаза по отдельности содержит наложение:

$$E(z^2) = \frac{X(z) + X(-z)}{2}, \qquad z^{-1} O(z^2) = \frac{X(z) - X(-z)}{2}$$

При сборке $y[2n] = e[n]$, $y[2n+1] = o[n]$ слагаемые с $X(-z)$ сокращаются, и $y = x$ точно, без округлений.

## Алгоритм и стоимость

1. `polyphase`: один проход по каждому каналу, отсчёт с чётным номером уходит в `even`, с нечётным — в `odd`; частота выходов — $f_s/2$.
2. `ipolyphase` проверяет, что у фаз одинаковые частота и число каналов и что $\lvert e\rvert - \lvert o\rvert$ равно 0 или 1; затем чередует отсчёты, частота выхода — $2 f_s$.

Стоимость $O(N)$ без арифметики; память — копия сигнала.

## С числами этого блока

Параметров нет: из $N$ отсчётов получаются фазы длины $\lceil N/2\rceil$ и $\lfloor N/2\rfloor$. Время узла {{block.wall}}, память {{block.bytes}}.

## Проверки

- Стерео $(1, 2, 3, 4, 5)$ и $(-1, -2)$ на 1000 Гц даёт `even` $= (1, 3, 5), (-1)$ и `odd` $= (2, 4), (-2)$ на 500 Гц; `ipolyphase` возвращает те же каналы и 1000 Гц.
- Разбиение и сборка эталонного сигнала совпадают с входом побитно.
- `ipolyphase` отклоняет фазы длин 3 и 1, разное число каналов и разные частоты.

## Реализация

Разбиение одного канала: чётные отсчёты в одну фазу, нечётные — в другую.

```cpp
    for (const auto& c : a.channels) {
        Samples e((c.size() + 1) / 2), o(c.size() / 2);
        for (std::size_t i = 0; i < c.size(); ++i) (i % 2 ? o[i / 2] : e[i / 2]) = c[i];
        even.channels.push_back(std::move(e));
        odd.channels.push_back(std::move(o));
    }
```
