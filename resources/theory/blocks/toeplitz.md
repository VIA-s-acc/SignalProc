## Назначение

Показать свёртку $y = h * x$ матрицей: ленточной тёплицевой для линейной свёртки и циркулянтом для круговой. Видно, откуда берётся диагональная структура банков фильтров и почему циркулянт умножается быстро.

## Формулы

Линейная свёртка — нижнетреугольная ленточная матрица ширины $L$:

$$y = T_h\, x, \qquad (T_h)_{ij} = h[i-j], \qquad T_h \in \mathbb R^{(N+L-1) \times N}, \qquad T_g T_h = T_{g * h}$$

Круговая свёртка — циркулянт, диагонализуемый DFT:

$$C = \operatorname{circ}(c), \qquad C_{ij} = c[(i-j) \bmod N], \qquad C = F^{-1} \operatorname{diag}(\hat c)\, F, \qquad \lambda_k = \hat c[k]$$

Следствия: $Cx = F^{-1}(\hat c \cdot \hat x)$ с поэлементным произведением спектров, $\|C\|_2$ равна наибольшему $\lvert \hat c \rvert$, а число обусловленности — отношению наибольшего $\lvert \hat c \rvert$ к наименьшему.

## Алгоритм и стоимость

1. Матрица свёртки: столбец $j$ — копия $h$, сдвинутая на $j$ позиций вниз. Ненулевых элементов $NL$, лента — $L$ диагоналей.
2. Циркулянт: отводы $h$ складываются по индексу $(\text{смещение} + k) \bmod N$ в вектор $c$; столбец $j$ — его циклический сдвиг на $j$.
3. Плотные матрицы строятся только для режима объяснений и тестов. Умножение на $T_h$ — прямая свёртка за $O(NL)$; умножение на $C$ — вещественное FFT, $\hat c \cdot \hat x$ и обратное FFT за $O(N \log N)$ вместо $O(N^2)$ плотных.

Квадратные усечения $T_h$ не замкнуты относительно произведения: $T_g T_h = T_{g * h}$ точно только для полных прямоугольных матриц.

## С числами этого блока

Фильтр {{block.filter}}, лента из $L = {{block.band_width}}$ диагоналей, сигнал длины $N = {{block.n}}$. Матрица свёртки имеет $N + L - 1$ строк и $N$ столбцов, циркулянт — $N \times N$; на экране показана матрица {{block.rows}} × {{block.cols}}.

Ненулевых элементов в матрице свёртки $N \cdot L$; в циркулянте — не больше $N \cdot L$ (при $L > N$ отводы складываются).

## Проверки

- Умножение на циркулянт через FFT совпадает с плотным произведением $Cx$, наибольшее отклонение: {{check.circulant_fft}}
- Плотное $T_h x$ равно прямой свёртке; для полных матриц $T_g T_h = T_{g * h}$ (тест).
- Собственные числа плотного $C$ совпадают с FFT от первого столбца $c$.

## Реализация

Матрица свёртки: столбец $j$ получается сдвигом коэффициентов $h$ на $j$ строк вниз.

```cpp
Eigen::MatrixXd convolution_matrix(const Laurent& h, std::size_t n) {
    const std::size_t taps = h.coeffs.size();
    Eigen::MatrixXd m = Eigen::MatrixXd::Zero(idx(n + taps - 1), idx(n));
    for (std::size_t j = 0; j < n; ++j)
        for (std::size_t k = 0; k < taps; ++k) m(idx(j + k), idx(j)) = h.coeffs[k];
    return m;
}
```
