## Назначение

Делить на полосы не только низкочастотную ветвь, как DWT, но и детали — и выбрать из полного дерева разбиение, лучше всего сжимающее сигнал: `wpt` строит дерево пакетов и выдаёт коэффициенты выбранного базиса, `iwpt` собирает сигнал обратно из любого допустимого базиса.

## Формулы

Корень $c_{0,0} = x$; каждый узел делится тем же шагом, что и DWT, с фазой pywt:

$$c_{j+1,2m}[k] = \sum_i h_0[i]\,c_{j,m}[2k+1-i], \qquad c_{j+1,2m+1}[k] = -\sum_i h_1[i]\,c_{j,m}[2k+1-i]$$

Знак минус — это `dec_hi` из PyWavelets (§0.4), поэтому узлы совпадают с `pywt.WaveletPacket`. Края — по `ext`; длина ребёнка $\lfloor (n+L-1)/2\rfloor$, для `periodization` — $\lceil n/2\rceil$.

Узел $(j, m)$ — путь из $a$ и $d$: двоичная запись $m$ (порядок Пэли). Ветвь $d$ переворачивает спектр, поэтому место узла по частоте — обратный код Грея:

$$p(m) = m \oplus \lfloor m/2\rfloor \oplus \lfloor m/4\rfloor \oplus \dots$$

Базис (`basis`): `full` — все $2^J$ листьев уровня $J$ по частоте; `dwt` — $a\dots a$ уровня $J$ и детали $(J, 1), (J-1, 1), \dots, (1, 1)$; `best` — Койфман–Викерхаузер по энтропии Шеннона, суммированной по каналам:

$$\mathcal{M}(c) = -\sum_k p_k \ln p_k, \qquad p_k = \frac{c_k^2}{E_x}, \quad E_x = \sum_n x[n]^2$$

Нули пропускаются; $E_x$ — энергия всего канала, а не узла. Узел заменяется детьми, если $\mathcal{M}(\text{дети}) < \mathcal{M}(\text{узел})$ строго. Для ортогональных банков это оптимум среди всех допустимых базисов, для биортогональных — приближение.

## Алгоритм и стоимость

1. `wpt`: нужно $N \ge 2^J$; на уровне $j$ каждый из $2^j$ узлов делится одним шагом DWT, всего дерево не больше $2^{28}$ значений.
2. Для `best` стоимости считаются снизу вверх, листья собираются обходом от корня и сортируются по частоте, приведённой к самому глубокому уровню.
3. `iwpt`: базис проверяется на допустимость (листья покрывают все частоты без дыр и наложений), строится дерево нулей той же глубины, в него кладутся полосы, затем пары братьев синтезируются снизу вверх с обрезкой до длины родителя.

Стоимость дерева $O(N\,L\,J)$, выбора базиса — $O(N\,J)$ после построения, `iwpt` — $O(N\,L\,J)$.

## Проверки

- Блок `wpt` в пяти наборах (db2/symmetric/best, sym4/periodization/full, haar/periodization/dwt, coif1/zero/best, стерео db2/periodization/best) совпадает с пакетами `pywt`: пути полос — точно, коэффициенты — до $10^{-10}$; `iwpt` возвращает сигнал до $10^{-10}$.
- Сумма компонент `mra` по всем полосам базиса равна входу до $10^{-10}$; частота полосы — $f_s/2^j$; `idwt` и `iswt` отклоняют пакеты, `iwpt` — коэффициенты DWT; 3 отсчёта на 2 уровня и неполный набор полос отклоняются.
- В ядре: все узлы и восстановление совпадают с `pywt.WaveletPacket` для нескольких вейвлетов, режимов и длин; любой допустимый базис (`dwt`, полный уровень, корень, 20 случайных) восстанавливает сигнал.
- Лучший базис совпадает с минимумом перебором по всем допустимым базисам (2, 5, 26, 677 для $J$ = 1…4) для haar и db2, энтропии и лог-энергии, и не хуже корня и полного уровня.

## Реализация

Койфман–Викерхаузер: узел дробится, только если дети вместе дешевле.

```cpp
        for (std::size_t n = 0; n < count; ++n) {
            double own = 0;
            for (std::size_t t = 0; t < trees.size(); ++t) own += packet_cost(trees[t].nodes[j][n], cost, norm2[t]);
            best[j][n] = own;
            if (j == levels) continue;
            const double children = best[j + 1][2 * n] + best[j + 1][2 * n + 1];
            if (children < own) {
                best[j][n] = children;
                split[j][n] = true;
            }
        }
```
