## Назначение

`quantize` огрубляет отсчёты до сетки $b$-битного целого, по желанию с треугольным дизером; `mulaw` сжимает или разжимает амплитуду по μ-закону G.711 — логарифмической кривой, которая отдаёт тихим звукам больше уровней квантования.

## Формулы

Шкала $Q = 2^{b-1}$, шаг $\Delta = 1/Q$. Дизер $\delta = u_1 - u_2$, $u_{1,2}$ равномерны на $[0, 1)$ — треугольное распределение на $(-1, 1)$ в единицах шага; без дизера $\delta = 0$:

$$q[n] = \frac{1}{Q}\,\min\big(Q - 1, \max(-Q, \mathrm{round}(Q\,x[n] + \delta))\big)$$

Округление к ближайшему, половины — к чётному (как `numpy.round`); диапазон $[-1, 1 - \Delta]$; NaN и бесконечности дают 0.

Без дизера ошибка равномерна на $[-\Delta/2, \Delta/2]$ с дисперсией $\Delta^2/12$; для синуса полной шкалы

$$\mathrm{SNR} \approx 6{,}02\,b + 1{,}76\,\text{дБ}$$

Дизер добавляет $\Delta^2/6$, всего $\Delta^2/4$: SNR ниже на $10\lg 3 \approx 4{,}77$ дБ, зато среднее и мощность ошибки не зависят от сигнала и гармоники квантования исчезают.

μ-закон (у G.711 $\mu = 255$), вход обрезается до $[-1, 1]$:

$$F(x) = \mathrm{sgn}(x)\,\frac{\ln(1 + \mu\lvert x\rvert)}{\ln(1 + \mu)}, \qquad F^{-1}(y) = \mathrm{sgn}(y)\,\frac{(1 + \mu)^{\lvert y\rvert} - 1}{\mu}$$

Сам `mulaw` не квантует: выход непрерывен. Цепочка `mulaw` encode → `quantize` 8 бит → `mulaw` decode даёт шаг по входу

$$\Delta_x \approx \Delta_y\,\frac{\ln(1 + \mu)}{\mu}\,(1 + \mu\lvert x\rvert)$$

— при больших $\mu\lvert x\rvert$ относительная ошибка почти постоянна, $\Delta_x/\lvert x\rvert \approx \Delta_y \ln(1 + \mu)$. Это приближение G.711: там кривая кусочно-линейная по сегментам.

## Алгоритм и стоимость

1. `quantize`: генератор `mt19937_64` с семенем «seed + номер канала» — каналы получают разный дизер, повтор с тем же семенем точен.
2. Масштаб, дизер, округление, насыщение, обратный масштаб — по одному отсчёту.
3. `mulaw`: NaN → 0, обрезка до ±1, `log1p` и `expm1` для точности около нуля.

Стоимость $O(N)$ на канал, память — выход.

## Проверки

- Без дизера `quantize` для 1, 2, 8, 16 и 24 бит совпадает с `np.clip(np.round(y/Δ)·Δ, −1, 1−Δ)` точно (ошибка 0); 0 и 33 бита отклоняются.
- С дизером (8 бит) результат повторяется при том же семени и меняется при другом; $\lvert q - x\rvert \le 1{,}5\Delta$, все значения лежат на сетке.
- `mulaw_encode` совпадает с формулой G.711 на numpy до $10^{-15}$; encode → decode возвращает вход на $[-1, 1]$ до $10^{-12}$; 2 и −3 дают ±1, NaN — 0, бесконечность — 1.
- Блоки обрабатывают каналы отдельно: 2 бита переводят (−1,5; −0,25; 0; 0,3; 1,2) точно в (−1; 0; 0; 0,5; 0,5) (`tests/pipeline/test_blocks_basic.cpp`).

## Реализация

Квантование одного отсчёта: масштаб, треугольный дизер, округление и насыщение.

```cpp
    for (std::size_t n = 0; n < x.size(); ++n) {
        double v = std::isfinite(x[n]) ? x[n] * scale : 0.0;
        if (dither) {
            const double d1 = uniform(rng), d2 = uniform(rng);
            v += d1 - d2;
        }
        out[n] = std::clamp(std::nearbyint(v), -scale, scale - 1) / scale;
    }
```
