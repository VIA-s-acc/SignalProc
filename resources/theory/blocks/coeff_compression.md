## Назначение

Два шага сжатия в области коэффициентов разложения: `keep_largest` оставляет $K$ коэффициентов с наибольшим модулем и обнуляет остальные, `coeff_quantize` округляет коэффициенты деталей к равномерной сетке с шагом $\Delta$. После обратного преобразования слышно, сколько можно выбросить и огрубить.

## Формулы

Сохранение наибольших: в общий пул $\mathcal P$ канала входят все полосы $b \ge b_0$, где $b_0 = 1$, если аппроксимацию (полосу 0) не трогать, и $b_0 = 0$ иначе. Число сохраняемых, $[\cdot]$ — округление половины от нуля:

$$K = \min\Big(\lvert\mathcal P\rvert,\ \Big[\frac{a}{100}\,\lvert\mathcal P\rvert\Big]\Big) \quad \text{(проценты)}, \qquad K = \min\big(\lvert\mathcal P\rvert,\ [a]\big) \quad \text{(штуки)}$$

Коэффициенты сортируются по $\lvert c\rvert$ по убыванию устойчиво (при равенстве выигрывает более ранняя полоса и позиция), первые $K$ остаются, остальные обнуляются. Для ортонормированного банка с периодизацией ошибка равна энергии выброшенного:

$$\sum_n \big(x[n] - \hat x[n]\big)^2 = \sum_{c\ \text{обнулён}} c^2$$

Квантование полос $b \ge 1$ (аппроксимация не квантуется никогда); шаг по битам $B$ — свой у каждой полосы, по шагу — общий:

$$\Delta_b = \frac{\max_k\lvert c_b[k]\rvert}{2^{B-1} - 1}, \qquad \hat c = \mathrm{sign}(c)\,\Big\lfloor\frac{\lvert c\rvert}{\Delta_b} + \frac12\Big\rfloor\,\Delta_b, \qquad \lvert c - \hat c\rvert \le \frac{\Delta_b}{2}$$

Это квантователь со ступенькой в нуле (mid-tread): $2^B - 1$ уровней $q\Delta_b$, $\lvert q\rvert \le 2^{B-1} - 1$, пик полосы попадает точно на крайний уровень, а $\lvert c\rvert < \Delta_b/2$ даёт 0. При мелком шаге шум квантования $\approx \Delta_b^2/12$ на коэффициент.

## Алгоритм и стоимость

1. `keep_largest`: пул указателей на коэффициенты канала, устойчивая сортировка по модулю, обнуление хвоста. Проценты больше 100 и NaN во входе отклоняются.
2. Ранжирование — по $\lvert c\rvert$ без весов: для биортогональных банков и SWT это не наилучшее $K$-членное приближение (§12.2 советует умножать на нормы синтезирующих функций).
3. На экране разложения то же сохранение задаётся долей, и там $K$ округляется вверх, а в блоке — к ближайшему.
4. `coeff_quantize`: в режиме битов шаг считается по пику каждой полосы; полоса из одних нулей ($\Delta_b = 0$) не меняется. В отличие от квантователя с мёртвой зоной из §12.2 ($\lfloor\lvert c\rvert/\Delta\rfloor$ и восстановление со сдвигом $\rho$), здесь простое округление: нулевая ступенька шириной $\Delta$, а не $2\Delta$.
5. У пакетов (`wpt`) полоса 0 — первый узел базиса.

Стоимость: сохранение $O(P\log P)$ для $P$ коэффициентов, квантование $O(P)$.

## С числами этого блока

Режим {{block.mode}}: у `keep_largest` — проценты или штуки, у `coeff_quantize` — биты или шаг. Сохранение: {{block.amount}}, аппроксимация не трогается: {{block.keep_approx}}. Квантование: {{block.bits}} бит, то есть $2^{B-1} - 1$ уровней на знак, или шаг {{block.step}}.

Узел работал {{block.wall}}, память {{block.bytes}}.

## Проверки

- `keep_largest` на db2-разложении в 3 уровня совпадает с эталоном на устойчивой `numpy.argsort` до $10^{-10}$ для «10 %, аппроксимация не трогается», «25 штук, трогается» и «37,5 %, не трогается».
- $10^9$ штук оставляют всё как было; 0 % сохраняет аппроксимацию, а детали обнуляет; 150 % и NaN отклоняются с понятным сообщением.
- `coeff_quantize` совпадает с эталоном numpy до $10^{-10}$ для 4 и 9 бит и для шага 0,05; при 2 битах каждый коэффициент деталей равен 0 или $\pm$ пику полосы до $10^{-15}$.
- Сохранение половины коэффициентов лучшего базиса пакетов даёт сигнал исходной длины после `iwpt`.

## Реализация

Пул коэффициентов, число $K$ и обнуление всего, что не вошло в первые $K$ по модулю.

```cpp
        std::vector<double*> pool;
        for (std::size_t b = first; b < ch.bands.size(); ++b)
            for (double& v : ch.bands[b]) pool.push_back(&v);
        const auto total = static_cast<double>(pool.size());
        const auto keep = std::min(pool.size(), static_cast<std::size_t>(std::llround(percent ? amount / 100 * total : amount)));
        std::ranges::stable_sort(pool, std::greater<>{}, [](const double* v) { return std::abs(*v); });
        for (std::size_t k = keep; k < pool.size(); ++k) *pool[k] = 0.0;
```
