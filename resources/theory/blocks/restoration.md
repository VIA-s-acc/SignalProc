## Назначение

Три классических способа убрать шум или размытие без вейвлетов: `wiener` — локальный фильтр Винера во времени, как `scipy.signal.wiener`; `spectral_subtract` — вычитание оценённого спектра шума по Берути; `deconvolve` — винеровская деконволюция известного ядра в частотной области.

## Формулы

Локальное среднее и дисперсия по окну нечётной длины $K$, $h = (K-1)/2$; за краями сигнала — нули, делитель всегда $K$:

$$m_n = \frac1K\sum_{j=-h}^{h} x[n+j], \qquad v_n = \frac1K\sum_{j=-h}^{h} x[n+j]^2 - m_n^2$$

$$\hat s[n] = m_n + \Big(1 - \frac{\nu}{v_n}\Big)\big(x[n] - m_n\big) \quad (v_n \ge \nu), \qquad \hat s[n] = m_n \quad (v_n < \nu)$$

$\nu$ — заданная дисперсия шума или, если она 0, среднее $v_n$ по всему сигналу.

Вычитание спектра: STFT с периодическим окном Ханна длины $N$, шагом $R = N/4$, по $N/2$ нулей с обеих сторон и масштабом $1/\sum w$, как `scipy.signal.stft`. Мощность шума $\hat P_k$ — среднее $\lvert Z_m(k)\rvert^2$ по кадрам шумового отрезка; фаза $X$ сохраняется:

$$\lvert\hat S_m(k)\rvert^2 = \max\big(\lvert X_m(k)\rvert^2 - \alpha\hat P_k,\ \beta\hat P_k\big), \qquad \hat S_m(k) = X_m(k)\,\frac{\lvert\hat S_m(k)\rvert}{\lvert X_m(k)\rvert}$$

Обратно — наложение со сложением с тем же окном и делением на $\sum_m w[n - mR]^2$, как `scipy.signal.istft`, и обрезка до длины $x$.

Деконволюция — круговая, длина ДПФ $N$ равна длине $y$, ядро $h$ дополнено нулями:

$$\hat X_k = \frac{Y_k\,H_k^{*}}{\lvert H_k\rvert^2 + 10^{-\mathrm{SNR}/10}}, \qquad \hat x[n] = \mathrm{Re}\,\frac1N\sum_{k=0}^{N-1}\hat X_k\,e^{2\pi i k n/N}$$

Регуляризатор $10^{-\mathrm{SNR}/10}$ — постоянное отношение «шум/сигнал» на бин, оно не масштабируется ни по уровню сигнала, ни по усилению ядра: при ядре с усилением 1 на нулевой частоте SNR читается как отношение мощностей.

## Алгоритм и стоимость

1. `wiener`: прямые суммы по окну для каждого отсчёта; чётное или нулевое окно отклоняется; при $v_n \le 0$ выход — среднее.
2. `spectral_subtract`: шумовой отрезок — вход `noise` (тот же канал или последний) либо первые `noise_s` секунд самого $x$; он должен быть не короче окна. Кадры шума включают краевые, наполовину заполненные нулями дополнения, как в scipy, поэтому на коротком отрезке $\hat P_k$ немного ниже истинной мощности.
3. $\alpha > 1$ вычитает с запасом, $\beta$ оставляет пол шума вместо нулевых провалов — так меньше «музыкального шума».
4. `deconvolve`: три БПФ длины $N$; ядро не длиннее сигнала и начинается в отсчёте 0, задержка не компенсируется. Линейное (не круговое) размытие даёт ошибку у краёв; ноль $H_k$ не опасен — знаменатель не меньше $10^{-\mathrm{SNR}/10}$.

Стоимость: `wiener` $O(N K)$, вычитание спектра $O\big((N_x + N_z)/R\cdot N\log N\big)$, деконволюция $O(N\log N)$.

## Проверки

- `wiener` совпадает со `scipy.signal.wiener` до $10^{-12}$ для окон 5 и 11 с оценкой шума и 3 и 21 с заданным шумом 0,04 и 0,01; окна 4 и 0 отклоняются; постоянный сигнал даёт конечный выход.
- Вычитание спектра совпадает с эталоном на `scipy.signal.stft` и `istft` до $10^{-12}$ для $(\alpha, \beta, N, R) = (2;\ 0{,}01;\ 64;\ 16)$, $(1;\ 0{,}05;\ 32;\ 8)$ и $(4;\ 0{,}001;\ 128;\ 64)$; шум или сигнал короче окна отклоняются.
- Деконволюция совпадает с формулой на numpy FFT до $10^{-12}$ для SNR 20, 40 и 80 дБ; при 120 дБ возвращает чистый сигнал до $10^{-4}$; пустое ядро и ядро длиннее сигнала отклоняются; ядро $(0{,}5;\ 0{,}5)$ с нулём на Найквисте даёт конечный выход.
- Блоки в цепочке совпадают с ядром до $10^{-12}$, в том числе шум из первых 0,02 с сигнала; окно 4096 на коротком сигнале отклоняется.

## Реализация

Вычитание по Берути: мощность с полом $\beta\hat P_k$, фаза исходного кадра.

```cpp
    for (auto& frame : z->frames)
        for (std::size_t k = 0; k < bins; ++k) {
            const double power = std::max(std::norm(frame[k]) - o.alpha * level[k], o.beta * level[k]);
            const double magnitude = std::abs(frame[k]);
            frame[k] = magnitude > 0 ? frame[k] * (std::sqrt(power) / magnitude) : C{std::sqrt(power), 0.0};
        }
```
