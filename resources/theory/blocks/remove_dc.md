## Назначение

Убрать из сигнала постоянное смещение (DC offset): вычесть среднее значение, чтобы сигнал колебался вокруг нуля. Это освобождает запас по амплитуде и убирает пик на нулевой частоте в спектре.

## Формулы

$$\bar x = \frac{1}{N} \sum_{n=0}^{N-1} x[n], \qquad y[n] = x[n] - \bar x$$

Нулевая гармоника DFT равна $X[0] = \sum_n x[n] = N \bar x$, поэтому после вычитания

$$\sum_{n=0}^{N-1} y[n] = 0, \qquad Y[0] = 0, \qquad Y[k] = X[k] \;\; (k \ne 0)$$

Остальные гармоники не меняются, а энергия уменьшается ровно на энергию смещения:

$$\sum_n y[n]^2 = \sum_n x[n]^2 - N \bar x^2$$

Это не фильтр верхних частот: вычитается одна константа на весь сигнал, поэтому фаза и амплитуда остальных частот не искажаются, но медленный дрейф среднего (смещение, меняющееся во времени) не убирается.

## Алгоритм и стоимость

1. Среднее считается суммированием Неймайера (компенсированным): ошибка суммы остаётся порядка $u = 2^{-53}$, а не растёт как $N u$ (§13.2).
2. Из каждого отсчёта копии вычитается среднее.
3. Пустой сигнал возвращается без изменений.

Два прохода, время $O(N)$, память $O(N)$.

## С числами этого блока

Постоянная составляющая входа $\bar x$ (в долях полной шкалы): {{metric.dc}}. Выход получается как $y[n] = x[n] - ({{metric.dc}})$, и его среднее равно нулю с точностью округления. Если смещение велико, пики сигнала несимметричны: с одной стороны запаса до полной шкалы меньше, и удаление смещения может это исправить.

## Проверки

—

Тест проверяет точный результат на простом примере: из $(1, 2, 3)$ получается $(-1, 0, 1)$.

## Связи

- §0.1 — DFT: $X[0]$ — сумма отсчётов, DC — нулевая гармоника.
- §1.2 — z-преобразование и DTFT: значение спектра в $\omega = 0$.
- §13.2 — компенсированное суммирование Неймайера для длинных сигналов.
- Статистика канала при чтении WAV (`channel_stats`) считает то же среднее $\bar x$ тем же суммированием.

## Реализация

Среднее с компенсацией и вычитание из каждого отсчёта.

```cpp
std::vector<double> remove_dc(std::span<const double> x) {
    std::vector<double> y(x.begin(), x.end());
    if (y.empty()) return y;
    const double mean = neumaier_sum(x) / static_cast<double>(x.size());
    for (double& v : y) v -= mean;
    return y;
}
```
