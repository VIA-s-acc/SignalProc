## Назначение

Свести многоканальный сигнал в один канал, усреднив каналы отсчёт за отсчётом. Нужно, когда достаточно одного канала: для спектра, вейвлет-разложения, прослушивания в моно.

## Формулы

$$m[n] = \frac{1}{C} \sum_{c=0}^{C-1} x_c[n]$$

Деление на $C$ гарантирует, что результат не выходит за пределы входов: $\lvert m[n] \rvert \le \max_c \lvert x_c[n] \rvert$, поэтому из сигналов в пределах полной шкалы получается сигнал в её пределах.

Уровень зависит от связи каналов. Одинаковые каналы ($x_0 = x_1 = x$) дают $m = x$ без изменения уровня. Некоррелированные каналы одной мощности $\sigma^2$ дают мощность $\sigma^2 / C$, то есть падение уровня на $10 \log_{10} C$ дБ. Противофазные каналы ($x_1 = -x_0$) взаимно уничтожаются:

$$m[n] = \frac{x_0[n] + x_1[n]}{2} = 0 \quad \text{при } x_1 = -x_0$$

Mid-канал стерео $M = \tfrac12(L+R)$ — это ровно такой микс (§12.6).

## Алгоритм и стоимость

1. Для $C$ каналов выделяется вектор сумм длиной в число кадров первого канала.
2. Каналы по очереди добавляются в сумму; более короткий канал дополняется нулями справа, а более длинный обрезается до длины первого.
3. Сумма делится на $C$, результат оформляется как один канал с прежней частотой дискретизации.

Время $O(N\,C)$, память $O(N)$. Пустой набор каналов возвращается пустым. Каналы разной длины в нормальных данных не встречаются; код терпит их, а не проверяет.

## С числами этого блока

Входной сигнал имеет $C = {{block.channels}}$ кан.; вес каждого канала в миксе $1 / C$. Для некоррелированных каналов равной мощности уровень сдвигается на $-10 \log_{10} {{block.channels}}$ дБ (при $C = 1$ — на ноль: канал копируется), а для идентичных остаётся тем же.

## Проверки

Численной проверки в интерфейсе у этого блока нет: его правильность закрепляют тесты.

Тест проверяет на паре каналов $(1, 3)$ и $(3, 5)$ результат $(2, 4)$, один выходной канал и сохранение частоты дискретизации.

## Связи

- §12.6 — стерео: mid/side, поканальная обработка.
- §0.1 — сигнал $x[n]$ и линейные операции над ним.

- Блок «Mid/side» хранит и сумму, и разность каналов, так что ничего не теряется.

## Реализация

Суммирование каналов поотсчётно и деление на их число.

```cpp
AudioBuffer mixdown(const AudioBuffer& audio) {
    AudioBuffer out{audio.sample_rate, {}};
    if (audio.channels.empty()) return out;
    std::vector<double> sum(audio.frames(), 0.0);
    for (const auto& c : audio.channels)
        for (std::size_t k = 0; k < sum.size() && k < c.size(); ++k) sum[k] += c[k];
    for (double& v : sum) v /= static_cast<double>(audio.channels.size());
    out.channels.push_back(std::move(sum));
    return out;
}
```
