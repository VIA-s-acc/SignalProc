## Назначение

Пропустить каждый отсчёт через одну и ту же функцию $y = F(x)$ без памяти: `clip` — жёсткий срез по порогу, `softclip` — мягкое насыщение $\tanh$, `wavefold` — «складывание» волны обратно в $[-1, 1]$. Так получают перегруз и новые гармоники.

## Формулы

Жёсткий срез с порогом $A$ и мягкое насыщение с усилением $k$:

$$y_{\mathrm{clip}} = \begin{cases} x, & \lvert x\rvert \le A \\ A\,\mathrm{sgn}\,x, & \lvert x\rvert > A \end{cases} \qquad y_{\mathrm{soft}} = \tanh(kx)$$

Складывание: $u = kx$, $v = (u + 1) \bmod 4 \in [0, 4)$ — треугольная волна периода 4 по $u$, при $\lvert u\rvert \le 1$ это просто $y = u$; форма `sine` — гладкий вариант:

$$y_{\mathrm{tri}} = \begin{cases} v - 1, & v < 2 \\ 3 - v, & v \ge 2 \end{cases} \qquad y_{\sin} = \sin\frac{\pi u}{2}$$

Все функции нечётные, $F(-x) = -F(x)$: синус $f_0$ на входе даёт только нечётные гармоники $3f_0, 5f_0, \dots$. Для малых $kx$ $\tanh(kx) \approx kx - (kx)^3/3$, а $\sin^3\theta = \tfrac34\sin\theta - \tfrac14\sin 3\theta$ — третья гармоника тона амплитуды $a$ равна примерно $(ka)^3/12$.

Передискретизации нет: гармоники выше $f_s/2$ не подавляются и отражаются в $\lvert n f_0 - j f_s\rvert$ — то же наложение, что при прореживании без фильтра.

## Алгоритм и стоимость

1. Каждый отсчёт каждого канала обрабатывается отдельно: сравнение, $\tanh$, `fmod` или $\sin$.
2. `clip` в ядре (`hard_clip`) ещё считает срезанные отсчёты, блок возвращает только сигнал.
3. Длина, число каналов и частота дискретизации не меняются.

Стоимость $O(N)$ на канал, память — выход.

## С числами этого блока

`clip`: порог {{block.limit}} — всё, что по модулю выше, становится ровно ± порогом.

`softclip` и `wavefold`: усиление {{block.drive}}, форма складывания {{block.shape}}; при усилении 1 треугольная форма не меняет сигнал внутри $[-1, 1]$.

Время узла {{block.wall}}, память {{block.bytes}}.

## Проверки

- `wavefold` с усилением 3 совпадает с формулами на numpy для обеих форм до $10^{-12}$ и не выходит за $[-1, 1]$; с усилением 1 треугольная форма точно сохраняет 0,25 и −0,5.
- `softclip` с усилением 2 совпадает с `numpy.tanh(2x)` до $10^{-15}$ (`tests/pipeline/test_blocks_more.cpp`).
- `clip` с порогом 0,5 переводит (−1,5; −0,25; 0; 0,3; 1,2) точно в (−0,5; −0,25; 0; 0,3; 0,5) (`tests/pipeline/test_blocks_basic.cpp`).

## Реализация

Складывание: треугольная волна периода 4 через `fmod`, синусная форма — одной функцией.

```cpp
                               return each_sample(in, [drive, sine](double x) {
                                   const double u = drive * x;
                                   if (sine) return std::sin(kPi / 2 * u);
                                   double v = std::fmod(u + 1, 4.0);
                                   if (v < 0) v += 4;
                                   return v < 2 ? v - 1 : 3 - v;
                               });
```
