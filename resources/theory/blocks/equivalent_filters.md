## Назначение

Свернуть цепочку «фильтры уровней $1..j$ и прореживания» в один фильтр и одно прореживание на $2^j$, чтобы увидеть АЧХ каждой полосы пирамиды в исходной шкале частот: октавное разбиение, перекрытие соседних полос и боковые лепестки.

## Формулы

По тождествам Нобла (§3.3) детали и аппроксимация уровня $j$ получаются одним фильтром и $\downarrow 2^j$:

$$H^{\mathrm{eq}}_j(z) = H_1\big(z^{2^{j-1}}\big) \prod_{k=0}^{j-2} H_0\big(z^{2^k}\big), \qquad G^{\mathrm{eq}}_j(z) = \prod_{k=0}^{j-1} H_0\big(z^{2^k}\big)$$

Растяжение $H(z^m)$ вставляет $m-1$ нулей между отводами. При длинах $L_0 = L_1 = L$ длина эквивалентного фильтра

$$L_j^{\mathrm{eq}} = (2^j - 1)(L - 1) + 1$$

Номинальные полосы: деталь $d_j$ — $[\pi/2^j,\ \pi/2^{j-1}]$, аппроксимация $a_j$ — $[0,\ \pi/2^j]$. Фаза прореживания pywt (§0.4) не учитывается: она сдвигает отсчёты полосы во времени, но не меняет АЧХ.

## Алгоритм и стоимость

1. $g \leftarrow 1$. Для $k = 0, \dots, j-2$: $g \leftarrow g * H_0(z^{2^k})$.
2. Последний множитель — $H_1$ для детали или $H_0$ для аппроксимации, растянутый в $2^{j-1}$ раз; результат — его произведение с $g$.
3. АЧХ эквивалентного фильтра вычисляется как у любого КИХ (прямая сумма по сетке).

Произведения плотные: стоимость $O(4^{j} L^2)$ умножений, длина результата растёт как $2^j$. Считается один раз на фильтр, не на сигнал.

## С числами этого блока

Банк «{{block.bank}}», полоса {{block.band}} — уровень $j = {{block.level}}$. Длина эквивалентного фильтра — {{block.length}} отсчётов (при равных длинах $L$ исходных фильтров ожидается $(2^j - 1)(L - 1) + 1$). Срез по $-3$ дБ: $\omega_c = {{metric.cutoff_3db}}$.

Эквивалентные фильтры берутся из анализирующей части банка; PR самого банка (проверки ниже) гарантирует, что набор полос не теряет информацию.

## Проверки

- Искажение банка $T = z^{-\ell}$, наибольшее отклонение коэффициентов от единичного импульса: {{check.pr_distortion}}
- Наложение банка $A \equiv 0$, наибольший модуль коэффициентов: {{check.pr_alias}}
- Для ортогонального банка с нормировкой $\sqrt2$ энергия эквивалентного фильтра $\|h^{\mathrm{eq}}_j\|^2 = 1$.
- Для Хаара $a_3$ — прямоугольник из восьми отсчётов $2^{-3/2}$, $d_3$ — разность половин (тест). Прямое многоуровневое DWT единичного импульса даёт те же импульсные характеристики.

## Реализация

Растяжение фильтра нулями и произведение растянутых фильтров по уровням.

```cpp
Laurent dilate(const Laurent& h, std::size_t m) {
    if (h.coeffs.empty() || m <= 1) return h;
    Laurent out{std::vector<double>((h.coeffs.size() - 1) * m + 1, 0.0), h.offset * static_cast<std::ptrdiff_t>(m)};
    for (std::size_t k = 0; k < h.coeffs.size(); ++k) out.coeffs[k * m] = h.coeffs[k];
    return out;
}

Result<Laurent> equivalent_filter(const FilterBank& bank, std::size_t level, bool detail) {
    if (level == 0) return make_error(Errc::invalid_argument, "equivalent_filter: level must be at least 1");
    Laurent g{{1.0}, 0};
    for (std::size_t k = 0; k + 1 < level; ++k) g = multiply(g, dilate(bank.h0, std::size_t{1} << k));
    const auto& last = detail ? bank.h1 : bank.h0;
    return multiply(dilate(last, std::size_t{1} << (level - 1)), g);
}
```
