## Назначение

Понизить частоту дискретизации в $M$ раз, оставив каждый $M$-й отсчёт; перед этим ФНЧ убирает всё выше $\pi/M$, иначе оно сложится в полосу сигнала.

## Формулы

$${\downarrow}M:\quad y[n] = x[Mn], \qquad Y(e^{i\omega}) = \frac{1}{M}\sum_{k=0}^{M-1} X\big(e^{i(\omega - 2\pi k)/M}\big)$$

Спектр растягивается в $M$ раз, $M$ копий перекрываются — наложение, если $X$ не ограничен полосой $\lvert\omega\rvert < \pi/M$. Децимация — ФНЧ со срезом $\pi/M$ и усилением $1$, затем ${\downarrow}M$:

$$y[k] = (h * x)[kM], \qquad h[m] = \frac{\sin(\pi m / M)}{\pi m}\, w[m], \qquad \sum_m h[m] = 1$$

Окно $w$ — Кайзера. Длина фильтра по ослаблению $A$ дБ и ширине перехода $\Delta\omega = \pi\tau / M$ ($\tau = 0{,}1$ по умолчанию):

$$L \approx \frac{A - 8}{2{,}285\,\Delta\omega} + 1$$

## Алгоритм и стоимость

1. Коэффициент $M = 1$ — тождество; $M = 0$ — ошибка.
2. Без антиалиасинга берутся отсчёты $x[kM]$ как есть: частоты выше $\pi/M$ сворачиваются на $\lvert\omega_0 M - 2\pi k\rvert$.
3. С антиалиасингом строится нечётный по длине КИХ-фильтр Кайзера; его задержка $(L-1)/2$ компенсируется сдвигом выбора отсчётов.
4. Полная свёртка (§1.1), затем выбор каждого $M$-го отсчёта.

Длина выхода $\lceil N/M \rceil$. Стоимость $\approx N L$ умножений (длинные сомножители идут через FFT): реализация считает свёртку целиком и отбрасывает лишнее; полифазная форма (§3.4) обошлась бы в $N L / M$.

## Проверки

Проверить стоило бы, что тон в полосе пропускания проходит без искажения амплитуды и фазы, тон выше $\pi/M$ подавлен не хуже заданного ослабления, а без фильтра он оказывается на частоте $\lvert\omega_0 M - 2\pi k\rvert$ — эти проверки живут в `tests/core/test_multirate.cpp`, на экране их нет.

## Реализация

Выбор отсчётов с фильтром или без него: каждый $M$-й отсчёт свёртки со сдвигом на задержку фильтра.

```cpp
if (!options.anti_alias) {
    for (std::size_t k = 0; k < out_len; ++k) y[k] = x[k * m];
    return y;
}
const auto h = anti_alias_filter(m, options);
const auto filtered = convolve(Laurent{{x.begin(), x.end()}, 0}, h);
const std::size_t d = filter_delay(h, options);
for (std::size_t k = 0; k < out_len; ++k) y[k] = filtered.coeffs[k * m + d];
return y;
```
