## Назначение

Сдвинуть сигнал вправо по времени на целое число отсчётов $d$, дописав слева нули. Сигнал становится длиннее на $d$ отсчётов, ничего не теряется и не заворачивается по кругу.

## Формулы

$$y[n] = \begin{cases} 0, & 0 \le n < d \\ x[n-d], & d \le n < N + d \end{cases}$$

В области $z$-преобразования и DTFT задержка — умножение на $z^{-d}$:

$$Y(z) = z^{-d}\, X(z), \qquad Y(e^{i\omega}) = e^{-i\omega d}\, X(e^{i\omega})$$

Амплитудный спектр не меняется, $\lvert Y \rvert = \lvert X \rvert$, а фаза получает линейную добавку $-\omega d$. Групповая задержка постоянна на всех частотах, $\tau_g(\omega) \equiv d$ отсчётов (§8.4), то есть форма сигнала сохраняется. В секундах задержка равна $d / f_s$.

## Алгоритм и стоимость

1. Выделяется вектор из $d$ нулей.
2. К нему дописывается исходный сигнал.

Время $O(N + d)$, память $8\,(N + d)$ байт: очень большая задержка выделит столько же памяти. Задержка только целая; дробный сдвиг требует интерполяции (фильтра), и этим блоком не выполняется.

## С числами этого блока

Задержка $d = {{block.samples}}$ отсчётов: $y[n] = x[n - {{block.samples}}]$, первые $d$ отсчётов выхода равны нулю, длина выхода $N + d$. Время сдвига равно $d / f_s$, групповая задержка по всем частотам равна $d$.

## Проверки

—

Тест проверяет точный результат на простом примере: задержка $(1, 2)$ на два отсчёта даёт $(0, 0, 1, 2)$.

## Связи

- §1.2 — свойство $x[n-k] \leftrightarrow z^{-k} X$.
- §8.4 — групповая задержка: чистая задержка $z^{-k}$ даёт ровно $k$.
- §0.1 — задержка на $k$ отсчётов как умножение на $z^{-k}$.
- Блок «Вырезка фрагмента» — обратное действие: убирает начало, а не добавляет нули.

## Реализация

Вектор нулей длиной $d$ и сигнал за ним.

```cpp
std::vector<double> delay(std::span<const double> x, std::size_t samples) {
    std::vector<double> y(samples, 0.0);
    y.insert(y.end(), x.begin(), x.end());
    return y;
}
```
