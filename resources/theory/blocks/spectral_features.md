## Назначение

Свести спектр к нескольким числам: `mfcc` — мел-кепстральные коэффициенты, `spectral_features` — центроид, ширина, спад, плоскостность и поток спектра, `spectrum_peaks` — самые заметные пики спектра Уэлча, `band_power` — доли мощности по октавам или третям октавы, `thd` — гармонические искажения тона, `onsets` — моменты атак.

## Формулы

Кадры `mfcc` и `spectral_features`: периодическое окно Ханна $w$ длины $N$, шаг $R$, без дополнения нулями; мощность в шкале «спектр» $P(k) = \lvert X(k)\rvert^2 / \big(\sum_n w[n]\big)^2$ на частотах $f_k = k f_s/N$, $k = 0, \dots, N/2$.

MFCC: мел-шкала HTK $\mathrm{mel}(f) = 2595\log_{10}(1 + f/700)$, $M + 2$ границы $\phi_j$ равномерно по мелам от 0 до $\mathrm{mel}(f_s/2)$, треугольники с вершиной 1 (площадь не нормируется), ортонормированное DCT-II, как `scipy.fft.dct(norm="ortho")`:

$$H_j(f) = \max\Big(0,\ \min\Big(\frac{f - \phi_j}{\phi_{j+1} - \phi_j},\ \frac{\phi_{j+2} - f}{\phi_{j+2} - \phi_{j+1}}\Big)\Big), \qquad L_j = 10\log_{10}\max\Big(\sum_k H_j(f_k)\,P(k),\ 10^{-10}\Big)$$

$$c_q = \sqrt{\frac{2}{M}}\,\lambda_q\sum_{j=0}^{M-1} L_j\cos\frac{\pi q\,(2j+1)}{2M}, \qquad \lambda_0 = \frac{1}{\sqrt2}, \quad \lambda_{q \ge 1} = 1$$

Признаки кадра по амплитудам $A_k = \sqrt{P(k)}$; спад — наименьшая $f_k$, где $\sum_{j \le k} A_j \ge \frac{p}{100}\sum_j A_j$ (веса — амплитуды, не мощности):

$$\mu = \frac{\sum_k f_k A_k}{\sum_k A_k}, \qquad \sigma = \sqrt{\frac{\sum_k (f_k - \mu)^2 A_k}{\sum_k A_k}}, \qquad \Delta_m = \sqrt{\sum_k \big(A_{m,k} - A_{m-1,k}\big)^2}$$

Плоскостность — по мощности с полом $\tilde P_k = \max(P(k), 10^{-10})$ по всем $K = N/2 + 1$ бинам: $\Phi = \exp\big(\frac1K\sum_k\ln\tilde P_k\big) \big/ \big(\frac1K\sum_k\tilde P_k\big)$. Поток $\Delta_m$ не выпрямляется: рост и спад амплитуд считаются одинаково.

Спектр Уэлча для `spectrum_peaks` и `band_power`, как `scipy.signal.welch`: сегмент $L = \min(\text{длина}, \text{segment})$, шаг $L - \lfloor L/2 \rfloor$, окно Ханна, из каждого из $G$ сегментов вычитается его среднее, $c_k = 2$ кроме бинов 0 и $L/2$:

$$S(k) = \frac{c_k}{G\,f_s\sum_n w[n]^2}\sum_{s=1}^{G}\Big\lvert\sum_n \big(x_s[n] - \bar x_s\big)\,w[n]\,e^{-2\pi i k n/L}\Big\rvert^2, \qquad D(k) = 10\log_{10}\max\big(S(k), 10^{-20}\big)$$

Пики — локальные максимумы $D$ (у плато — середина) с выступом, как в `scipy.signal.find_peaks`: $\pi_k = D(k) - \max(m_l, m_r)$, где $m_l, m_r$ — минимумы $D$ слева и справа до первой точки выше $D(k)$. Частота пика — бин $k f_s/L$ без интерполяции.

Полосы — десятичные (base-ten), $s = 3$, $i_0 = -5$ для октав (центры 31,5 Гц … 16 кГц) и $s = 1$, $i_0 = -16$ для третей (25 Гц … 20 кГц); первая граница 22,4 Гц, последняя 22,4 кГц:

$$g_i = 1000\cdot 10^{(s\,(i + i_0) - s/2)/10}, \qquad p_b = \frac{\sum_{g_b \le f_k < g_{b+1}} S(k)}{\sum_k S(k)}$$

THD: одно БПФ всего сигнала длины $N$ с 4-членным окном Блэкмана–Харриса, $\theta = 2\pi n/N$; пик $k^*$ мощности $P_k = \lvert X_k\rvert^2$ уточняется параболой по $\ln P$ (сдвиг ограничен $\pm\tfrac12$), мощность гармоники $B_h$ — сумма $\pm 4$ бинов вокруг $[h\hat k]$, где $[\cdot]$ — округление до целого:

$$w[n] = 0{,}35875 - 0{,}48829\cos\theta + 0{,}14128\cos 2\theta - 0{,}01168\cos 3\theta, \qquad \hat k = k^* + \frac{a - c}{2\,(a - 2b + c)}$$

$$\mathrm{THD} = \sqrt{\frac{\sum_{h=2}^{H} B_h}{B_1}}, \qquad f_0 = \frac{\hat k f_s}{N}, \qquad a, b, c = \ln P_{k^*-1},\ \ln P_{k^*},\ \ln P_{k^*+1}$$

Атаки: моно-смесь (среднее каналов), кадры без дополнения, функция детекции — выпрямленный спектральный поток, $\lvert X_{-1}\rvert = 0$. Кадр $m$ — атака, если он локальный максимум, превышает порог и стоит не ближе $\lceil 0{,}05 f_s/R\rceil$ кадров к предыдущей атаке:

$$\mathrm{SF}(m) = \sum_k \max\big(0,\ \lvert X_m(k)\rvert - \lvert X_{m-1}(k)\rvert\big), \qquad \mathrm{SF}(m) > 1{,}5\,\mathrm{med}_{\lvert j - m\rvert \le W}\mathrm{SF}(j) + 0{,}1\max_j\mathrm{SF}(j)$$

Окно медианы $W = \max\big(1, [0{,}25 f_s/R]\big)$ кадров; время атаки $t = \max\big(0,\ mR + \tfrac34 N - \tfrac12 R\big)/f_s$: щелчок в $p$ отсчётах от начала кадра даёт максимум потока там, где склон окна Ханна круче всего, $p + R/2 = 3N/4$.

## Алгоритм и стоимость

1. `mfcc` и `spectral_features`: $F = 1 + \lfloor (L_x - N)/R \rfloor$ кадров; сигнал короче $N$ даёт 0 кадров и нулевые поля. В отчёт идут средние по кадрам; кадры с нулевой суммой амплитуд пропускаются для $\mu$, $\sigma$, спада и $\Phi$, но поток считается по всем $F - 1$ парам.
2. Мел-треугольники строятся на сетке бинов; при большом $M$ и коротком $N$ нижние треугольники могут не задеть ни одного бина, тогда $L_j = -100$ дБ. В отличие от librosa: шкала HTK, а не Slaney, нет нормировки площади и нет обрезки `top_db`.
3. `spectrum_peaks`: пики сортируются по $D$ по убыванию (устойчиво) и обрезаются до `count`. `band_power`: каждый бин целиком относится к полосе своей центральной частоты; DC попадает в «ниже 22 Гц»; полосы с нижней границей не ниже $f_s/2$ не выводятся, сумма долей равна 1.
4. `thd`: пик ищется среди бинов $1 \dots N/2 - 1$; гармоники берутся в точках $h\hat k$ без поиска своего максимума и обрываются, когда $h\hat k + 4 > N/2$. `harmonics` = $H$ — номер старшей гармоники, основная — первая. Ошибка, если пик ниже 10-го бина (полосы основной и второй гармоники перекрылись бы) или ни одной гармоники ниже Найквиста.
5. `onsets`: медиана — через `nth_element`, при чётном окне берётся верхний из двух средних; у краёв окно усечено; если максимум потока не больше $10^{-12}$, атак нет.

Стоимость: STFT-блоки $O(F N\log N)$ и ещё $O(F M N)$ на мел-банк; Уэлч $O(G L\log L)$; THD $O(N\log N)$; атаки $O(F N\log N + F W)$.

## Проверки

- `mfcc` совпадает с эталоном numpy (мел HTK, треугольники с вершиной 1, `scipy.fft.dct(type=2, norm="ortho")`) до $10^{-10}$ при $(Q, M, N, R) = (13, 20, 256, 128)$ и $(8, 40, 512, 256)$, число кадров — точно; $Q > M$ отклоняется.
- `spectral_features` совпадают с эталоном numpy до $10^{-10}$ при $(N, R, p) = (256, 64, 85)$ и $(512, 200, 50)$; у тишины центроид и плоскостность равны 0.
- `spectrum_peaks`: частоты до $10^{-9}$ Гц и уровни до $10^{-10}$ дБ совпадают со `scipy.signal.welch` и `find_peaks` для сегментов 4096 и 64. `band_power` совпадает с эталоном на `welch` до $10^{-10}$ для октав и третей, сумма долей — 1 до $10^{-12}$; тихий канал даёт нулевые доли и 0 пиков.
- `thd`: тон 1 кГц с гармониками 1 % и 0,1 % — $f_0$ до 0,01 Гц, THD до $10^{-3}$ от $\sqrt{0{,}01^2 + 0{,}001^2}$, гармоники −40 и −60 дБ до 0,05 дБ; нецелое число периодов (441,7 Гц, 30011 отсчётов) — $f_0$ до 0,1 Гц, THD до 2 %. Слишком низкий или короткий тон и тон без гармоник ниже Найквиста отклоняются.
- `onsets`: четыре синтетических щелчка находятся с точностью $(R/2 + 1)/f_s$; тишина и постоянный сигнал не дают атак; у тона с самого начала нет отрицательных времён.

## Реализация

Признаки одного кадра: ширина, спад и плоскостность за один проход по бинам.

```cpp
    for (std::size_t k = 0; k < m.size(); ++k) {
        spread += (freq(k) - centroid) * (freq(k) - centroid) * m[k];
        cumulative += m[k];
        if (!rolloff && cumulative >= pct / 100 * total) rolloff = freq(k);
        const double floored = std::max(power[k], kPowerFloor);
        logs += std::log(floored);
        sum += floored;
    }
```
