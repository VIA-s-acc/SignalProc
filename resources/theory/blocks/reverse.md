## Назначение

Проиграть сигнал задом наперёд: первый отсчёт становится последним. Нужно для проверки на слух (реверс скрывает атаку и показывает затухание), для обратной фильтрации и как строительный блок нуль-фазовой фильтрации вперёд-назад.

## Формулы

$$y[n] = x[N-1-n], \qquad n = 0, \dots, N-1$$

Для вещественного $x$ в области $z$-преобразования и DTFT:

$$Y(z) = z^{-(N-1)}\, X(z^{-1}), \qquad Y(e^{i\omega}) = e^{-i\omega (N-1)}\, \overline{X(e^{i\omega})}$$

Амплитудный спектр не меняется, $\lvert Y \rvert = \lvert X \rvert$, а фаза меняет знак и получает линейную добавку: $\arg Y = -\arg X - \omega (N-1)$. Энергия, пик, RMS и постоянная составляющая остаются теми же, операция обратна самой себе: двойной реверс возвращает вход.

Нуль-фазовая фильтрация вперёд-назад в книге записана через реверс $R$ (§9.12):

$$y = R\big( h * R(h * x) \big), \qquad \lvert H(e^{i\omega}) \rvert^2, \ \text{фаза нулевая}$$

## Алгоритм и стоимость

1. Новый вектор строится по итераторам, идущим от конца входа к началу.

Время $O(N)$, память $O(N)$, одна копия с обратным порядком. Значения не пересчитываются, поэтому реверс точный, без округления.

## С числами этого блока

У блока нет собственных параметров: результат зависит только от входа. Выход имеет ту же длину $N$ и ту же частоту дискретизации, что и вход; первый отсчёт выхода — последний отсчёт входа.

## Проверки

—

Тест проверяет точный результат на простом примере: реверс $(1, 2, 3)$ даёт $(3, 2, 1)$.

## Связи

- §0.1 — обращение времени $h^-[n] = h[-n]$ соответствует $H(z^{-1})$.
- §1.2 — свойство $x[-n] \leftrightarrow X(z^{-1})$.
- §9.12 — нуль-фазовая фильтрация вперёд-назад: два реверса и два прохода одного фильтра.
- Блок «Задержка» — другая операция над временной осью: сдвиг вместо отражения.

## Реализация

Реверс — одна строка `reverse` (копирование от конца к началу); она показана вместе с соседней в файле `delay`.

```cpp
std::vector<double> delay(std::span<const double> x, std::size_t samples) {
    std::vector<double> y(samples, 0.0);
    y.insert(y.end(), x.begin(), x.end());
    return y;
}

std::vector<double> reverse(std::span<const double> x) { return {x.rbegin(), x.rend()}; }
```
