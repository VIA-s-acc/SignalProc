## Назначение

Умножить выбранные полосы на усиления (ноль — обнуление) и собрать сигнал обратно; показать цену такого редактирования — потерю энергии и наложение.

## Формулы

$$\hat x = \mathrm{IDWT}\big(g_a\, a_J,\; g_J\, d_J,\; \dots,\; g_1\, d_1\big), \qquad g = 10^{G/20}, \qquad g = 0 \text{ у отключённой полосы}$$

Для ортонормированного банка с периодизацией (§14.3) энергия складывается по полосам:

$$\|\hat x\|^2 = g_a^2\,\|a_J\|^2 + \sum_{j=1}^{J} g_j^2\,\|d_j\|^2$$

Цена редактирования. Если $g \ne 1$, член $X(-z)$ перестаёт компенсироваться. Для двух каналов при обнулённых деталях

$$\hat X(z) = \tfrac12 F_0(z)\big[H_0(z)X(z) + H_0(-z)X(-z)\big]$$

и величина наложения $\tfrac12\,\lvert F_0(e^{i\omega})\,H_0(e^{i(\omega+\pi)})\rvert$ максимальна в переходной полосе около $\pi/2$: у Хаара $\tfrac12\lvert\sin\omega\rvert$, то есть $-6$ дБ.

Для $J$ уровней $\hat X(z) = \sum_k A^{(g)}_k(z)\,X(zW^k)$, $A^{(g)}_k = \sum_i \frac{g_i}{M_i}\,F^{eq}_i\,H^{eq}_i(zW^k)$; при $g \equiv 1$ остаётся только $A_0 = z^{-\ell}$.

## Алгоритм и стоимость

1. DWT считается один раз и хранится; смена усиления или включение полосы повторяет только шаги 2–3.
2. Каждая полоса умножается на свой $g_b$; отключённая заполняется нулями.
3. IDWT по изменённым коэффициентам; энергия $\hat x$ сравнивается с энергией $x$.

Стоимость: $N$ умножений на усиления плюс синтез $\approx N\,(L_0 + L_1)$; память $O(N)$.

Как уменьшить наложение: плавный переход усилений через соседние полосы вместо жёсткого нуля; длинные фильтры (db20, sym20); SWT/MODWT-MRA, где обнуление детали — линейная стационарная фильтрация.

## Проверки

Проверить стоило бы, что единичные усиления возвращают $x$ с точностью округления, что включение полосы возвращает исходный сигнал, а энергия наложения (§14.6) мала для выбранной стратегии — эти проверки живут в `tests/tui/test_decomposition_model.cpp` и `tests/core/test_shrink.cpp`, на экране их нет.

## Реализация

Усиления умножают полосы, отключённые полосы обнуляются, затем синтез собирает $\hat x$.

```cpp
for (std::size_t i = 0; i < processing.gains_db.size() && i <= J; ++i)
    if (processing.gains_db[i] != 0) {
        const double g = std::pow(10.0, processing.gains_db[i] / 20);
        for (double& c : bands[J - i]) c *= g;
    }
auto kept = rec->processed;
for (std::size_t i = 0; i <= J && i < enabled.size(); ++i)
    if (!enabled[i]) std::fill(kept.bands[J - i].begin(), kept.bands[J - i].end(), 0.0);
auto xhat = inverse_transform(kept, bank, d->options);
```
