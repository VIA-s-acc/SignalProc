## Назначение

Поотсчётные операции над одним или двумя сигналами: `affine` — $sx + o$, `math` — функция одного сигнала, `binary` — функция двух сигналов, `mix` — сумма с усилениями или переход от одного сигнала к другому, `abs` и `square` — модуль и квадрат.

## Формулы

Один вход:

$$y_{\mathrm{affine}} = s\,x + o, \qquad y_{\mathrm{abs}} = \lvert x\rvert, \qquad y_{\mathrm{square}} = x^2$$

`math`: $\ln x$, $\lg x$, $e^x$, $\sqrt{x}$, $x^p$, $\mathrm{sgn}\,x \in \{-1, 0, 1\}$, $1/x$. Область: $x > 0$ для логарифмов, $x \ge 0$ для корня, $x \ne 0$ для $1/x$; для $x^p$ запрещены $x < 0$ при нецелом $p$ и $x = 0$ при $p < 0$. Первый отсчёт вне области останавливает блок с номером отсчёта, канала и значением.

`binary`: $a/b$ ($b \ne 0$), $\min(a, b)$, $\max(a, b)$, $a^b$ (те же ограничения, что у $x^p$), $\sqrt{a^2 + b^2}$ (`hypot`, без переполнения в промежуточном квадрате).

`mix` с усилениями $g_a = 10^{G_a/20}$, $g_b = 10^{G_b/20}$; режим `sum` и режим `crossfade`:

$$y[n] = g_a a[n] + g_b b[n], \qquad y[n] = (1 - w[n])\,g_a a[n] + w[n]\,g_b b[n]$$

$$w[n] = \min\big(1, \max(0, (n - n_0)/L)\big), \qquad n_0 = \lfloor t_0 f_s + 1/2 \rfloor, \quad L = \lfloor \tau f_s/1000 + 1/2 \rfloor$$

При $L = 0$ — резкое переключение в отсчёте $n_0$. Переход линейный по амплитуде: веса в сумме дают 1, поэтому у некоррелированных сигналов мощность в середине перехода ниже на 3 дБ.

`abs` и `square` нелинейны и рождают новые частоты: $\cos^2\omega_0 n = \tfrac12 + \tfrac12\cos 2\omega_0 n$ — квадрат удваивает частоту и добавляет постоянную составляющую; модуль синуса даёт постоянную и чётные гармоники.

Входы разной длины: короткий дополняется нулями до длины длинного (у `binary` деление на эти нули — ошибка области); каналы сопоставляются по номеру, у входа с меньшим числом каналов повторяется последний; частоты дискретизации должны совпадать.

## Алгоритм и стоимость

1. Один проход по отсчётам; у `math` и `binary` перед вычислением — проверка области.
2. Если результат стал $\pm\infty$ или NaN (например, $e^{800}$ или $(10^{200})^2$), блок не выдаёт его, а сообщает об ошибке.
3. `mix` вычисляет вес $w[n]$ на лету; в режиме `sum` веса нет.

Стоимость $O(N)$ на канал, память — выход.

## Проверки

- `affine` с множителем −1,5 и сдвигом 0,25 совпадает с numpy до $10^{-15}$; все операции `math` с $p = 2{,}5$ — с numpy до $10^{-12}$.
- Значения вне области (логарифм нуля, корень из −1, $1/0$, $(-2)^{0{,}5}$, $0^{-1}$) отклоняются, сообщение называет операцию, отсчёт и значение; $(-2)^3 = -8$ точно; $e^{800}$ — ошибка.
- `binary`: деление, min, max и hypot со вторым сигналом короче (300 отсчётов) и pow совпадают с numpy до $10^{-12}$; деление на дополненные нули и разные частоты дискретизации — ошибки; одноканальный второй вход применяется к обоим каналам.
- `mix` (−3 и +2 дБ, переход с 4 мс длиной 5 мс) совпадает с numpy до $10^{-12}$; при длине 0 переключение точное: (1, 1, 2, 2) (`tests/pipeline/test_blocks_more2.cpp`).
- `abs` и `square` дают точные значения на (−2; 0,5; 3); квадрат $10^{200}$ отклоняется (`tests/pipeline/test_blocks_more.cpp`).

## Реализация

Проверка области `math` до вычисления: отказ вместо NaN или бесконечности.

```cpp
bool math_defined(std::string_view op, double x, double p) {
    if (op == "log" || op == "log10") return x > 0;
    if (op == "sqrt") return x >= 0;
    if (op == "reciprocal") return x != 0;
    if (op == "pow") return !(x < 0 && !whole(p)) && !(x == 0 && p < 0);
    return true;
}
```
