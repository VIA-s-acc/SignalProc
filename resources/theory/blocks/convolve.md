## Назначение

Применить КИХ-фильтр $h$ к сигналу $x$: базовая операция всех банков фильтров, из которой складываются анализ и синтез.

## Формулы

Линейная свёртка сигналов длины $N$ и $L$ даёт $N + L - 1$ отсчётов:

$$y[n] = \sum_k h[k]\, x[n-k]$$

Та же операция — умножение на ленточную тёплицеву матрицу (§2.2), $(T_h)_{ij} = h[i-j]$:

$$y = T_h\, x, \qquad T_h \in \mathbb R^{(N+L-1)\times N}$$

Круговая свёртка длины $N$ и её диагонализация DFT (§2.3):

$$(h \circledast x)[n] = \sum_k h[k]\, x[(n-k) \bmod N], \qquad h \circledast x = F^{-1}\big(\hat h \cdot \hat x\big)$$

Линейная совпадает с круговой, если оба сигнала дополнены нулями до длины $\ge N + L - 1$. В многочленах Лорана начальный индекс результата равен сумме начальных индексов сомножителей.

## Алгоритм и стоимость

1. Метод «прямой»: двойной цикл по коэффициентам, $O(NL)$ умножений.
2. Метод «FFT»: нулевое дополнение до удобной длины $n \ge N + L - 1$, два прямых и одно обратное вещественных БПФ, поэлементное произведение спектров — $O(n \log n)$.
3. Автовыбор: FFT, если $\min(N, L) \ge 160$ (константа `fft_threshold`), иначе прямой метод.

Память $O(N + L)$. Ошибка FFT-свёртки порядка $u \log n\,\|h\|\,\|x\|$ абсолютна, а не относительна к каждому отсчёту: малые выходы получают большую относительную ошибку.

## Проверки

Проверить стоило бы, что прямая свёртка, FFT-свёртка и умножение на тёплицеву матрицу совпадают с точностью $10^{-13}\|h\|_1\|x\|_\infty$, а круговая равна линейной после свёртки по модулю $N$ — эти проверки живут в `tests/core/test_conv.cpp`, на экране их нет.

## Реализация

Выбор метода по длинам сомножителей и вызов прямого или FFT-варианта.

```cpp
Laurent convolve(const Laurent& a, const Laurent& b, ConvMethod method) {
    if (a.coeffs.empty() || b.coeffs.empty()) return {{}, a.offset + b.offset};
    if (method == ConvMethod::automatic)
        method = std::min(a.coeffs.size(), b.coeffs.size()) >= fft_threshold ? ConvMethod::fft : ConvMethod::direct;
    return method == ConvMethod::fft ? convolve_fft(a, b) : multiply(a, b);
}
```
