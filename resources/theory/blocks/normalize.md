## Назначение

Привести уровень сигнала к заданному значению в дБFS: либо так, чтобы максимум модуля стал равен цели (по пику), либо так, чтобы среднеквадратичное значение стало равно цели (по RMS). Форма сигнала не меняется.

## Формулы

Цель $T$ в дБFS переводится в амплитуду $10^{T/20}$. По пику, $P = \max_n \lvert x[n] \rvert$:

$$y[n] = \frac{10^{T/20}}{P}\, x[n], \qquad \max_n \lvert y[n] \rvert = 10^{T/20}$$

По RMS, $\rho = \sqrt{\tfrac{1}{N} \sum_{n=0}^{N-1} x[n]^2}$:

$$y[n] = \frac{10^{T/20}}{\rho}\, x[n], \qquad \sqrt{\tfrac{1}{N} \sum_n y[n]^2} = 10^{T/20}$$

Это усиление $y = g\,x$ с $G = T - L_x$ дБ, где $L_x = 20 \log_{10} P$ или $20 \log_{10} \rho$ — текущий уровень. Если $P = 0$ или $\rho = 0$ (тишина), сигнал остаётся как есть.

Нормализация по RMS не гарантирует отсутствие среза: пик выходного сигнала равен $T + C$ дБFS, где $C = 20 \log_{10}(P / \rho)$ — пик-фактор. Срез начнётся, как только $T + C \ge 0$.

## Алгоритм и стоимость

1. Один проход: максимум модуля (по пику) либо сумма квадратов с компенсированным суммированием Неймайера (по RMS).
2. Если найденная величина равна нулю, возвращается копия входа.
3. Иначе множитель $10^{T/20}$, делённый на найденный уровень, применяется ко всем отсчётам.

Два прохода по $N$ отсчётам: поиск уровня и масштабирование; память $O(N)$. После масштабирования уровень совпадает с целью до погрешности округления.

## С числами этого блока

Режим {{block.kind}}, цель $T = {{block.target_dbfs}}$ дБFS, то есть амплитуда $10^{ {{block.target_dbfs}} / 20}$ в долях полной шкалы. Режим по пику ставит на это значение максимум модуля; режим по RMS — среднеквадратичное значение, и тогда пики оказываются выше цели на пик-фактор.

—

Тесты проверяют, что после нормализации по пику максимум равен цели, а после нормализации по RMS RMS равен цели (обе проверки с погрешностью $10^{-12}$ дБ), а нулевой сигнал остаётся нулевым.

## Реализация

Две ветви нормализации: максимум модуля либо RMS через энергию, затем одно масштабирование.

```cpp
std::vector<double> normalize_peak(std::span<const double> x, double target_dbfs) {
    double peak = 0;
    for (double v : x) peak = std::max(peak, std::abs(v));
    if (peak == 0) return {x.begin(), x.end()};
    return scaled(x, db_to_amplitude(target_dbfs) / peak);
}

std::vector<double> normalize_rms(std::span<const double> x, double target_dbfs) {
    const double rms = x.empty() ? 0.0 : std::sqrt(energy(x) / static_cast<double>(x.size()));
    if (rms == 0) return {x.begin(), x.end()};
    return scaled(x, db_to_amplitude(target_dbfs) / rms);
}
```
