## Назначение

Оставить из сигнала фрагмент между двумя отсчётами $[b, e)$ и отбросить остальное. Нужно, чтобы выделить интересный участок для анализа, прослушивания или записи.

## Формулы

Границы — номера отсчётов, правая не входит в фрагмент:

$$y[n] = x[b + n], \qquad 0 \le n < e - b, \qquad 0 \le b \le e \le N$$

Длина выхода $e - b$; при $b = e$ получается пустой сигнал, он допустим. Время границ в секундах — $b / f_s$ и $e / f_s$, длительность фрагмента $(e - b) / f_s$.

Вырезка — умножение на прямоугольное окно: $y$ — это $x[m]\, w[m]$ при $w[m] = 1$ на $b \le m < e$, сдвинутое к нулю. Спектр фрагмента равен спектру $X$, свёрнутому со спектром окна (ядром Дирихле): главный лепесток шириной $4\pi/(e-b)$, боковые лепестки около $-13$ дБ (§9.3). Если сигнал на границе не равен нулю, обрезка даёт скачок и слышимый щелчок.

## Алгоритм и стоимость

1. Проверяется $b \le e \le N$; иначе ошибка с допустимым пределом $N$.
2. Диапазон $[b, e)$ копируется в новый вектор.

Время и память $O(e - b)$. Значения не меняются, обрезка точная.

## С числами этого блока

Границы $b = {{block.begin}}$ и $e = {{block.end}}$ дают фрагмент $y[n] = x[{{block.begin}} + n]$ длиной $e - b$ отсчётов. Если сигнал на границах не нулевой, при воспроизведении возможен щелчок на краю фрагмента: его снимает короткое затухание.

## Проверки

—

Тесты проверяют, что неверные границы дают ошибку ($b > e$ и $e > N$), что фрагмент $[1, 3)$ из $(1, 2, 3, 4)$ равен $(2, 3)$, а фрагмент $[4, 4)$ пуст.

## Связи

- §9.3 — метод окон: прямоугольное окно, его боковые лепестки.
- §0.1 — сигнал конечной длины $N$ с индексами $0, \dots, N-1$.
- §1.2 — спектр произведения на окно — свёртка спектров.
- Блок «Задержка» — обратное действие, оно добавляет нули слева, а не отбрасывает отсчёты.

## Реализация

Проверка границ и копирование диапазона $[b, e)$.

```cpp
Result<std::vector<double>> cut(std::span<const double> x, std::size_t begin, std::size_t end) {
    if (begin > end || end > x.size())
        return make_error(Errc::invalid_argument, "cut: need begin <= end <= " + std::to_string(x.size()));
    return std::vector<double>(x.begin() + static_cast<std::ptrdiff_t>(begin), x.begin() + static_cast<std::ptrdiff_t>(end));
}
```
