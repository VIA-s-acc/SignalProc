## Назначение

Собрать сигнал обратно из полос $a_J, d_J, \dots, d_1$: на каждом уровне вставить нули, отфильтровать синтезирующими $f_0, f_1$ и сложить. Если банк обладает PR, результат совпадает с исходным сигналом.

## Формулы

$$a_{j-1}[m] = \sum_k \left(f_0[m-2k]\, a_j[k] + f_1[m-2k]\, d_j[k]\right), \qquad j = J, J-1, \dots, 1, \qquad \hat x = a_0$$

Фаза pywt (§0.4) срезает по $L-2$ отсчётов с каждого края полной свёртки: выходной отсчёт $i$ собирается из слагаемых с $m = i + L - 2$, а длина результата для $n$ коэффициентов в полосе равна

$$n_{\mathrm{out}} = 2n - L + 2$$

В режиме `periodization` длина результата ровно $2n$.

Условие точного восстановления — нулевое наложение и чистая задержка (§4.1): $A \equiv 0$, $T = z^{-\ell}$.

## Алгоритм и стоимость

1. Начать с $a_J$ и $d_J$.
2. Для $j = J, \dots, 1$: если $a_j$ на один отсчёт длиннее $d_j$ (нечётная длина на прямом проходе), отбросить последний отсчёт $a_j$; затем $a_{j-1} = \mathrm{idwt}(a_j, d_j)$.
3. Обрезать результат до исходной длины $N$.

Нули при $\uparrow 2$ не материализуются: для выходного отсчёта суммируются только отводы с шагом два. Стоимость $\approx N\,(L_0 + L_1)$ умножений, память $O(N)$ — как у прямой пирамиды. Знак ФВЧ синтеза определяется настройкой совместимости с pywt.

## С числами этого блока

Банк {{block.wavelet}}, $J = {{block.levels}}$ уровней, края — {{block.mode}}: из полос восстанавливается $N = {{block.n}}$ отсчётов за $J = {{block.levels}}$ проходов синтеза.

## Проверки

- Точное восстановление на этом сигнале, $\max\lvert \hat x - x \rvert$: {{check.round_trip}}
- `idwt(dwt(x))` равно `x` во всех девяти режимах границ для ортогональных и биортогональных банков (§6.5).
- Одноотсчётные сигналы возвращаются в тех режимах, где они допустимы; рассогласование длин аппроксимации и деталей — ошибка (тест).

## Реализация

Один уровень синтеза: для каждого выходного отсчёта суммируются вклады аппроксимации и деталей с шагом два.

```cpp
    for (std::ptrdiff_t i = 0; i < out_len; ++i) {
        if (stop_requested(progress, static_cast<std::size_t>(i))) return std::unexpected{cancelled_error("idwt")};
        const auto pos = i + filter_len - 2;
        T acc(0);
        for (std::ptrdiff_t k = std::max<std::ptrdiff_t>(0, (pos - filter_len + 2) / 2); k < n; ++k) {
            const auto j = pos - 2 * k;
            if (j < 0) break;
            if (j >= filter_len) continue;
            acc += lo[static_cast<std::size_t>(j)] * approx[static_cast<std::size_t>(k)] +
                   hi[static_cast<std::size_t>(j)] * detail[static_cast<std::size_t>(k)];
        }
        out[static_cast<std::size_t>(i)] = acc;
    }
```
