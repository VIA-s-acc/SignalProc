## Назначение

Повысить частоту дискретизации в $M$ раз: вставить $M-1$ нулей между отсчётами и сгладить ФНЧ, убрав зеркальные копии спектра.

## Формулы

$${\uparrow}M:\quad y[n] = \begin{cases} x[n/M], & M \mid n \\ 0, & \text{иначе} \end{cases} \qquad Y(z) = X(z^M)$$

Спектр сжимается в $M$ раз, появляются $M-1$ зеркальных копий (imaging) на частотах $2\pi k/M$. Интерполятор — ${\uparrow}M$, затем ФНЧ со срезом $\pi/M$ и усилением $M$:

$$y = g * ({\uparrow}M\, x), \qquad g = M\, h, \qquad \sum_m g[m] = M$$

Усиление $M$ нужно потому, что вставка нулей уменьшает среднее в $M$ раз: фильтр возвращает амплитуду.

## Алгоритм и стоимость

1. Коэффициент $M = 0$ — ошибка; без фильтра результат — сигнал с нулями между отсчётами.
2. Отсчёты раскладываются с шагом $M$ в массив длины $N M$.
3. Фильтр Кайзера со срезом $\pi/M$ (как у дециматора) умножается на $M$; его задержка $(L-1)/2$ компенсируется.
4. Свёртка (§1.1), результат обрезается до ровно $N M$ отсчётов.

Стоимость $\approx N M L$ умножений (длинные сомножители идут через FFT): фильтруется массив с нулями целиком; полифазная форма (§3.4) обошлась бы в $N L$ — нули не умножаются.

## С числами этого блока

$M = {{block.m}}$: после каждого отсчёта идёт $M - 1 = {{block.m}} - 1$ нулей, спектр $Y(z) = X(z^{ {{block.m}} })$.

Фильтр из $L = {{block.taps}}$ отводов с усилением $M$ на нуле; задержка $(L-1)/2 = ({{block.taps}} - 1)/2$ отсчётов компенсирована.

## Проверки

Проверить стоило бы, что без фильтра вставка нулей точна ($[1, 2] \to [1, 0, 0, 2, 0, 0]$), а цепочка «интерполяция, затем децимация» возвращает полосно-ограниченный сигнал в пределах пульсаций — эти проверки живут в `tests/core/test_multirate.cpp`, на экране их нет.

## Связи

- §3.1 — спектр после ${\uparrow}M$: зеркальные копии.
- §3.2 — интерполятор: срез $\pi/M$ и усиление $M$.
- §3.4 — полифазный интерполятор без умножений на нули.
- §4.1 — в банке фильтров ${\uparrow}2$ — часть синтеза, наложение гасится вторым каналом.
- §11.1 — обратный DWT: ${\uparrow}2$ и синтезирующие фильтры.

## Реализация

Вставка нулей, ФНЧ с усилением $M$ и обрезка до $N M$ отсчётов с учётом задержки фильтра.

```cpp
std::vector<double> stuffed(x.size() * m, 0.0);
for (std::size_t k = 0; k < x.size(); ++k) stuffed[k * m] = x[k];
if (m == 1 || !options.anti_alias || x.empty()) return stuffed;
auto h = anti_alias_filter(m, options);
for (double& c : h.coeffs) c *= static_cast<double>(m);
const auto filtered = convolve(Laurent{std::move(stuffed), 0}, h);
const std::size_t d = filter_delay(h, options);
return std::vector<double>(filtered.coeffs.begin() + static_cast<std::ptrdiff_t>(d),
                           filtered.coeffs.begin() + static_cast<std::ptrdiff_t>(d + x.size() * m));
```
