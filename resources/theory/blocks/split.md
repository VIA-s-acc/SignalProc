## Назначение

Разделить многоканальный сигнал на независимые моно-сигналы, по одному на канал, чтобы обрабатывать каждый своей цепочкой блоков. Частота дискретизации и число отсчётов у всех ветвей остаются прежними.

## Формулы

Многоканальный сигнал — набор $x_0[n], \dots, x_{C-1}[n]$ одной длины $N$; ветвь $c$ получает свой канал без изменений:

$$y_c[n] = x_c[n], \qquad c = 0, \dots, C-1, \quad n = 0, \dots, N-1$$

В файле WAV отсчёты перемежаются кадрами, $s[nC + c] = x_c[n]$; разделение — это обращение такого перемежения. Операция не меняет значений, поэтому она точная: никаких округлений.

Поканальная обработка одинаковыми фильтрами и уровнями даёт выровненные коэффициенты каналов; пороги и маски поддиапазонов для стерео обычно делают общими, чтобы сохранить стереобазу (§12.6).

## Алгоритм и стоимость

1. Проверяется, что запрошенный канал существует; иначе ошибка с номером канала и числом каналов.
2. Выбранный вектор копируется в новый моно-буфер с той же частотой дискретизации.
3. Ветвь $c$ — это результат `select_channel(audio, c)`; для всех каналов вызов повторяется с индексами $0, \dots, C-1$.

Отдельной функции «split» в коде нет: разделение сводится к выбору канала. Время и память на ветвь $O(N)$ (копия вектора); все $C$ ветвей вместе занимают столько же памяти, сколько вход.

## С числами этого блока

Входной сигнал имеет $C = {{block.channels}}$ кан.; значит, на выходе $C$ независимых моно-сигналов, каждый длины $N$ и с той же частотой дискретизации $f_s$. Для стерео это левый и правый; при $C = 1$ блок просто передаёт единственный канал дальше.

## Проверки

Численной проверки в интерфейсе у этого блока нет: его правильность закрепляют тесты.

Тест проверяет, что выбранный канал совпадает с исходным (для стерео-пары $(1, 3)$ и $(3, 5)$ канал 1 даёт $(3, 5)$), а запрос несуществующего канала возвращает ошибку.

## Связи

- §12.6 — стерео: поканальная обработка, одинаковые фильтры и уровни, одна маска на оба канала.
- §0.1 — сигнал $x[n]$ конечной длины $N$.
- Блок «Микширование в моно» собирает каналы обратно в один усреднением.
- Блок «Mid/side» — альтернатива поканальной обработке для стерео.

## Реализация

Отдельной функции «split» нет; ближайший реальный код — `select_channel`, который берёт нужный канал в новый моно-буфер.

```cpp
Result<AudioBuffer> select_channel(const AudioBuffer& audio, std::size_t index) {
    if (index >= audio.channels.size())
        return make_error(Errc::invalid_argument, "channel " + std::to_string(index) + " does not exist (" +
                                                      std::to_string(audio.channels.size()) + " channels)");
    return AudioBuffer{audio.sample_rate, {audio.channels[index]}};
}
```
