## Назначение

Построить максимально плоский полуполосный фильтр $P_p$ и разделить его корни между $H_0$ и $F_0$: каждое расщепление даёт двухканальный банк с точным восстановлением, а показатель Соболева говорит, порождает ли он вейвлетный базис.

## Формулы

$$P_p(z) = 2\left(\frac{(1+z)(1+z^{-1})}{4}\right)^{p} B_p\left(\frac{2-z-z^{-1}}{4}\right), \qquad B_p(y) = \sum_{k=0}^{p-1} \binom{p-1+k}{k}\, y^k$$

$$P_p(z) + P_p(-z) = 2, \qquad P_0(z) = z^{-(2p-1)}\, P_p(z), \qquad \deg P_0 = 4p-2$$

Корни $y_j$ многочлена $B_p$ дают пары $z_j, 1/z_j$ из уравнения $z^2 - c_j z + 1 = 0$, $c_j = 2 - 4 y_j$. Расщепление: $k$ нулей в $z = -1$ и подмножество $S$ групп корней уходят в $H_0$, остальное — в $F_0$:

$$H_0(z) \propto (1+z^{-1})^{k} \prod_{g \in S} (1 - z_g z^{-1}), \qquad F_0(z) \propto (1+z^{-1})^{2p-k} \prod_{g \notin S} (1 - z_g z^{-1}), \qquad H_0(1) = F_0(1) = \sqrt2$$

Показатель Соболева стороны с $N$ нулями в $-1$ (Villemoes), $m(\omega) = \left(\tfrac{1+e^{-i\omega}}{2}\right)^N L(\omega)$:

$$s = N - \log_4 \rho(T_W), \qquad (T_W)_{n,k} = 2\, w_{2n-k}, \qquad \lvert L(e^{i\omega}) \rvert^2 = \sum_j w_j\, e^{ij\omega}$$

Вейвлетный базис Рисса получается, когда $s > 0$ у обеих сторон.

## Алгоритм и стоимость

1. Коэффициенты $B_p$ — целые биномиальные; корни $y_j$ степени $p-1$ ищутся итерацией Аберта в 256-битной арифметике. Нули в $z = -1$ в поиск корней не передаются.
2. Каждый $y_j$ даёт пару $z_j, 1/z_j$. Вещественный корень — отдельная группа, комплексный — группа вместе с сопряжённым. Групп $g$, причём $p-1 \le g \le 2(p-1)$.
3. Для каждого $k = 0, \dots, 2p$ и каждого из $2^g$ подмножеств групп собираются $H_0$ и $F_0$, нормируются на $\sqrt2$, проверяется полуполосность $P_0$ и фильтры укладываются в раскладку pywt (§0.4).
4. Расщепление классифицируется: ортогональное, линейно-фазовое или прочее; считаются $s$ для обеих сторон.

Всего $(2p+1)\,2^{g}$ расщеплений, на каждое — произведение многочленов длины $O(p)$. Для $p = 2$: $5 \cdot 4 = 20$ расщеплений, 6 из них вейвлетные.

## С числами этого блока

$p = {{block.p}}$: фильтр $P_0$ имеет степень $4p-2 = {{block.degree}}$ и $2p$ нулей в $z = -1$. Перебор даёт {{block.splits}} расщеплений, из них {{block.wavelet_splits}} — вейвлетные.

Выбрано расщепление «{{block.split}}»: в $H_0$ уходит $k = {{block.zeros_h0}}$ нулей в $-1$, длина $H_0$ — {{block.h0_length}}; в $F_0$ — $2p-k = {{block.zeros_f0}}$ нулей, длина $F_0$ — {{block.f0_length}}. Задержка банка в раскладке pywt $\ell = {{block.delay}}$.

Показатели Соболева: $s(\tilde\varphi) = {{metric.sobolev_h0}}$ для $H_0$ и $s(\varphi) = {{metric.sobolev_f0}}$ для $F_0$.

## Проверки

- Наложение $A \equiv 0$, $\max$ модуля коэффициентов $\tfrac12\left[F_0(z) H_0(-z) + F_1(z) H_1(-z)\right]$: {{check.pr_alias}}
- Искажение $T = z^{-\ell}$, наибольшее отклонение коэффициентов $\tfrac12\left[F_0 H_0 + F_1 H_1\right]$ от единичного импульса: {{check.pr_distortion}}
- Ортогональность $\sum_n h_0[n]\, h_0[n+2k] = \delta[k]$ и $f_0$ — обращённый $h_0$: {{check.orthogonality}}. У биортогональных расщеплений эта проверка не проходит по построению.
- Полуполосность $P_p(z) + P_p(-z) = 2$ выполняется тождественно для любого $p$ — это тождество Безу, а не численный результат.

## Реализация

Расщепление: степени $(1+z^{-1})$ и множители групп корней распределяются между $H_0$ и $F_0$ (`one_plus` — многочлен $1 + z^{-1}$), затем банк нормируется и проверяется на PR.

```cpp
auto h0 = power(one_plus, split.zeros_h0);
auto f0 = power(one_plus, 2 * f.p - split.zeros_h0);
for (std::size_t g = 0; g < f.groups.size(); ++g) {
    if (split.group_in_h0[g])
        h0 = multiply(h0, group_factor(f.groups[g]));
    else
        f0 = multiply(f0, group_factor(f.groups[g]));
}
return make_bank<double>(std::move(name), normalised(h0), normalised(f0));
```
