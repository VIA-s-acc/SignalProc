## Назначение

Фильтры с обратной связью (БИХ), у которых выход зависит от прошлых выходов: `lfilter` — любое разностное уравнение по коэффициентам $b$ и $a$, `biquad` — секция второго порядка по рецептам RBJ, `dc_block` — снятие постоянной составляющей, `comb` — гребёнка с задержкой $D$.

## Формулы

`lfilter` — разностное уравнение с нулевым начальным состоянием, как `scipy.signal.lfilter` без `zi`:

$$a_0\,y[n] = \sum_{k=0}^{M} b_k\,x[n-k] - \sum_{k=1}^{P} a_k\,y[n-k], \qquad H(z) = \frac{\sum_k b_k z^{-k}}{\sum_k a_k z^{-k}}$$

Все корни $A(z)$ должны лежать в $\lvert p\rvert \le 1 + 10^{-6}$: полюс на единичной окружности (интегратор $a = (1, -1)$) допускается, $a_0 = 0$ — нет.

`biquad` — кулинарная книга RBJ, $\omega_0 = 2\pi f_0/f_s$, $\alpha = \sin\omega_0/(2Q)$, $A = 10^{G/40}$ ($G$ — `gain_db`). Например, ФНЧ и пиковый:

$$b = \big(\tfrac{1-\cos\omega_0}{2},\ 1-\cos\omega_0,\ \tfrac{1-\cos\omega_0}{2}\big), \qquad a = (1+\alpha,\ -2\cos\omega_0,\ 1-\alpha)$$

$$b = (1+\alpha A,\ -2\cos\omega_0,\ 1-\alpha A), \qquad a = (1+\alpha/A,\ -2\cos\omega_0,\ 1-\alpha/A)$$

Полоса `bandpass` — $b = (\alpha, 0, -\alpha)$ с пиком 0 дБ; полки берут $2\sqrt{A}\,\alpha$ — форма через $Q$, а не через наклон $S$. Усиление $G$ влияет только на `peaking`, `lowshelf` и `highshelf`.

`dc_block` — нуль в $z = 1$ и полюс в $r$; срез около $(1-r)\,f_s/2\pi$:

$$y[n] = x[n] - x[n-1] + r\,y[n-1], \qquad H(z) = \frac{1 - z^{-1}}{1 - r z^{-1}}$$

`comb` — пики или провалы через $f_s/D$; обратная связь требует $\lvert g\rvert < 1$:

$$y[n] = x[n] + g\,x[n-D] \quad (H = 1 + g z^{-D}), \qquad y[n] = x[n] + g\,y[n-D] \quad \Big(H = \frac{1}{1 - g z^{-D}}\Big)$$

## Алгоритм и стоимость

1. `lfilter`: коэффициенты делятся на $a_0$, корни $A(z)$ проверяются на устойчивость; затем КИХ-часть $b * x$ (обрезанная до $N$, для длинных $b$ — через БПФ) и рекурсия по $a$ на месте — прямая форма I.
2. `biquad`: коэффициенты RBJ делятся на $a_0$; $f_0$ должна лежать в $(0, f_s/2)$; фильтр — транспонированная прямая форма II с двумя переменными состояния.
3. `dc_block`: та же схема первого порядка с одной переменной состояния.
4. `comb`: задержка $D$ в отсчётах или в секундах (`0.01s` даёт $\mathrm{round}(0{,}01\,f_s)$), $D = 0$ отклоняется; при $n < D$ выход равен входу.

Стоимость `lfilter` — $O\big(N\,(M+P)\big)$ плюс поиск корней степени $P \le 127$ (до 128 коэффициентов $a$); `biquad`, `dc_block` и `comb` — $O(N)$.

## Проверки

- `lfilter` совпадает со `scipy.signal.lfilter` до $10^{-10}$ на четырёх парах $(b, a)$, включая $a_0 = 2$ и интегратор $a = (1, -1)$; $a = (0, 1)$ и полюс 1,5 дают ошибку с причиной, двойной полюс $a = (1, -2, 1)$ принимается.
- `biquad`: все восемь типов совпадают с `lfilter` по коэффициентам RBJ до $10^{-10}$; $f_0 = 4000$ Гц при $f_s = 8000$ отклоняется.
- `comb`: прямая ($D = 9$, $g = -0{,}8$) и обратная ($D = 23$, $g = 0{,}6$) совпадают с `lfilter` с линией задержки до $10^{-10}$; обратная с $g = 1$ и $D = 0$ отклоняются.
- `dc_block`: сигнал со смещением 0,5 при $r = 0{,}99$ совпадает с `lfilter([1, -1], [1, -0.99])` до $10^{-12}$; на постоянном входе выход к 4000-му отсчёту меньше $10^{-12}$.

## Реализация

Транспонированная прямая форма II: две переменные состояния на секцию.

```cpp
    for (std::size_t n = 0; n < x.size(); ++n) {
        y[n] = f.b0 * x[n] + z0;
        z0 = f.b1 * x[n] - f.a1 * y[n] + z1;
        z1 = f.b2 * x[n] - f.a2 * y[n];
    }
```
