## Назначение

`lpc` описывает сигнал всеполюсной моделью порядка $p$: находит коэффициенты предсказателя и отражения, выигрыш предсказания и остаток — то, что предсказать не удалось. `lpc_synth` пропускает остаток через обратный фильтр и точно возвращает сигнал.

## Формулы

Автокорреляция без окна и без деления на длину:

$$r[\ell] = \sum_{n=\ell}^{N-1} x[n]\,x[n-\ell], \qquad \ell = 0, \dots, p$$

Левинсон–Дурбин для $A(z) = 1 + \sum_{j=1}^{p} a_j z^{-j}$, $E_0 = r[0]$:

$$k_m = -\frac{r[m] + \sum_{j=1}^{m-1} a^{(m-1)}_j\,r[m-j]}{E_{m-1}}, \qquad a^{(m)}_j = a^{(m-1)}_j + k_m\,a^{(m-1)}_{m-j}, \qquad a^{(m)}_m = k_m$$

$$E_m = (1 - k_m^2)\,E_{m-1}, \qquad G = 10\log_{10}\frac{r[0]}{E_p}\ \mathrm{dB}$$

Знаки: предсказание $\hat x[n] = -\sum_j a_j x[n-j]$, а $k_m$ совпадает с последним коэффициентом $a^{(m)}_m$; частичная автокорреляция на задержке $m$ равна $-k_m$.

Остаток — КИХ-фильтр $A(z)$, синтез — БИХ-фильтр $1/A(z)$, оба с нулевым начальным состоянием:

$$e[n] = x[n] + \sum_{j=1}^{\min(p,n)} a_j\,x[n-j], \qquad y[n] = e[n] - \sum_{j=1}^{\min(p,n)} a_j\,y[n-j]$$

## Алгоритм и стоимость

1. Автокорреляция по каналу; при $r[0] = 0$ (тишина) все $a_j = k_j = 0$, $G = 0$, остаток равен сигналу.
2. Рекурсия порядок за порядком; если $\lvert k_m\rvert \ge 1$ или $E_m \le 0$, блок останавливается: порядок слишком велик для сигнала (например, чистый тон).
3. Отчёт: `order`, `gain_db`, `a1…ap`, `k1…kp`, у нескольких каналов — с суффиксом `_chN`.
4. `lpc_synth` читает из отчёта порядок и $a_j$; число каналов отчёта и остатка должно совпадать.

Стоимость $O(N p)$ на автокорреляцию и каждый фильтр плюс $O(p^2)$ на рекурсию.

## С числами этого блока

Порядок модели $p$ = {{block.order}}: столько коэффициентов $a_j$ и $k_j$ в отчёте на каждый канал. Узел работал {{block.wall}}, память {{block.bytes}}.

## Проверки

- Для $p = 4$ и $p = 12$ коэффициенты $a_j$ совпадают со `scipy.linalg.solve_toeplitz` до $10^{-10}$, отражения $k_j$ — с эталонной рекурсией Левинсона–Дурбина до $10^{-10}$, `gain_db` — до $10^{-10}$, остаток — со `scipy.signal.lfilter([1, a], 1, x)` до $10^{-10}$.
- `lpc_synth` возвращает исходный сигнал до $10^{-10}$, в том числе для трёх каналов с коротким тихим каналом, у которого $a_1 = 0$ и $G = 0$.
- Пустой отчёт и отчёт с другим числом каналов отклоняются; порядок 64 на чистом косинусе из 64 отсчётов либо считается, либо отклоняется с сообщением о порядке; один отсчёт 0,5 возвращается без изменений.

## Реализация

Шаг рекурсии Левинсона–Дурбина: отражение, обновление коэффициентов и ошибки, проверка устойчивости.

```cpp
    for (std::size_t m = 1; m <= order; ++m) {
        double acc = r[m];
        for (std::size_t j = 1; j < m; ++j) acc += a[j] * r[m - j];
        const double k = -acc / error;
        previous = a;
        for (std::size_t j = 1; j < m; ++j) a[j] = previous[j] + k * previous[m - j];
        a[m] = k;
        error *= 1 - k * k;
        if (!(std::abs(k) < 1) || !(error > 0)) return fail(tr("pipeline.error.lpc_order"), fmt::arg("order", order));
        out.k[m - 1] = k;
    }
```
