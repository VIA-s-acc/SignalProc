## Назначение

Добавить к сигналу его задержанные копии: `echo` — одна линия задержки с обратной связью, повторы через равные интервалы; `reverb` — схема Freeverb из восьми гребенчатых фильтров с затуханием высоких частот и четырёх диффузоров, которая даёт плотный «хвост» комнаты.

## Формулы

Эхо: задержка $D = \lfloor \tau f_s/1000 + 1/2 \rfloor \ge 1$ отсчётов ($\tau$ в мс), обратная связь $g$, доля $m$:

$$e[n] = x[n-D] + g\,e[n-D], \qquad E(z) = \frac{z^{-D}}{1 - g z^{-D}}, \qquad y = (1-m)\,x + m\,e$$

Импульсный отклик: $1-m$ в нуле и $m\,g^{j-1}$ в точках $jD$, $j \ge 1$. АЧХ мокрого сигнала — гребень с пиками на кратных $f_s/D$ и отношением пика к провалу $(1+\lvert g\rvert)/(1-\lvert g\rvert)$.

Реверберация (Freeverb, Jezar): длины линий заданы для 44,1 кГц и масштабируются, $L = \max\big(1, \lfloor L_{44} f_s/44100 + 1/2 \rfloor\big)$; гребни $L_{44} \in \{1116, 1188, 1277, 1356, 1422, 1491, 1557, 1617\}$, диффузоры $\{556, 441, 341, 225\}$.

Каждый гребень — линия $b$ длины $L_i$ и однополюсный ФНЧ $f$ в петле; размер комнаты $R$ и затухание $D_a$ задают

$$o[n] = b[n - L_i], \quad f[n] = (1-d)\,o[n] + d\,f[n-1], \quad b[n] = 0{,}015\,x[n] + g\,f[n], \qquad g = 0{,}28R + 0{,}7, \quad d = 0{,}4D_a$$

$$C_i(z) = \frac{0{,}015\,z^{-L_i}}{1 - g\,\frac{1-d}{1 - d z^{-1}}\,z^{-L_i}}, \qquad s = \sum_{i=1}^{8} o_i$$

Усиление петли — $g$ на нуле частоты и $g(1-d)/(1+d)$ на Найквисте: высокие гаснут быстрее. Спад на 60 дБ на низких частотах $T_{60} \approx -3L_i/(f_s \lg g)$; при $R = 0{,}5$ ($g = 0{,}84$) и $L = 1617$ — около 1,5 с.

Четыре диффузора последовательно, обратная связь $1/2$:

$$v[n] = s[n] + \tfrac12 v[n-L], \qquad s'[n] = v[n-L] - s[n], \qquad P(z) = \frac{-1 + \tfrac32 z^{-L}}{1 - \tfrac12 z^{-L}}$$

Это не фазовый фильтр Шрёдера $(-g + z^{-L})/(1 - g z^{-L})$ из §9.8: $\lvert P\rvert$ колеблется между $1$ и $5/3$. Так устроен оригинальный Freeverb, код его повторяет. Выход $y = W_d\,x + 3W_w\,s'$; в отличие от оригинала сухой сигнал не умножается на 2, а стереоразноса (+23 отсчёта у правого канала) нет — каждый канал проходит одни и те же линии отдельно.

## Алгоритм и стоимость

1. Эхо: задержка из миллисекунд с округлением, $D = 0$ — ошибка; рекурсия по одной линии.
2. Реверберация: длины линий пересчитываются под $f_s$; если самый длинный гребень длиннее $2^{20}$ отсчётов, блок отказывает.
3. Восемь гребней по очереди проходят весь сигнал, каждый со своим круговым буфером и ФНЧ в петле; выходы складываются.
4. Сумма проходит четыре диффузора последовательно, затем смешивается с сухим сигналом.

Эхо стоит $O(N)$, реверберация — $O(12N)$ на канал. Память: выход и одна линия за раз (до 1617 отсчётов на 44,1 кГц).

## Проверки

- `reverb` совпадает с построчной реализацией Freeverb на Python из `tools/gen_golden.py` до $10^{-12}$ для (размер; затухание; wet; dry) = (0,5; 0,5; 0,33; 0,7) и (0,95; 0,1; 1; 0).
- При wet = 0, dry = 1 выход точно равен входу; два канала стерео точно совпадают с отдельными моно-прогонами.
- `echo` (2 мс, $g = 0{,}5$, $m = 0{,}4$) совпадает со `scipy.signal.lfilter` с числителем $z^{-D}$ и знаменателем $1 - 0{,}5z^{-D}$ до $10^{-10}$; без частоты дискретизации блок отказывает (`tests/pipeline/test_blocks_more2.cpp`).

## Реализация

Один гребень Freeverb: чтение линии, ФНЧ в петле, запись входа с обратной связью.

```cpp
        for (std::size_t k = 0; k < x.size(); ++k) {
            const double out = line[at];
            store = out * (1 - damp) + store * damp;
            line[at] = 0.015 * x[k] + store * feedback;
            at = at + 1 == line.size() ? 0 : at + 1;
            acc[k] += out;
        }
```
