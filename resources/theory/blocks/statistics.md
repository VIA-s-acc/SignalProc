## Назначение

Описать распределение чисел, а не их порядок: `histogram` считает отсчёты каждого канала по равным корзинам, как `numpy.histogram`; `coeff_stats` для каждой полосы разложения сообщает долю энергии, энтропию и разреженность — насколько полоса годится для сжатия.

## Формулы

Гистограмма с $B$ корзинами на $[lo, hi]$ (по умолчанию $lo = \min x$, $hi = \max x$; при $lo = hi$ — $[lo - \tfrac12, hi + \tfrac12]$):

$$e_i = lo + i\,\frac{hi - lo}{B}, \quad e_B = hi, \qquad i(v) = \min\Big(B - 1,\ \Big\lfloor B\,\frac{v - lo}{hi - lo}\Big\rfloor\Big)$$

Корзины полуоткрыты $[e_i, e_{i+1})$, последняя замкнута $[e_{B-1}, hi]$; индекс $i(v)$ поправляется на единицу по фактическим границам $e_i$, как в numpy. Значения вне $[lo, hi]$ идут в `outside`; мода — середина самой полной корзины $(e_k + e_{k+1})/2$, при равенстве — первой.

Статистика полосы $b$ с коэффициентами $c_b[k]$, $k < N_b$:

$$\varepsilon_b = \frac{w_b E_b}{\sum_j w_j E_j}, \qquad E_b = \sum_k c_b[k]^2, \qquad H_b = -\sum_k p_k\log_2 p_k, \quad p_k = \frac{c_b[k]^2}{E_b}$$

$$s_b = \frac{\#\big\{k : \lvert c_b[k]\rvert < \tau\,c_{\max}\big\}}{N_b}, \qquad c_{\max} = \max_{j,k}\lvert c_j[k]\rvert$$

Веса $w_b = 1$, кроме ненормированного SWT: $w(a_J) = 2^{-J}$, $w(d_j) = 2^{-j}$ — так компенсируется рост энергии непрореженных уровней, и доли совпадают с блоком «Энергия по полосам». Энтропия — в битах, от 0 (вся энергия в одном коэффициенте) до $\log_2 N_b$ (энергия поровну). Порог разреженности берётся от наибольшего модуля по всем полосам канала, а не внутри полосы.

## Алгоритм и стоимость

1. `histogram`: границы и минимум с максимумом — по каналу; диапазон `range` задаётся двумя числами $lo < hi$ или `auto`; отсчёты NaN и бесконечности отклоняются.
2. Если $hi - lo$ переполняется (например, $\pm 1{,}7\cdot 10^{308}$), всё масштабируется на $\tfrac12$ до деления — индекс остаётся конечным.
3. `coeff_stats`: для каждой полосы — одна сумма квадратов, одна сумма $p\log_2 p$ и один подсчёт малых коэффициентов. При $E_b = 0$ энтропия 0, при $c_{\max} = 0$ разреженность 1.
4. Поля называются `c<канал>.<полоса>.energy|entropy|sparsity`; у пакетов полосы названы путями в дереве.

Стоимость $O(N)$ на канал для гистограммы и $O\big(\sum_b N_b\big)$ для статистики; память — $B$ счётчиков.

## Проверки

- `histogram` совпадает с `numpy.histogram`: счётчики, $lo$, $hi$ и число значений вне диапазона — точно, мода — до $10^{-15}$; случаи: 10 корзин на авто-диапазоне, 7 корзин на $[-1, 1]$, 4 корзины на постоянном сигнале.
- Отсчёты $0$, $0{,}5$, $1$ в двух корзинах дают «1 2» — правый край входит в последнюю корзину; диапазон «1 0» и NaN отклоняются с понятным сообщением; второй канал считается отдельно.
- Огромный диапазон $\pm 1{,}7\cdot 10^{308}$ и вырожденный постоянный сигнал не теряют отсчётов: все попадают в корзины.
- `coeff_stats` на db2, 3 уровня, $\tau = 0{,}05$: доли, энтропии и разреженности всех полос совпадают с эталоном numpy и pywt до $10^{-12}$; доли SWT совпадают с блоком `band_energy` до $10^{-15}$; у нулевого сигнала разреженность 1, энтропия и доля 0; полосы пакетов названы путями.

## Реализация

Раскладка отсчётов по корзинам с поправкой индекса по фактическим границам.

```cpp
    for (const double v : x) {
        if (!(v >= lo && v <= hi)) continue;
        const double position = (v * scale - lo * scale) / span * static_cast<double>(bins);
        if (!std::isfinite(position)) continue;
        auto k = static_cast<std::size_t>(std::clamp(position, 0.0, static_cast<double>(bins - 1)));
        if (k > 0 && v < edges[k]) --k;
        if (k + 1 < bins && v >= edges[k + 1]) ++k;
        ++counts[k];
        ++inside;
    }
```
