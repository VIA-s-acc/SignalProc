## Назначение

Записать один уровень банка фильтров матрицей: анализ $A$ стопкой строк $[L;\ B]$ и синтез $S$, по которым видны точное восстановление, ортогональность и обусловленность преобразования, включая поведение на границах.

## Формулы

Бесконечные матрицы (Strang–Nguyen, [SN]): каждая строка $A$ — обращённый фильтр, соседние строки сдвинуты на два; столбцы $S$ — сдвинутые фильтры синтеза.

$$L_{k,n} = h_0[2k-n], \qquad B_{k,n} = h_1[2k-n], \qquad A = \begin{pmatrix} L \\ B \end{pmatrix}, \qquad (S_L)_{n,k} = f_0[n-2k], \qquad (S_B)_{n,k} = f_1[n-2k], \qquad S = \begin{pmatrix} S_L & S_B \end{pmatrix}$$

$$S A = S_L L + S_B B = I \quad \text{(PR)}, \qquad S = A^{\mathsf T} \iff f_i[n] = h_i[-n] \quad \text{(ортогональный банк)}, \qquad A^{\mathsf T} A = I$$

Реализация следует фазе pywt (§0.4): в режимах продолжения строка $i$ — свёртка, оканчивающаяся на отсчёте $2i+1$, а не $2i$. При периодизации и чётном $N$ матрица $A$ — блочный циркулянт из $N/2$ блоков $2 \times 2$, и её спектр собирается из символа $H_p$:

$$\sigma(A) = \bigcup_{k=0}^{N/2-1} \sigma\Big(H_p\big(e^{2\pi i k / (N/2)}\big)\Big), \qquad \operatorname{cond}(A) = \frac{\sigma_{\max}}{\sigma_{\min}}$$

## Алгоритм и стоимость

1. Длина полосы за уровень $\mathrm{len}$ (здесь $L$ — длина фильтра): $\lfloor (N+L-1)/2 \rfloor$ для всех режимов, кроме `periodization`, где $\lceil N/2 \rceil$. Строк $2\,\mathrm{len}$, столбцов $N$.
2. Столбец $j$ — результат одного уровня DWT единичного сигнала $e_j$ в выбранном режиме границы: сверху коэффициенты аппроксимации, снизу детали. Так матрица учитывает продолжение сигнала за краями.
3. Синтез $S$ строится так же, обратным уровнем на единичных коэффициентах.
4. Перемежающийся порядок строк берёт строки попарно $(a_k, d_k)$ — тогда видна $2 \times 2$-блочно-тёплицева структура (§6.2).
5. $\operatorname{cond}(A)$ — по сингулярным числам (SVD).

Построение стоит $N$ прогонов уровня по $O(NL)$, то есть $O(N^2 L)$; SVD — $O(N^3)$. Матрицы строятся только для режима объяснений и тестов.

## С числами этого блока

Банк «{{block.bank}}», $N = {{block.n}}$, режим границы — {{block.mode}}, порядок строк — {{block.order}}. Размер матрицы: {{block.rows}} × {{block.cols}} (строк × столбцов).

Число обусловленности $\operatorname{cond}(A) = {{metric.cond}}$. Для ортогонального банка с периодизацией оно равно $1$: все сингулярные числа единичные. Вне периодизации строк больше, чем столбцов ($2\,\mathrm{len} > N$), и $A$ не квадратна.

## Проверки

- Ортогональность $A^{\mathsf T} A = I$, наибольшее отклонение от единичной матрицы: {{check.ata_identity}}. Выполняется для ортогонального банка с периодизацией; на краях других режимов и у биортогональных банков эта проверка не проходит по построению.
- Левая обратность $S A = I$ (точное восстановление), наибольшее отклонение $S A x$ от $x$ на тестовом сигнале: {{check.sa_identity}}
- Спектр через символ $H_p$ при периодизации совпадает с плотным SVD (§6.4).

## Реализация

Анализ: каждый столбец матрицы — один уровень DWT единичного сигнала, аппроксимация сверху, детали снизу.

```cpp
    const std::size_t len = dwt_coeff_len(n, bank.length(), options.mode);
    Eigen::MatrixXd a = Eigen::MatrixXd::Zero(idx(2 * len), idx(n));
    for (std::size_t j = 0; j < n; ++j) {
        const auto e = unit(n, j);
        const auto level = dwt_level<double>(e, bank, options);
        if (!level) return std::unexpected(level.error());
        for (std::size_t i = 0; i < len; ++i) {
            a(idx(i), idx(j)) = level->approx[i];
            a(idx(len + i), idx(j)) = level->detail[i];
        }
    }
    return a;
```
