## Назначение

Менять усиление во времени по уровню самого сигнала: `compressor` и `limiter` уменьшают громкие места выше порога, `gate` приглушает тихие места ниже порога.

## Формулы

Уровень в дБ — один на все $C$ каналов (сцепленный детектор). Пиковый и RMS:

$$L_{\mathrm{peak}}[n] = 20\lg\max\big(\max_c \lvert x_c[n]\rvert, 10^{-10}\big)$$

$$P[n] = c_r P[n-1] + (1 - c_r)\,\frac{1}{C}\sum_c x_c[n]^2, \qquad L_{\mathrm{rms}}[n] = 10\lg\max\big(P[n], 10^{-20}\big)$$

Коэффициент сглаживания для постоянной $\tau$ мс: $c(\tau) = e^{-1000/(\tau f_s)}$, $c(0) = 0$; за время $\tau$ ступенька проходит $1 - 1/e \approx 63$ %.

Статическая кривая с порогом $T$, наклоном $S = 1/R$ и квадратичным коленом ширины $W$:

$$G(L) = \begin{cases} L, & L - T < -W/2 \\ L + (S - 1)\,\frac{(L - T + W/2)^2}{2W}, & \lvert L - T\rvert \le W/2 \\ T + (L - T)\,S, & L - T > W/2 \end{cases}$$

Сглаживается не уровень, а требуемое снижение в дБ $\gamma^*[n] = G(L[n]) - L[n] \le 0$, с ветвлением атака/восстановление; начальное $\gamma = 0$:

$$\gamma[n] = c\,\gamma[n-1] + (1 - c)\,\gamma^*[n], \qquad c = c_{\mathrm{att}} \text{ при } \gamma^*[n] < \gamma[n-1], \text{ иначе } c_{\mathrm{rel}}$$

$$y_c[n] = x_c[n]\cdot 10^{(\gamma[n] + M)/20}$$

Лимитер — тот же расчёт с $S = 0$, $W = 0$, $M = 0$ и пиковым детектором: $\gamma^* = \min(0, T - L)$. Гейт: $\gamma^* = -\rho$ при $L < T$, иначе $0$, без подъёма $M$; у гейта атака — это открытие ($c_{\mathrm{att}}$ при $\gamma^* > \gamma[n-1]$), восстановление — закрытие.

## Алгоритм и стоимость

1. Детектор: мгновенный пик или однополюсное сглаживание мощности, усреднённой по каналам; канал короче остальных дополняется нулями.
2. Требуемое снижение по статической кривой (у гейта — ступенька).
3. Однополюсное сглаживание снижения в дБ с разными коэффициентами на нарастание и спад.
4. Каждый канал умножается на $10^{(\gamma + M)/20}$ и сохраняет свою длину.

Заглядывания вперёд нет: при нулевой атаке лимитер срезает пик точно в тот же отсчёт, при ненулевой — пропускает выбросы. Стоимость $O(NC)$; память — уровень и усиление по $N$ значений плюс выход.

## Проверки

- Компрессор (пик: −12 дБ, 4:1, без колена, 2/30 мс; RMS: −18 дБ, 3:1, колено 6 дБ, 0,5/10 мс, подъём 4 дБ, окно 1,5 мс), лимитер (−6 дБ, атака 0 и 1 мс) и гейт (−6 дБ, глубина 40 дБ, 0,5/3 мс) на стереопаре каналов разной длины совпадают с эталонным вычислителем усиления на Python до $10^{-10}$ в каждом канале.
- Лимитер с нулевой атакой держит $\lvert y\rvert \le 10^{-6/20}(1 + 10^{-12})$.
- Тихий сигнал ниже порога проходит компрессор без изменений; тишина через гейт остаётся точным нулём.

## Реализация

Вычислитель усиления: снижение по статической кривой и его сглаживание с разной атакой и восстановлением.

```cpp
    Samples gain(level.size());
    double state = 0;
    for (std::size_t n = 0; n < level.size(); ++n) {
        const double target = static_curve(level[n], threshold, slope, knee) - level[n];
        const double coef = target < state ? attack : release;
        state = coef * state + (1 - coef) * target;
        gain[n] = state + makeup;
    }
    return apply_gain(a, gain);
```
