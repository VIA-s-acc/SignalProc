## Назначение

Создать тестовый сигнал известной формы: синус, свип, импульс, ступеньку, шум трёх цветов, набор гармоник, AM- и FM-сигналы или один из тестовых сигналов Донохо–Джонстона. Известная форма позволяет проверять фильтры и вейвлеты по ответу, который можно предсказать заранее.

## Формулы

С $t_n = n / f_s$ и $\omega = 2\pi f / f_s$ рад/отсчёт синус и гармоники:

$$x[n] = A \sin\left(\frac{2\pi f}{f_s}\, n + \varphi\right), \qquad x[n] = \sum_{h=1}^{H} a_h \sin\left(2\pi h f_0 \frac{n}{f_s}\right)$$

Свип от $f_0$ до $f_1$ за $t_1 = (N-1)/f_s$, $x[n] = \cos \varphi(t_n)$:

$$\varphi_{\mathrm{lin}}(t) = 2\pi \left( f_0 t + \frac{f_1 - f_0}{2 t_1}\, t^2 \right)$$

$$\varphi_{\mathrm{log}}(t) = \frac{2\pi f_0 t_1}{\ln (f_1 / f_0)} \left( \left(\frac{f_1}{f_0}\right)^{t/t_1} - 1 \right)$$

Импульс и ступенька в точке $n_0$:

$$x_{\delta}[n] = \begin{cases} 1, & n = n_0 \\ 0, & n \ne n_0 \end{cases} \qquad x_{u}[n] = \begin{cases} 0, & n < n_0 \\ 1, & n \ge n_0 \end{cases}$$

Амплитудная и частотная модуляция (несущая $\omega_c$, модулирующая $\omega_m$, глубина $m$, индекс $\beta$):

$$x_{\mathrm{AM}}[n] = \left(1 + m \sin \omega_m n\right) \sin \omega_c n, \qquad x_{\mathrm{FM}}[n] = \sin\left(\omega_c n + \beta \sin \omega_m n\right)$$

Цветной шум: белый гауссов шум $x$, его DFT $X[k]$ домножается на $k^{\alpha}$, нулевая гармоника убирается, затем сигнал приводится к заданному RMS $\rho$:

$$X[0] \leftarrow 0, \quad X[k] \leftarrow k^{\alpha} X[k], \quad x \leftarrow \frac{\rho\, x}{\sqrt{\tfrac{1}{N} \sum_n x[n]^2}}, \qquad \alpha = 0,\ -\tfrac{1}{2},\ -1$$

Показатель $\alpha$ у белого, розового и коричневого шума: мощность спектра пропорциональна $k^{2\alpha}$, то есть $1$, $1/k$ и $1/k^2$.

Сигналы Донохо–Джонстона берутся на $t_i = (i+1)/N$; например

$$x_{\mathrm{heavisine}}(t) = 4 \sin 4\pi t - \operatorname{sgn}(t - 0{,}3) - \operatorname{sgn}(0{,}72 - t), \qquad x_{\mathrm{doppler}}(t) = \sqrt{t(1-t)}\, \sin\frac{2\pi \cdot 1{,}05}{t + 0{,}05}$$

Все частоты должны лежать ниже $f_s / 2$, иначе частота $f$ неотличима от $f_s - f$ (§3.1).

## Алгоритм и стоимость

1. Вектор из $N = f_s T$ отсчётов заполняется за один проход; фаза каждого отсчёта считается напрямую как $2\pi f k / f_s$, а не накапливается, поэтому дрейфа фазы нет.
2. Свип выбирает формулу фазы по виду (линейный или логарифмический); при $f_0 = f_1$ логарифмический свип вырождается в чистый тон, а при $N < 2$ возвращается вектор из единиц.
3. Шум: гауссовы числа из mt19937_64 с заданным зерном; для розового и коричневого дальше прямое FFT, умножение гармоник на $k^\alpha$, обратное FFT.
4. В конце шум масштабируется к заданному RMS.

Время $O(N)$ для синуса, свипа, AM и FM (по одной тригонометрической функции на отсчёт), $O(H N)$ для $H$ гармоник, $O(N \log N)$ для цветного шума. Память $8N$ байт. При одном и том же зерне шум воспроизводится бит в бит.

## С числами этого блока

Вид сигнала: {{block.kind}}; частота дискретизации $f_s$ = {{block.rate}}, длительность $T$ = {{block.duration}}. Число отсчётов $N = f_s T$; частота Найквиста $f_s / 2$ — верхняя граница для любой частоты в сигнале, а разрешение спектра по частоте равно $f_s / N = 1/T$.

## Проверки

Численной проверки в интерфейсе у этого блока нет: его правильность закрепляют тесты.

Тесты сверяют свипы со scipy (`chirp`) и сигналы Донохо–Джонстона с PyWavelets. Для шума проверяется наклон спектра в логарифмическом масштабе (белый, розовый, коричневый), точное RMS и воспроизводимость по зерну. Импульс, ступенька, AM, FM и гармоники совпадают с формулами до $10^{-15}$. Вырожденные свипы дают константу или пустой вектор.

## Реализация

Ядро свипа: мгновенная фаза линейного и логарифмического чирпа; синус и остальные виды — прямые формулы выше (`sine`, `am`, `fm`, `harmonics`).

```cpp
    const double t1 = static_cast<double>(n - 1) / fs;
    for (std::size_t k = 0; k < n; ++k) {
        const double t = static_cast<double>(k) / fs;
        double ph = 0;
        if (kind == SweepKind::linear) {
            const double beta = (f1 - f0) / t1;
            ph = kTwoPi * (f0 * t + 0.5 * beta * t * t);
        } else if (f0 == f1) {
            ph = kTwoPi * f0 * t;
        } else {
            const double beta = t1 / std::log(f1 / f0);
            ph = kTwoPi * beta * f0 * (std::pow(f1 / f0, t / t1) - 1.0);
        }
        x[k] = std::cos(ph);
    }
```
