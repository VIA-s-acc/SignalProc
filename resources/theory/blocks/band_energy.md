## Назначение

Показать, как энергия сигнала распределена по полосам разложения, и убедиться, что ортонормированное преобразование её сохраняет.

## Формулы

Энергия полосы $b$ и её доля, где $c_b \in \{d_1, \dots, d_J, a_J\}$:

$$E_b = \sum_k c_b[k]^2, \qquad p_b = \frac{E_b}{\sum_{b'} E_{b'}}$$

Ортонормированный банк с периодизацией — равенство Парсеваля:

$$\sum_n x[n]^2 = \sum_{j=1}^{J}\sum_k d_j[k]^2 + \sum_k a_J[k]^2$$

Биортогональный банк, границы Рисса $A$ и $B$ (§14.3): $A\,\|x\|^2 \le \sum_b E_b \le B\,\|x\|^2$.

## Алгоритм и стоимость

1. Для каждой полосы $E_b$ — сумма квадратов с компенсацией Неймайера: ошибка порядка $u$, а не $Nu$ (§13.2).
2. Полная энергия $T = \sum_b E_b$ — тоже с компенсацией.
3. Доля $p_b = E_b / T$; при $T = 0$ все доли нулевые.

Стоимость $O(N)$: каждый коэффициент читается один раз, суммарно их $\approx N$; память $O(J)$.

Чтобы сравнивать полосы разной длины $N_b$, энергию делят на длину: $E_b / N_b$ — мощность на отсчёт (§12.5).

## Проверки

- Парсеваль, $\lvert \sum_b E_b - \|x\|^2 \rvert / \|x\|^2$: {{check.parseval}}
- Равенство выполняется для ортонормированного банка с периодизацией; в других режимах границ и у биортогональных банков есть лишь оценки Рисса.

## Реализация

Энергия каждой полосы и нормировка на сумму.

```cpp
std::vector<double> band_energy_fractions(const BasicCoeffs<double>& coeffs) {
    std::vector<double> e;
    e.reserve(coeffs.bands.size());
    for (const auto& band : coeffs.bands) e.push_back(energy(band));
    const double total = neumaier_sum(e);
    for (double& v : e) v = total > 0 ? v / total : 0.0;
    return e;
}
```
